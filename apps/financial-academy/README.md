# 复利学堂 · 看懂一家公司

面向公司研究的中文互动财报课程：读知识点、调整参数做实验、完成章节练习，最后通过综合考试。

[已有在线版本](https://financial-apprentice.xbtlin.chatgpt.site)目前为私有站点，需要获准的 ChatGPT 账号；公开源码不改变站点访问权限。

## 课程与出师条件

- 12 章、72 个知识点：财报地图、利润表、资产负债表、现金流、利润质量、营运资本、ROE/ROIC、债务、每股价值、附注审计、行业阅读与估值。
- 48 道章节题、24 道结业题；包含数值计算、情景判断及逐题解析。
- 3 个互动实验：利润与现金、杜邦 ROE、增长与估值。
- 错题自动收录，重答正确后移出待复习列表；提供公式速查、官方资料入口和结业记录打印。
- 学完本章全部知识点后才能闯关，每章至少答对 **3/4**；12 章全部通过后解锁结业考试。
- 结业至少答对 **21/24**，且 **4 道核心风险题全部正确**。复习错题不会替代正式结业考试。

章节阅读以确认理解为准，不设置倒计时。考试不限时，允许使用计算器和复习后重考。这是个人学习结业记录，不是职业资格认证。

## 本地运行

要求 Node.js **22.13.0 或以上**与 npm。在仓库根目录执行：

```bash
cd apps/financial-academy
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_silly_power_pack.sql
npm run dev
```

按终端显示的地址访问；默认本地开发地址为 `http://localhost:5173`。首次运行需要应用上述本地数据库迁移，之后不要重复执行同一迁移。

干净克隆默认使用 portable 开发配置。仅在本地回环地址的开发服务器中，点击“登录”会使用模板提供的本地模拟身份；本地 D1 数据保存在 `.wrangler/`。这不连接线上数据库，也不代表已经验证线上账号同步。

```bash
npm test
npm run typecheck
npm run build
```

`npm test` 检查题库结构、章节及结业分数边界、核心题否决、数值输入、答案隐藏、错题生命周期和结业状态。`npm start` 预览构建后的 Worker，但不模拟 ChatGPT 登录；需要模拟身份时使用 `npm run dev`。

## 部署与账号进度

这是 **Vinext / React + Cloudflare Worker + D1** 应用，不是可直接由 GitHub Pages 托管的纯静态网页。GitHub Pages 不能运行 `/api/progress` 或保存账号进度。

- `.openai/hosting.json` 保留 `DB` 绑定，已移除原站点的账号专属 `project_id`。
- 在 Sites 新建站点时，应绑定新站点返回的 ID；数据库迁移随源码提供。更新已有站点时应使用该站点自己的 ID。
- 生产端依赖受信任的 Sites 入口注入身份信息，API 按当前用户隔离读写。自行部署到其他环境时，必须接入可靠身份验证并保护这些身份头，不能直接信任客户端发送的身份头。
- 本仓库不包含学习记录、数据库文件、环境密钥或部署凭证。复制源码不会迁移旧站点的学习进度。
- 线上站点仍独立运行；推送 GitHub 不会自动更新它。修改课程或代码后需要另行构建并发布。

## 内容维护

新增或修改题目时保持题目 ID 稳定；调整课程结构、题目数量或通过标准时，需要同步更新页面文案、评分逻辑与测试。已有学习记录按 ID 关联，改变含义时应设计明确的版本迁移。

所有计算案例均为教学假设。腾讯、快手、拼多多、美团、泡泡玛特、茅台、Google、京东健康、现代牙科用于说明阅读问题，不代表课程披露其最新业绩。不同准则、期间、币种和归属口径需要分别核对；本项目仅供学习研究。
