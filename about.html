这是什么

AI Berkshire 是一套开源的投资研究方法：把价值投资的分析框架写成 Claude Code 与 Codex 都能调用的研究技能（Skill）， 让一个人加上 AI 代理，能完成一个投研小组的工作量：读一手财报、交叉核验数字、多视角对抗论证、写成结论明确的报告。

这个网站是项目的阅读入口，收录全部成品研究，按公司、专题、时间、类型整理，电脑、手机、电子阅读器都能读。

研究方法的几条原则

  • 只用一手材料：交易所公告、年报、业绩会原话。旧报告只当线索，不当证据。
  • 事实与判断分开写：凡是推算和判断都标明，数字注明来源与口径。
  • 强制给结论：不写"一方面、另一方面"的两头讨好，给出可以被检验的判断和检验时间点。
  • 可追溯：同一家公司的报告按时间排在一起，判断怎么变、为什么变，都能对照着看。

怎么用这个网站

  • 按公司：每家公司一页，分公众号发表、深度系列、财报、估值等类型。
  • 专题：行业研究、横向对比、筛选池。
  • 按时间与按类型：看最近写了什么。
  • 搜索：输入公司名或关键词，例如"拼多多 财报"。
  • 右上角可调字号和深浅色；读过的文章会标记进度，下次打开可以接着读（只记在你自己的浏览器里）。
  • 发现数据错误：每篇报告末尾有"提交纠错"，会打开 GitHub 的纠错表单并自动填好报告名称，请附上正确值和来源链接。
  • 也可以用 RSS 订阅更新：feed.xml。
