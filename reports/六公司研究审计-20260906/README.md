## 估值审查

- 区分已披露历史数据、正常化调整与未来假设。正常化盈利必须有可追溯桥接，不能把希望实现的利润当作已实现利润。
- 三年目标价是未来情景价值；今天的价值需要折现，并考虑期间现金分红。不能用未折现目标价直接宣布当前安全边际。
- 报告中的含分红年化若按末期汇总计算，属于终值财富的等效年化，不是逐笔分红现金流IRR；期间分红不预设再投资回报。
- 整体PE模型与经营价值加富余净现金的分部估值是交叉校核方法，不能相加。既给利息收入估值又全额加入同一现金，需要剔除重复。
- 回购提升每股收益后，不再加一次回购收益率；股份薪酬、融资与可转债需在费用、股数或债务中一致反映，不能遗漏或重复扣减。
- AI运行率收入不等于已实现全年收入，AI融资金额不等于经营创造现金。亏损公司不使用负PE推断便宜。
- 悲观情景允许盈利下降、估值压缩及融资困难，不是只把乐观增速调低。基准情景的利润率恢复、收入增长与股本变化都必须说明经济条件。
- 情景价格和主观概率不能直接输出“最优仓位”。公司研究先判断价格吸引力，账户现金、期权、资金期限与可承受损失决定实际仓位。
