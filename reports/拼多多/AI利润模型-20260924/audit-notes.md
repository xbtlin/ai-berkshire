# 拼多多AI与利润研究：审计说明

资料截止与核验日期：2026-09-24 UTC。

## 范围与结论

主报告为[拼多多AI与三年十年利润研究](../拼多多-AI与三年十年利润研究-20260924.md)。历史数据核验、预测输入一致性和算术复算分开处理，不能把工具显示PASS解释为未来利润已获证实。

- 对23项历史/行情及衍生口径进行了双源数值比对。以原始值为分母、差异不超过1%为准，均通过；数据来源和数值见`validation.json`。
- `report_audit.py extract`按固定种子42、15%比例，从162个可识别数字中抽取25项。
- 其中22项进入数值核验：7项历史或历史衍生数字（2项只有原始来源）、8项模型算术、7项声明的输入假设；均无超限差异。
- 排除3项：两项主观评分；一项解析器从“不是每包统一3欧元或每件3欧元”中抽出的3。后者按欧盟原文核对语义，而非把否定句误作正向事实。
- 财务角色独立用Decimal核对三年及十年净利、估值、反向所需利润；商业角色复核AI收益去重；风险角色复核关税、DSA及FSR程序状态。未发现影响结论的计算错误。

判决：**已核验数据和算术通过，附披露限制准出；不对预测实现率作保证。**

## 已处理的实质差异

1. 2025初步归母993.64469亿元与审计归母978.42539亿元差异超过1%，使用审计值，未取平均；经营利润亦使用审计后值。
2. `financial_rigor.py cross-validate`默认中位数基准及2%阈值，与skill的一手分母/1%要求不同。本次附加Decimal差异检查，不依赖工具默认绿色标记。
3. 现有`financial_rigor.py calc`内部表达式会经过浮点求值。本研究仍按项目要求调用，同时由`model.py`全程Decimal独立复算，模型结果以Decimal文件为准。没有为本次报告改动共享工具。
4. 2029AI详细桥接经营贡献64.3721052亿元，主情景近似65亿元；税后50.210242056与50.70的差异在正文解释。
5. JSON含AI利润除反事实基础收入的字段已改名为`op_profit_over_base_revenue`和`net_profit_over_base_revenue`，避免误认作会计利润率。
6. AI成本池限定为基线业务量，新增订单变动成本在贡献率中扣除；新增AI费用另扣一次，防止重复节约或重复扣成本。

## 验证边界

- 2026年中集团财务披露仍未经审计。
- 2026H1在线营销收入和现金及等价物抽样仅取得原始口径核对，没有将同一公告转载冒充独立来源。
- 最新精确时点股本未核实。收盘市值按最近核实法定发行股本估计；EPS使用加权/摊薄股本，二者分开。
- 市值工具用2026-09-24 12:26 EDT同页报价78.38美元和1115.7亿美元快照校验股本数量级；报告估值价格另锁9月23日79.20美元，两者未混合冒充同一时点。
- 股权PE约8.6倍基于法定发行股数；工具按14.8亿ADS假设计算的摊薄PE约8.9倍，差异是分母口径，不是利润变动。
- 三情景工具按2026E至2029E三个年度的等值盈利增速验证终值；报告股价回报按研究日至2029年末约3.25年计算。
- 公司没有披露足以验证的国内/Temu独立利润和新增AI利润贡献。模型是可修改假设，不是从报表识别出的因果结果。
- 抽样不能覆盖全部文字。监管规则、来源版本、利润定义和关键模型进行了额外人工审读；法律环境可能继续变化。

## 附件与复现

- `model.py`：所有情景公式、AI桥接和敏感性，金额单位为人民币亿元。
- `model-results.json`：完整模型输入、口径定义和Decimal结果。
- `validate.py`：保存于截止日的外部核验值、工具调用、模型复算和抽样分类。不联网刷新资料。
- `validation.json`：23项双源比对、工具输出和版本差异。
- `audit-extract.txt`、`audit-sample.json`：固定种子抽样。
- `audit-results.json`、`audit-verdict.txt`：分类核验及判决。

在仓库根目录依次运行：

```bash
python3 reports/拼多多/AI利润模型-20260924/model.py
python3 reports/拼多多/AI利润模型-20260924/validate.py
python3 tools/report_audit.py extract --report reports/拼多多/拼多多-AI与三年十年利润研究-20260924.md --seed 42
```

调整主报告表格或模型后，应重新核对抽样映射；映射不匹配会停止，而非自动把新数字当正确值。
