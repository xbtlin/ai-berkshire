# Community Reports

This folder contains research reports produced by community members **using this repository's skills**, organized by `[company]/`. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the submission requirements: state the skill and model used at the top, include a disclaimer, and keep one report per PR.

Reports in this directory reflect the contributors' work, not the maintainer's views, and are not investment advice. The maintainer's own research lives in the other `reports/` directories.
