## 二、生意本质 — 段永平视角

### 一句话

**融捷股份是一座"中国最好的锂矿山"，但它的锂精矿99.76%卖给大股东的关联企业——价格比市场价低一大截。好资产在烂人手里。**

### 🔴 致命问题：关联交易

| 维度 | 数据 |
|------|------|
| 前五大客户占比 | **99.76%** |
| 第一大(控股股东关联) | **92.25%** |
| 锂精矿售价 | **~615美元/吨**（市场价>800） |
| 比亚迪关联 | 吕向阳是比亚迪副董事长+第三大股东 |

**你买融捷股份，实际上是在买吕向阳家的"内部资源池"。** 锂矿确实好（1.42%品位全国第一），但矿主把锂低价卖给自家人，小股东只能分到残渣。

> **段永平会说**："管理层不诚信的公司——不管矿有多好，我都不碰。99.76%的销售卖给关联方——这不是投资，这是给大股东送钱。"

## 四、逆向思考

### 🔴 四重红旗

| 红旗 | 说明 |
|------|------|
| **关联交易99.76%** | 几乎全部卖给大股东关联企业 |
| **低价输送** | 锂精矿售价显著低于市场价 |
| **同业竞争** | 大股东承诺2027年解决，仅剩1年，无方案 |
| **高管离职** | 2026年CEO+CFO接连离职 |

### 空方核心

1. **"好矿在烂人手里"** — 关联交易结构下小股东无法受益
2. **3个跌停** — 锂价从20万→16万，市场先跑为敬
3. **PE 9x不贵** — 但如果利润也是关联交易"做"出来的呢？
4. **同业竞争仅剩1年** — 如果解决不了会怎样？
