# 腾讯与拼多多：商业质量及2036年度利润底稿

信息丰富度：腾讯A，PDD合并报表A、国内与海外独立经济性B。公开材料能验证合并账目，不能直接验证内部文化、分业务净利或十年后的行业格局。以下将事实、行为推断和预测假设分开。

## 生意本质、护城河与文化

腾讯的独特性在于用户关系可以跨越内容生命周期：某款游戏会衰退，但交流、支付、公众号、小程序等场景仍能反复发生。广告主的付费理由是有效转化，游戏付费理由是内容体验，云和支付的理由是稳定服务；这些利润源的资本要求与竞争程度不同。[公司Q2业务说明](https://www.prnewswire.com/apac/news-releases/tencent-announces-2026-second-quarter-results-302849608.html)

研究判断：关系链的迁移成本高于内容平台的时间粘性。朋友、工作联系和商家关系无法用一次补贴整体迁走，但用户可以同时刷短视频、使用其他AI应用。因此腾讯最强的是底层关系网络，不是占有用户所有时间。游戏护城河来自研发组合、IP、运营和分发；单款爆品仍需不断维护。广告护城河来自用户场景与交易闭环，若效果改善低于竞争者，流量规模也保不住预算。

文化不能由“用户为本”等口号直接证明。可观察行为是：腾讯2025年现金回购及现金股息合计1108.47亿元；产品仍持续迭代，并投入AI。前者是已发生的资本分配；后者的回报仍待验证。Q2公司明确披露算力预付款显著压低现金流，研究上不能把这笔已付资金永久删除。由此推断它兼顾生态、研发和资本回报，但不预设每一笔长期投入都有效。[年报现金流表](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0409/2026040901231.pdf)、[Q2原始新闻稿](https://www.prnewswire.com/apac/news-releases/tencent-announces-2026-second-quarter-results-302849608.html)

腾讯最强反方：社交入口依然强，股东经济性却可能变弱。如果AI竞争把业务变成需要持续算力更新的重投入生意，即使收入和会计利润增长，每元利润对应的自由现金也可能减少。微信的“不可替代”不能自动证明新投资回报率足够高。

PDD的付费客户主要是商家。平台聚合消费者需求，组织货品供给，并以广告和交易服务收钱；消费者重复购买的前提是到手价格、质量、交付和售后仍然有吸引力。海外扩张还要支付物流与合规成本。**“在线营销＝国内、交易服务＝Temu”不是公司披露的分部口径。**不能据此把国内和海外利润算成已知事实。[2025年报业务及收入注释](https://investor.pddholdings.com/static-files/92dafbdc-3125-4f2c-a28f-3d61203efbaf)

研究判断：PDD的护城河主要是成本、交易数据和组织执行，不是消费者被锁定。商家能否持续赚到钱是关键；如果必须靠更高补贴才能维持低价，或者商家支付推广费后已无合理利润，平台的定价权就接近上限。规模收益长期需要在平台、消费者、商家和履约网络之间分配。

文化证据须双面看。PDD持续扩展业务，管理层在Q2明确将商家生态投入置于当前重点，这是公司声称的优先级；报表中2025经营利润率从2024的27.53%降至21.56%，证明成本与投入正在实际占用利润，但不能单凭这一下降证明投入成功或全部自愿。年报表示目前无可预见现金分红计划，这使其资本回报可预测性弱于腾讯；不分红本身也不足以证明损害股东，最终还应看留存资金的投资回报。[Q2管理层声明与费用](https://investor.pddholdings.com/news-releases/news-release-details/pdd-holdings-announces-second-quarter-2026-unaudited-financial/)、[年报分红政策与利润表](https://investor.pddholdings.com/static-files/92dafbdc-3125-4f2c-a28f-3d61203efbaf)

PDD最强反方：低价电商的消费者忠诚可以属于“便宜”而非PDD，竞争者拿出补贴就能分流；海外规模增长也可能仅扩大低毛利交易。大量合并现金与少数股东何时收到现金是不同问题。相比腾讯，PDD的经营能力较易观察，长期利润在国内、海外和股东之间如何分配更难观察。

| 公司 | 可证伪观察项 | 推翻目前判断的方向 |
|---|---|---|
| 腾讯 | 微信使用频次、商家转化；长青游戏及新品贡献；广告增长的价格/负载/效果来源 | 关系链稳定而业务转化连续下降，说明流量优势不能保持经济价值 |
| 腾讯 | 算力投入、折旧、新增服务毛利、经常性利润现金转化 | 新增毛利长期无法覆盖算力与研发投入，需降低税后利润率假设 |
| PDD | 同款到手价、复购、获客和补贴成本、商家净回报 | 低价依赖持续补贴且商家回报下降，成本优势可能减弱 |
| PDD | 交易服务毛利与合规/履约成本；披露质量；留存现金的回报 | 收入增加但持续经营利润下降，或者资本配置缺乏可验证回报 |

这些是研究监测方向，并非目前都已具备可直接取得的公开时间序列。文化结论置信度低于报表数据。

## 2036年度利润的业务驱动情景

统一公式为：**各业务收入基数×十年收入增长因子×2036年归母经济净利率，加常态投资收益，减其他持续亏损。**净利率已经负担持续研发、股权薪酬、合理折旧摊销、获客、履约、总部费用分摊、利息及税项和少数股东权益；不包含公允价值变动等一次性收益。负净利率是税后无税盾的净损失假设，不因亏损自动确认退税或递延税收益。这是规范化税后会计经济利润，尚未扣股权资本机会成本，不是EVA，也不等于可以全额派发的现金。

两家都没有披露以下分业务净利率。它们只是把预测的驱动因素展开，避免一个净利CAGR隐藏所有竞争与投入假设。2036应以主表约数阅读，附录小数仅用于重算。

### 腾讯

2026全年研究收入基数：VAS 3900亿元、广告1650亿元、金融科技及企业服务2400亿元。它们是全年规范化假设，参考2025全年及2026H1的已披露规模，**不是2026全年实际，也不是把H1全部机械翻倍**。2026净利校核：`3900*0.32+1650*0.35+2400*0.16+200-100=2309.5`亿元，可取约2300亿元。

| 假设 | 悲观 | 基准 | 乐观 |
|---|---:|---:|---:|
| VAS收入年增速 / 2036经济净利率 | 0% / 25% | 6% / 32% | 8% / 36% |
| 广告收入年增速 / 2036经济净利率 | 2% / 25% | 9% / 35% | 12% / 40% |
| 金融科技及企业服务收入年增速 / 2036经济净利率 | 0% / 12% | 6% / 18% | 9% / 22% |
| 常态净投资收益 | 50 | 250 | 350 |
| 其他持续税后亏损 | -100 | -50 | -50 |
| 三项业务2036收入合计 | 8311 | 15188 | 19226 |
| 2036经济归母净利润计算值 | 1715.84 | 4575.78 | 6630.96 |
| 主表取整数 | **1700** | **4600** | **6600** |

这里的投资收益是归属腾讯的经常性被投企业税后盈利份额估计，不再重复加同一笔盈利对应的股息，也不另加投资资产价值；各业务利润率只覆盖合并业务，未含该投资收益。腾讯持有其他被比较公司权益，**七家公司利润不可直接相加**，否则可能重复计入穿透利润。

悲观是入口仍在但游戏停滞、广告仅温和增长、AI投入侵蚀利润率；基准要求长青游戏与新品替换、广告效果改善、支付和云扩张，算力回报足以维持经济净利率；乐观要求海外游戏、闭环广告与AI服务同时成功。AI服务的营业收入和成本已含各业务，不再额外加一笔“AI估值”或重复扣同一笔投入。

```text
悲观 = 3900*1**10*0.25 + 1650*1.02**10*0.25 + 2400*1**10*0.12 + 50 - 100
基准 = 3900*1.06**10*0.32 + 1650*1.09**10*0.35 + 2400*1.06**10*0.18 + 250 - 50
乐观 = 3900*1.08**10*0.36 + 1650*1.12**10*0.40 + 2400*1.09**10*0.22 + 350 - 50
```

### 拼多多

2026全年研究收入基数：在线营销及其他2200亿元、交易服务2350亿元。这是合并披露的收费类别模型，**不是国内与Temu分部预测**。2026盈利校核：`2200*0.35+2350*0+80=850`亿元；交易服务当前净利率0%只是分摊成本后的研究假设，不能引用为Temu已经盈亏平衡。

| 假设 | 悲观 | 基准 | 乐观 |
|---|---:|---:|---:|
| 在线营销及其他收入年增速 / 2036经济净利率 | 0% / 25% | 5% / 35% | 8% / 40% |
| 交易服务收入年增速 / 2036经济净利率 | -2% / -3% | 8% / 6% | 12% / 13% |
| 常态税后净利息收益 | 40 | 80 | 120 |
| 两项业务2036收入合计 | 4120 | 8657 | 12048 |
| 2036经济归母净利润计算值 | 532.40 | 1638.66 | 2968.69 |
| 主表取整数 | **500** | **1600** | **3000** |

模型净利率已将生态支持、合规、物流售后与日常补贴视为持续成本，不因管理层称其“投入”而加回。收益中不含无法解释的其他损益或公允价值收益。利息假设也不是将目前巨额现金以现有收益率永久外推。

悲观是国内收费停滞、交易服务规模收缩且持续亏损；基准是商家收益和供给质量稳定，交易规模增长而履约合规之后仅取得温和利润率；乐观要求国际业务有更强的成本摊薄和本地经营能力，低价优势延续但不以无限补贴维持。净利润是否能派发给股东仍由资金可及性和资本配置决定。

```text
悲观 = 2200*1**10*0.25 + 2350*0.98**10*(-0.03) + 40
基准 = 2200*1.05**10*0.35 + 2350*1.08**10*0.06 + 80
乐观 = 2200*1.08**10*0.40 + 2350*1.12**10*0.13 + 120
```

结论：腾讯的关系网络与盈利分布，使其十年利润可预测性优于PDD；PDD在低成本组织方面较强，但海外成本、商家分配及资本回报路径带来更宽的结果区间。这是商业质量判断，不能单独推出哪只股票在今天价格更值得买。本底稿用于学习研究，预测置信度低于历史报表核验；文化判断也不是对管理层人格的认证。
