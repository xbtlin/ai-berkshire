# 风电+商业航天产业链交叉研究

> **研究日期**：2026年7月14日

---

## 一、两个看似无关的行业，一个共同的底层逻辑

```
┌─────────────────────┐    ┌─────────────────────┐
│     风电产业链        │    │    商业航天产业链      │
├─────────────────────┤    ├─────────────────────┤
│ 上游: 钢材/玻纤/稀土  │    │ 上游: 特种钢/液氧甲烷   │
│ 中游: 风机整机制造    │    │ 中游: 火箭/发动机制造  │
│ 下游: 发电/并网/运维   │    │ 下游: 发射/卫星运营    │
│ 金风科技: 中游龙头     │    │ 蓝箭航天: 中游龙头     │
└─────────────────────┘    └─────────────────────┘
          ↓                        ↓
    清洁能源供应    ←────→    卫星通信/AI基础设施
```

**共同点**：
1. 都是重资产、高技术壁垒、长周期行业
2. 都是中国"新质生产力"的核心赛道
3. 都面临全球化竞争与地缘政治风险
4. 金风科技在这两个行业都有布局（风电主业+蓝箭航天4.14%）

## 二、朱雀三号×火箭回收：中国版可复用火箭的突破

### 技术里程碑

| 时间 | 事件 | 意义 |
|------|------|------|
| 2023.12 | 朱雀二号入轨 | 全球首枚液氧甲烷火箭成功 |
| 2025.11 | **朱雀三号一子级回收成功** | 中国首次火箭垂直回收 |
| 2026.H2 | 朱雀三号首飞（计划） | 进入商业运营 |

### 为什么火箭回收是"游戏规则改变者"

| | 一次性火箭 | 可复用火箭(朱雀三号) |
|------|:---:|:---:|
| 单次发射成本 | 2-3亿 | **~8000万** |
| 年发射频次 | 3-5次 | **50次+** |
| 星网星座发射总成本 | >500亿 | **~200亿** |

**朱雀三号如果成功商业化，将把中国低轨卫星的发射成本砍掉60%+。** 这对星网计划、千帆星座、卫星互联网直连——都是最底层的基础设施突破。

### 全球竞争格局

| 公司 | 国家 | 可复用火箭 | 状态 |
|------|:---:|:---:|:---:|
| SpaceX | 🇺🇸 | 猎鹰9/星舰 | 已验证数百次 |
| Rocket Lab | 🇺🇸/🇳🇿 | Electron/Neutron | 部分回收 |
| **蓝箭航天** | 🇨🇳 | **朱雀三号** | **2025首回收** |
| 星际荣耀 | 🇨🇳 | 双曲线三号 | 研发中 |
| 天兵科技 | 🇨🇳 | 天龙三号 | 研发中 |

**蓝箭是中国唯一完成回收验证的。** 这个先发优势价值百亿。
