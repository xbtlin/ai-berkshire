# 审计范围与结果

日期：2026-11-01。对象：[报告正文](../持械入宋研究报告-20261101.md)。

**发布结论：可以作为明确保留证据缺口的公开资料调研发布，不是技术栈认证、流量审计或财务尽调结论。**

## 数字检查

使用仓库 `tools/report_audit.py` 全量提取，得到26个候选数据点。其中23个与本次人工录入的公开来源相符；3个属于误识别：工具名n8n中的8、更新时间17:03中的3，以及来源日期“2月”。这些误识别单独列出，没有为了凑通过数而提供虚假业务值。

此外，人工检查14个自动提取遗漏的短语，覆盖收藏、账号获赞、原著长度、集数、时长、团队分工及主创财务陈述。脚本只检查这些短语没有在编辑时丢失；来源核实依赖研究时的页面阅读和浏览器观察。

使用 `tools/financial_rigor.py calc` 复算四个表达式，另用Python Decimal校验三个教学情景与热度变化。仓库计算器日志末位存在二进制浮点尾差，因此以Decimal复核后的两位小数作为正文展示结果。

## 通过究竟意味着什么

`report-audit-verdict.txt` 的工具通用“准出”文案只适用于输入数字的相符程度，不能扩大为对整份调研真实性的自动认证。

| 项目 | 实际达到的核验层级 |
| --- | --- |
| 制作方40亿喜报及第九季8200万热度帖 | 直接看到原帖／海报／标题；证明制作方公开宣称了这些数字 |
| 账号粉丝与获赞 | 直接看到主页显示值；非本剧专属数据 |
| 第十季九日走势 | 与第三方页面一致；官方原始榜单未直接核实 |
| 主创成本与回报陈述 | 具名专访可读；账单、结算、总成本和净利润未知 |
| 模型／harness／供应商 | 没有足够项目级证据，正文保留“未确认” |
| 教学情景 | 参数明确标为假设；只验证算术，不能用于估计本剧真实成本 |

没有把同一篇采访的转载算成多源验证，没有把阈值“突破40亿”改成精确累计值，没有给未知的净利润、模型份额或完播率补数。

## 文件

- `report-audit-extract.txt`：原始数字提取输出。
- `numeric-results.json`、`report-audit-verdict.txt`、`verdict.json`：23项转录比较及限定范围的结果。
- `extraction-exclusions.json`：3项误识别说明。
- `financial-rigor-calculations.txt`、`decimal-calculations.json`：仓库计算器输出与Decimal复核。
- `manual-scope.json`：补充人工复核范围。
- `audit-summary.json`：报告与指标文件哈希、计数及发布边界。
- `run_audit.py`：从本地指标记录复现上述检查的脚本。它不联网抓取或认证来源。

在仓库根目录运行：

```bash
python3 reports/持械入宋深度调研-20261101/audit/run_audit.py
```
