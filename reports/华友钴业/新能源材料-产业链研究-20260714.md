# 新能源电池材料产业链全景研究

> **研究日期**：2026年7月14日 | **核心标的**：华友钴业

---

## 一、产业链全景图

```
                        上游资源                中游冶炼            下游材料
                    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
钴：刚果金矿山     →   粗钴/钴盐    →   三元前驱体     →   LG/亿纬/三星
镍：印尼红土镍矿   →   湿法MHP/NPI  →   三元正极材料   →   特斯拉/比亚迪
锂：津巴布韦/澳洲  →   碳酸锂/氢氧化锂 → 电池/储能      →   电动车/电网
                    └──────────────┘    └──────────────┘    └──────────────┘
                      华友钴业主战场    ← 一体化的核心优势 →
```

## 二、关键金属价格驱动

### 钴（弹性最大）

| 变量 | 现状 |
|------|------|
| 刚果金出口配额 | 2025年起实施，全球供给锐减 |
| 2026-2027缺口 | **明确** |
| 价格 | 26Q1 MB钴26美元/磅(+119% YoY) |
| 华友优势 | 印尼副产钴不受配额限制 |

### 镍（利润主力）

| 变量 | 现状 |
|------|------|
| 印尼RKAB政策 | 收紧审批，新产能受限 |
| HPM基准价改革 | 抬升成本曲线底部 |
| 华友产能 | 18万吨→远期36万吨 |
| 湿法单吨盈利 | **~0.3万美元/吨** |

### 锂（成长新引擎）

| 变量 | 现状 |
|------|------|
| 津巴布韦出口配额制 | 供给受限 |

| 储能需求 | 🟢 旺盛 |
| 华友成本目标 | 6万元/吨以下（全球第一梯队） |

## 三、竞争格局

| 环节 | 华友位置 | 对手 |
|------|:---:|------|
| 钴 | 全球前3 | 洛阳钼业、嘉能可 |
| 镍 | 中国#1(印尼) | 青山、格林美 |
| 三元前驱体 | 国内前3 | 格林美、中伟股份 |
| 碳酸锂 | 新进入 | 赣锋、天齐 |

**华友的独特性**：四者全做，且一体化打通。这在全球找不到第二家。

## 四、华友 vs 紫金矿业

| 维度 | 华友钴业 | 紫金矿业 |
|------|:---:|:---:|
| 2026E PE | **~15x** | **~9x** |
| ROE | ~18% | 33% |
| 毛利率 | ~22% | 36% |
| 负债率 | ~62% | 51% |
| 金属覆盖 | 镍钴锂 | 金铜锌锂 |
| 海外风险 | 刚果+印尼（双风险） | 18国分散 |
| 成长性 | 镍钴锂量价齐升 | 金铜产量CAGR 13% |
| **谁是更好的投资** | 成长更强 | **更便宜+更安全** |

## 五、行业风险地图

| 风险 | 严重程度 | 如果发生 |
|------|:---:|------|
| 刚果金没收矿山 | 🔴 灾难 | 股价腰斩 |

## 六、投资结论

> 华友钴业是新能源材料一体化的全球龙头，2026E PE~15x处于合理区间。镍钴锂三大金属同时受益于"资源民族主义"涨价周期。但和紫金矿业比：**紫金更便宜(PE 9x vs 15x)、更安全(18国分散 vs 刚果+印尼双集中)、更赚钱(ROE 33% vs 18%)。** 如果只选一个资源股——紫金是更好的选择。
