# 青山集团 — 未上市公司深度研究

> **研究日期**：2026年7月14日 | **与华友钴业的关系**：全球最大镍生产商，华友在印尼最大的竞争对手

---

## 一、公司概况

| 项目 | 内容 |
|------|------|
| 公司全称 | 青山控股集团有限公司（Tsingshan Holding Group） |
| 成立时间 | 1988年（温州起家） |
| 地位 | **全球最大不锈钢和镍生产商** |
| 创始人 | 项光达（2023年已去世，家族控股） |
| 上市状态 | **未上市** |
| 2025年镍产量 | 预计**超100万吨**（全球第一） |
| 印尼资产 | 青山工业园（IMIP、IWIP） |
| 中国资产 | 温州、福建、广东等不锈钢基地 |

---

## 二、青山 vs 华友：印尼镍矿的双雄对决

| 维度 | 青山集团 | 华友钴业 |
|------|------|------|
| 镍产能 | **100万吨+**（全球#1） | 18万吨→远期36万吨 |
| 业务模式 | 不锈钢+镍铁+新能源材料 | 镍钴锂→三元材料 |
| 上市与否 | ❌ 未上市 | ✅ 603799 |
| 在印尼的地位 | IMIP/IWIP园区主导者 | Pomalaa/Sorowako/华越 |
| 技术路线 | RKEF火法+HPAL湿法 | HPAL湿法为主 |
| 向下延伸 | 也开始做三元材料 | 到正极材料为止 |

**关键区别**：青山体量是华友的5倍+，但未上市无法投资。青山在印尼的话语权远超任何一家中国企业。

---

## 三、青山对华友的影响

| 维度 | 影响 |
|------|------|
| **竞争** | 青山也在建三元材料产能，直接竞争华友下游 |
| **定价权** | 青山增减产直接决定全球镍价——华友是"价格接受者" |
| **政策影响力** | 青山在印尼的政治关系网络远超华友 |
| **标杆效应** | 青山未上市→华友是A股最接近"青山"的替代标的 |

---

## 四、为什么青山不上市

1. **家族控制**——项光达家族不愿稀释控制权
2. **不需要融资**——镍矿本身就赚钱，现金流极强
3. **政商关系复杂**——上市需要披露的信息太多
4. **不锈钢+新能源双线并进**——业务复杂，IPO定价困难

---

## 五、对投资者的启示

| 结论 | 说明 |
|------|------|
| **买不到青山** | 但可以通过华友钴业间接参与印尼镍矿的长期趋势 |
| **华友的对手很强大** | 青山体量碾压华友，竞争格局不是"华友独大" |
| **关注青山动态** | 青山增产/减产→直接影响华友股价 |
| **如果青山IPO** | 将成为A股镍业第一股。届时华友的估值会被重估 |

---

> **结论**：青山集团是印尼镍矿的真正霸主，未上市。华友钴业是A股中体量最大、产业链最完整的"替代标的"。但要知道——华友在印尼的地位远远不及青山。
