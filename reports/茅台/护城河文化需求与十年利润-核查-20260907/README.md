# 核查范围与复算

对应报告：`贵州茅台护城河文化需求与十年利润研究报告-20260907.md`，资料截止 2026-09-07。

- `model.py` 调用项目 `financial_rigor.py` 完成七项来源核对及三情景计算，同时使用 Decimal 保存精确结果。项目 calc 当前内部先用浮点求值，本研究以独立 Decimal 结果为精度依据，没有修改共享工具。
- `calculations.json` 包含原始基期、来源 URL、所有假设、情景、敏感性及精确结果。
- `financial-rigor-output.txt` 是原始项目工具输出。
- `audit.py` 调用 `report_audit.py extract --seed 42`，保留抽样结果，并对事实、推导值和假设分别处理；同时校验全部情景输出表格与计算一致。
- `audit-extract.txt` 保留六项原始抽样。两项为历史事实，一项为从财报计算的比率，三项为前瞻假设。
- `audit-classified.json` 保留每个原始样本及分类。三项前瞻假设仅验证模型输入与正文相符，没有填造外部真实值。
- `audit-verdict.txt` 仅对两项事实及一项历史推导比率输出判决。工具自带的“可发布”文字仅限其实际核查范围，不代表六项全部被外部验证，更不代表未来利润或企业文化结论获审计背书。

来源核对的第三方平台报道依然源自公司披露，不能视为独立的财务审计。官网对改革成效的陈述与行业问卷都不是茅台终端开瓶量的完整统计。

未来利润使用 2025 年完整财年为基期，推算至 2036 年，共十一个增长期；研究时点到目标年份约十年。模型中的增长是区间等效年均值，未做逐年路径预测。没有主观概率权重，三情景也不是统计置信区间。
