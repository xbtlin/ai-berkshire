# 中国铝业未上市巨头研究

> **研究日期**：2026年7月16日 | **与云铝股份的关系**：竞争对手

---

## 一、中国宏桥（1378.HK，非A股）

| 项目 | 内容 |
|------|------|
| 地位 | **全球最大铝生产商** |
| 产能 | 646万吨电解铝（云铝308万吨的2倍） |
| 创始人 | 张波（张士平之子） |
| 上市地 | 香港（不在A股） |
| 商业模式 | 山东煤电铝 → 云南绿色铝（转型中） |
| 2025年营收 | 约1,274亿 |
| PE | ~6x(H股折价) |

**和云铝的关系**：
- 产能是云铝2倍，但碳排放更高
- 正在向云南转移产能（和云铝抢水电资源）
- H股PE仅6x，比云铝更便宜

---

## 二、信发集团（未上市）

| 项目 | 内容 |
|------|------|
| 地位 | 中国第二大民营铝企 |
| 产能 | 约400万吨电解铝 |
| 创始人 | 张学信家族 |
| 上市状态 | **从未上市** |
| 特点 | 极低成本+极高效率+极低调 |

**信发是铝行业最神秘的巨头。** 不缺钱、不上市、不披露——外界永远不知道它到底赚多少。

---

## 三、三者对比

| | 云铝股份 | 中国宏桥 | 信发集团 |
|------|:---:|:---:|:---:|

---

## 四、对云铝投资的启示

| 结论 | 说明 |
|------|------|
| **云铝不是最大** | 宏桥产能是云铝2倍 |
| **云铝是最"干净"的** | 绿色铝标签+ASI认证，三个中唯一 |
| **云铝是最安全的** | 负债率17.7% vs 宏桥50%+ |
| **宏桥更便宜** | H股PE 6x，但港股折价+碳风险 |

---

> **结论**：如果你想要"最便宜的铝"——买宏桥(H股PE 6x)。如果你想要"最干净的铝"——买云铝(绿色铝+ASI+PE 10x)。如果你想要"最大产能"——宏桥。云铝的差异化在于绿色溢价。
