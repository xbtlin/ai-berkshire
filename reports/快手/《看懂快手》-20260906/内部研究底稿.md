# 快手内部研究底稿

> 截止2026年9月6日；为三篇系列提供可反驳的研究结构，不作为单独投资建议。主业历史信息A级；可灵收入与交易条款B级，独立经济性与远期现金C级。信息充分程度与投资安全程度分别判断。

研究从两个冲突开始：用户仍增而当期利润下降；可灵商业收入迅速形成而集团资本支出明显上升。文章据此分成主业、AI变量、财务与行动三篇，没有预设“低倍数即低估”或“高融资估值即泡沫”的结论。

## 初始硬错误清单及最终处理

| 风险 | 最终处理 |
|---|---|
| GMV当收入 | 明确收入来自广告、佣金及其他服务，交易额不进入集团收入总额 |
| AI运行速度当全年收入 | 区分重组备考收入、季度已实现收入、运行速度和客户付款 |
| AI已并表却另加估值 | 集团DCF包含AI投入和现金，未再加可灵融资估值 |
| 调整后利润视作股东现金 | 单列IFRS归母、集团调整后利润及SBC经济成本代理 |
| TTM资本开支沿用去年全年 | 拒绝第三方错配值，按季度披露约数重建并标近似 |
| 现金全部等于超额资产 | 列金融资源、借款、租赁、用途限制；估值可分余额为显著折让假设 |
| 18.96%误作腾讯总经济持股 | B类分母与全公司分母分开；年报总经济权为15.71%，不是最新现时精确值 |

## 四种价值投资视角下的同一家公司

巴菲特视角关注广告与交易带来的经济性：内容关系能降低商家获客摩擦，规模能改善推荐和广告匹配。但定价权最终受商家净回报约束；平台若靠更高分成或补贴维持收入，流量规模不能保证现金回报。最需要观察的是稳定使用基础上，收入、毛利与租赁后现金的联动。

芒格视角先问怎样会亏钱：优质商家迁移，用户不走但可变现价值下降；模型效果提高但价格战把价值让给客户；重资产投入超过真实需求；把融资权利不同的新投资人价格当作普通股底价。反方不需要所有风险同时发生，某一项持续成立即可明显降低恢复情景价值。

段永平视角先判断是否看懂：谁付钱、为什么重复付钱，主业可以解释；可灵未来每元收入留下多少全成本现金，公开证据仍不够。因此能看懂一部分生意，不等于可以给全部公司同样高确定性。价格低时仍要问管理层是否愿意在项目回报不足时收缩，而不能只看管理层对技术的信心。

李录视角把权益与制度放入长期现金：A/B股经济权、投票权、子公司少数权益、融资回购条件和关联交易都会影响普通股最终得到什么。公司拥有资产与普通股东能无约束取得资产，是两层问题。腾讯同时持快手及参与可灵融资，也提示两家公司同时持有存在经济暴露重叠，不能把它们当作完全独立的风险来源。

## 三篇论文与可证伪条件

第一篇论文是：快手拥有真实内容关系网络，但护城河的商业价值必须通过商家回报持续兑现。若日活稳定、商家复购与净成交改善、平台利润和现金恢复，增强此判断；若推广投入上升、生态分成加重而现金回报持续下降，降低判断。

第二篇论文是：可灵已经证明有人愿意付费，还没有公开证明所有成本后的持续高回报。提高判断需要付费留存、净收入留存、单位交付成本、全成本利润和投资回报等证据。收入增长本身不足以证伪反方；公司可能同时成功扩大使用量并给资本带来平庸回报。

第三篇论文是：现价对基准恢复有折让，尚不构成保守资金无条件重仓的依据。若现金恢复快于模型、投入资本回报改善，估值可上调；若现金恢复失败，历史利润倍数的便宜不再有说服力。模型保守区间不是最坏损失边界，VIE、算力与合同尾部冲击未充分量化。

## 估值与价格纪律

十年DCF使用集团普通股归属现金，扣税、经营及增长投入、借款利息、租赁和股份薪酬经济成本，并考虑可灵少数权益；期间现金不由持续净新增借款支持，假设债务能够在安全杠杆下正常续存。另加剩余资产对应的利息、股息与投资分配排除于路径之外；不再次机械减借款本金或全部租赁负债。直接设定的现金情景没有完成逐项债务到期预算，资产加回也是独立审慎假设，而非精确逐项资产桥。保守、基准、乐观不配主观概率。基准首期30亿元，第十期170亿元，外加150亿元假设可分资产；这是一条恢复路径，不能称作已实现正常化利润。

8%—9%回报要求得到基准46.45—53.67港元；同一路径以10%和12%折现则为40.88和32.89港元。20%稳态增量ROIC是终值一致性假设，并非快手已实现ROIC。9%基准终值现值约占含可分资产的总股权价值53%，其分母不能与另一公司核心业务价值的终值比例直接比较。

现价33.66港元：保守资金观察；风险承受能力较高且理解AI不确定性的资金可小额分阶段研究。25港元以下加强重新核查，32港元以下且修复证据出现更有吸引力；所有价格线均依赖生意红线未破。仓位过度集中的持有人应优先处理单一公司风险。价格接近46—54港元但经营证据未修复时，应提高持有门槛；若可灵经济性真正改善，则重新建模。

## 尚未解决的研究缺口

没有取得可灵独立审计分部现金流、客户留存与全成本利润；没有把已用满认购上限等同全部资金到账；没有独立穿透所有金融资产限制、供应商融资与表外义务；未构造准确历史估值分位；未取得可逐条核对的五年管理层原始承诺清单，因此不编造兑现率或诚信评分。管理层执行能力有事实支持，新增AI资本回报仍待观察。

至少三家独立机构的公开研究内容用于观点对照，但当前时期完整原始研报覆盖不足：DBS为本期原文，招银本期公开译文存在单位错误，浦银国际为历史原始全文，光大为本期团队摘要，大和为新闻摘要。各自日期和文档等级在来源附录列明，不能把五个链接说成五份本期原始完整研报。

## 复核边界

已执行财务算术工具、Decimal复核、三篇自动抽样和额外重点事实核验。自动提取器主要识别表格，第一篇只误识别出目录序号，第二篇主要识别示例金额，因此额外补查最新收入、调整后利润、年度广告收入、可灵备考收入与亏损、条件权益。外部独立代理审读三篇，发现年度三项收入精度错误后已纠正为814.62、390.87、222.27亿元，合计1,427.76亿元；市值统一四舍五入至1,456.46亿港元。保留这些修订记录是为了明确核查作用，不代表不存在其他遗漏。
