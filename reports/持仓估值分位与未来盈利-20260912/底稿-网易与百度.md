正常化算式（亿元）：

```text
正常化A（剔除一次性项目，保留股权激励为经常性成本）
  = 公司非GAAP归母TTM − 股权激励TTM
  = 145.82 − 29.61 = 116.21
  非GAAP已剔除：减值161.90、公允价值损益、长期投资减值、遣散费、并购无形资产摊销；
  但非GAAP同时加回股权激励，研究上视为真实成本予以扣回。

正常化B（自下而上校核）
  = （集团经营利润TTM −73.91 + 减值加回 161.90）
    + 净利息收入年化 43.08（2026Q2净利息10.77×4）
    + 权益法投资收益年化 17.86（2026上半年8.93×2）
    − 15%所得税 22.34 + 少数股东分担亏损 约2
  = 128.59
  两法相差约12亿元，差异来自税率与利息年化口径；取约116–129亿元，主表写"约116"。

再剔除AI主动投入（假设）
  公司不披露自动驾驶、昆仑芯、文心基模预训练各自的亏损；管理层称AI云基础设施"利润与利润率同比双升"，
  萝卜快跑国内"单位经济已打平"。因此可剔除的主动投入只剩基模研发与芯片、海外出行扩张。
  研究假设税前30／40／60亿元，税后按85%计：
  正常化A + 30×0.85 = 141.7；+ 40×0.85 = 150.2；+ 60×0.85 = 167.2
  主表写"约140–170"，中值约150。此项仅在"投入可停而搜索不倒"的前提下成立；若停投AI即失去搜索入口，则不应加回。
```

反方提示：正常化A隐含在线营销仍以TTM水平贡献利润；若在线营销继续以每年两位数萎缩，四季后正常化利润会随之下移，这不是一次性项目能还原的。另一方面，百度核心非GAAP经营利润率已从2025年三季度的9%回升至2026年二季度的15%，AI云基础设施收入同比增50%，支持"减值后基数已清、经营利润在回升"的判断。

## 六、2036年度利润的业务驱动情景

统一公式沿用腾讯与拼多多底稿：**各业务收入基数×十年收入增长因子×2036年归母经济净利率，加常态利息及投资收益，减其他持续亏损。**净利率已负担持续研发、股权激励、足额折旧摊销、总部费用、税项与少数股东权益；不含公允价值变动、减值与汇兑。负净利率为无税盾净损失。两家均不披露分业务净利率，下列净利率均为研究假设。

### 6.1 网易

2026全年研究收入基数：游戏1,000亿元、有道60亿元、云音乐80亿元、创新及其他65亿元，参考2025全年（921/59/78/68）与2026上半年（507/28/40/32）规模，**不是把上半年机械翻倍**。2026净利校核：`1000*0.33+60*0.02+80*0.12+65*0.05+30=374.05`，与4.2节正常化利润约370亿元相符。

| 假设 | 悲观 | 基准 | 乐观 |
|---|---:|---:|---:|
| 游戏收入年增速 / 2036经济净利率 | 0% / 25% | 5% / 32% | 8% / 35% |
| 有道收入年增速 / 2036经济净利率 | 0% / 0% | 5% / 6% | 10% / 10% |
| 云音乐收入年增速 / 2036经济净利率 | 0% / 10% | 4% / 15% | 7% / 18% |
| 创新及其他收入年增速 / 2036经济净利率 | −2% / 0% | 3% / 5% | 6% / 8% |
| 常态税后净利息及投资收益 | 20 | 40 | 60 |
| 四项业务2036收入合计 | 1,193 | 1,932 | 2,588 |
| 2036经济归母净利润计算值 | 278.00 | 589.24 | 868.83 |
| 主表取整数 | **280** | **590** | **870** |

悲观是长青产品自然衰减、新品只够补缺口、海外未成第二曲线，且行业增速趋平后买量成本抬高压低净利率；基准要求长青产品维持、每两三年一款新爆品、海外占比继续上升，净利率与当前经营利润率减税后水平相当；乐观要求海外主机与PC市场打开、AI压低研发成本并提升毛利率。游戏净利率上限受版号、渠道分成与内容成本约束，35%已高于2025全年归母净利率30%。

```text
悲观 = 1000*1**10*0.25 + 60*1**10*0 + 80*1**10*0.10 + 65*0.98**10*0 + 20
基准 = 1000*1.05**10*0.32 + 60*1.05**10*0.06 + 80*1.04**10*0.15 + 65*1.03**10*0.05 + 40
乐观 = 1000*1.08**10*0.35 + 60*1.10**10*0.10 + 80*1.07**10*0.18 + 65*1.06**10*0.08 + 60
```

### 6.2 百度

2026全年研究收入基数：在线营销520亿元（2026上半年257亿元，下半年管理层预期继续承压）、智能云与其他AI（即非在线营销，含AI云基础设施、AI应用、萝卜快跑、昆仑芯外销）500亿元（上半年255亿元）；爱奇艺以归母绝对数单列。2026净利校核：`520*0.24+500*(-0.07)+0+40=129.8`，与4.1节正常化A至B（116–129亿元）相符；其中非在线营销−7%的净利率意味着AI云基础设施盈利被自动驾驶、芯片与基模投入抵消，这是研究推断，公司未披露。

| 假设 | 悲观 | 基准 | 乐观 |
|---|---:|---:|---:|
| 在线营销收入年增速 / 2036经济净利率 | −6% / 18% | −2% / 24% | 1% / 28% |
| 智能云与其他AI收入年增速 / 2036经济净利率 | 6% / 2% | 12% / 8% | 18% / 12% |
| 爱奇艺归母贡献 | −3 | 3 | 8 |
| 常态税后净利息及权益法收益 | 30 | 45 | 60 |
| 两项业务2036收入合计 | 1,176 | 1,978 | 3,191 |
| 2036经济归母净利润计算值 | 95.32 | 274.20 | 542.86 |
| 主表取整数 | **100** | **270** | **540** |

悲观是搜索广告被AI应用持续分流、十年再缩一半，云业务增速与行业持平但只能维持微利；基准要求广告在AI搜索变现后稳住于缓降、云业务增速略低于Omdia口径的行业增速且净利率升至8%（对应经营利润率约10%，仍低于头部云厂商）；乐观要求AI云成为国内前三、萝卜快跑海外规模化、昆仑芯外销放量，净利率12%。利息收益假设不按当前2,800亿元现金及投资的现有收益率永久外推，因为资本开支已使自由现金流转负。

```text
悲观 = 520*0.94**10*0.18 + 500*1.06**10*0.02 + (-3) + 30
基准 = 520*0.98**10*0.24 + 500*1.12**10*0.08 + 3 + 45
乐观 = 520*1.01**10*0.28 + 500*1.18**10*0.12 + 8 + 60
```

| 公司 | 可证伪观察项 | 推翻目前判断的方向 |
|---|---|---|
| 网易 | 合同负债走势、长青产品流水、新品上线后三个月留存、海外收入占比（若公司开始披露） | 合同负债连续下滑且新品不能补位，说明基准情景的5%增速过高 |
| 网易 | 有效税率是否稳定在25%附近 | 若预提股息税成为常态，正常化税率应从18%上调 |
| 百度 | 在线营销同比降幅是否收窄至个位数；AI搜索变现启动时点 | 连续再降两位数则悲观情景的−6%仍偏乐观 |
| 百度 | AI云基础设施利润率披露、资本开支与自由现金流、昆仑芯上市后独立财务数据 | 若云收入增长而核心经营利润率不升，说明净利率假设8%过高 |
