## 摘要

**一句话结论：核心业务全面超预期（收入+11%、广告+22%、毛利率58%创历史新高、递延收入+21%），但公司主动把单季自由现金流打成-138亿元换取AI基础设施——腾讯正式从"现金奶牛+回购机器"切换为"重投入换AI期权"模式。管理层给出"今明两年一次性投入、回报不及预期即封顶"的框架承诺，市场首日用ADR跌5.4%表达了不信任。**

| 判定项 | 结论 |
|--------|------|
| 财报 vs 预期 | 经营面超预期，现金流低于预期（"质量超预期的换挡季"） |
| 利润质量 | 高：无开发开支资本化、SBC占收入比降至3.2%、递延收入领先增长；IFRS净利+0.7%为会计噪音 |
| 长期持有逻辑 | 轻微削弱未破裂：股东回报率从2025年的50-60%降档至年化约35%且回购明示让位；AI回报可见性上升；护城河与经营质量指标全部健康（详见第九节） |
| 持仓行动 | 持有；Q3财报为下一个关键验证点；458港元（悲观情景支撑，测算见第八节）以下值得评估加仓 |

## 三、AI专题：投入与回报的完整账本

### 3.1 投入侧：钱花在哪、花多少

| 项目 | 数据 |
|------|------|
| 资本开支 | Q2 527.8亿（+176%）；上半年847.2亿（+82%，超2025全年）；Q3继续"大幅增加算力采购"（马化腾） |
| 算力预付款 | 单季约514亿（FCF两口径之差）；非流动预付款余额912亿（年初245亿） |
| 研发开支 | Q2 272.8亿（+35%）；上半年498.2亿；一般及行政费用+22%至388亿 |
| **新AI产品经营拖累** | **Q1 88亿 → Q2 105亿**（=剔除口径861亿-实际756亿；范围：混元、元宝、CodeBuddy、WorkBuddy、小微） |
| 全年资本开支指引 | **拒绝给出具体数字**；绩前卖方预估：大和1,810亿（自1,080亿上调）、美银1,850亿（2027/2028年2,250/2,500亿）、摩根大通2,000亿 |

管理层的三条框架承诺（刘炽平，电话会实录原文）：

> "投向AI原生业务的资本开支，主要是今年和明年一次性集中投入，大家不要默认我们每年都会维持同等大额投入。模型训练属于固定成本……只有该业务能实现可观回报，我们才会持续追加投入；如果回报不及预期，现有投入规模就会封顶。"

即：**时限**（2026-2027集中投入）、**封顶**（AI新产品投入"控制在集团利润固定比例区间内"，未给比例）、**挂钩**（新增开支对应收益水平）。105亿投入的内部结构在动态腾挪——Mitchell披露：发现WorkBuddy爆发后"把资金大幅向它倾斜，同时缩减AI产品线里其他产品的投放预算"。

**正反两面**：框架比数字信息量更大（数字每季可改，框架是把话说死）；但三条全是无法当期验证的远期承诺，"固定比例""可观回报"均无量化标准，验证权在管理层手中。行业内尚无巨头兑现过"AI投入是一次性的"先例。

### 3.2 回报侧：已兑现、兑现中、纯期权三层

**第一层——已兑现（老业务赋能）**：广告+22%连续三季加速（AI推荐系统参数扩容、素材效率+80%）；毛利率57.8%创新高——AI基建折旧翻倍（技术基础设施运营成本+102%）被高毛利收入增长完全消化；游戏侧《和平精英》AI NPC累计体验用户1.67亿、最高日活1,770万，《洛克王国：世界》AI教练上线后PVP激活率+20%。

**第二层——兑现中（云与token变现）**：云收入增速从Q1"高十位数"加速至Q2"20%出头"（GPU租赁、模型即服务、WorkBuddy/CodeBuddy token用量三路驱动）；排期明确——"年底至明年将有足够GPU/ASIC产能，加大裸金属GPU对外出租"（Mitchell）。上季"有意推迟云AI变现"的口径正式转向。token经济学（Mitchell）："国内令牌定价确实偏低，但底层生产成本也极低……即便终端售价低廉，令牌业务依旧能实现正向毛利"；WorkBuddy付费部分与模型即服务的毛利率"已经和腾讯云整体毛利率持平"。

**第三层——纯期权（AI原生产品）**：
- **混元**：Hy3正式版7月发布，上线一周调用量较上代+68倍，日均token用量为预览版的约6倍（英文实录口径；部分中文报道为7倍），按OpenRouter token消耗持续位列全球前三；WorkBuddy内用户模型选择占比60%；**Hy4年内发布**，定位"参数量全面提升、性能超越更大规格竞品"。
- **WorkBuddy**：PC端6月访问量2,097万次居国内同类第一，落地50+行业，接入Hy3后任务解决率72%→90%，企业版已发布，"订阅和充值购买词元的付费意愿强烈"。
- **CodeBuddy**：AI编程工具月访问量前10中腾讯占4席。
- **小微（微信AI）**：6月启动灰度，覆盖16个高频场景；年度投入预算"低于往年元宝的常态化投入"。刘炽平的终局叙事："未来用户只需给专属智能体下达一条复杂指令，智能体就能自动完成全部交易流程……商户智能体可以直接和用户智能体对接"；"电脑时代QQ只是社交通讯工具，微信生态把QQ价值放大了十倍以上……AI时代，微信生态迎来第二次巨大增长机遇"。
- **元宝**：连续第二个季度未披露用户数据（2026Q1为MAU 5,700万，对比豆包3.4亿），战略定位已降为向WorkBuddy/微信等输出的"原子能力"。

**反面必须记录（观点）**：① 第三层目前无任何收入/用户量硬数据支撑，"十倍放大"是愿景类比不是指引；② 被问"AI智能体会否挤压广告与交易"时刘炽平答"这些风险都不会出现"——全场唯一把不确定性说成确定性的回答；③ 微信AI当前是纯叙事资产，需等小微出灰度后的用户数据。

### 3.3 下行保护：管理层的"保底方案"论证

刘炽平在11个问答中三次主动重复同一论证：

> "哪怕停止自研应用，单纯把算力对外租赁，相关业务本身就能盈利，因此我们敢于长期投入。"
> "几个月前预付定金下单的一批算力设备，现在转手出售，相比采购价能赚超30%。"

Mitchell同口径："若把算力全部租给第三方，几乎立刻就能收回设备折旧成本"，但腾讯选择自用优先换取"更长期更优的经济回报"。

**正反两面（观点）**：算力残值论证当下成立——GPU供不应求下设备转手溢价30%，"最坏情况变出租生意"的下行保护是真实的。但一个管理层反复强调"我们有保底"，恰说明他们清楚这笔投入的不确定性；且30%溢价是当前供需快照，保底逻辑的有效期与GPU短缺周期同长，不应作为长期安全边际。另注意口径陷阱：新浪实录标题《不准备出租算力》与正文矛盾，管理层真实排序是"先自研模型与应用、剩余算力再对外出租"——出租是第二优先级与保底，不是不做。

## 十、结论

1. **超预期还是低于预期？** 经营面超预期（收入+1%、广告大超、毛利率新高、递延+21%），现金流低于预期（资本开支超预期64%、FCF转负）。定性："质量超预期的换挡季"。
2. **这份财报+电话会改变了什么？** 三件事：① AI投入从"看不到底的开支"变为"有时限、有上限、有保底的投资"（管理层框架自洽但当期不可验证）；② 回购正式让位于资本开支——"回购机器"叙事终结；③ 云AI变现路径首次清晰（增速加速+年底出租排期+token正毛利证据）。
3. **持仓行动：持有。** 不加仓：资本开支高峰未过（912亿预付款在路上、Q3继续大采购）、FCF拐点未现、卖方下修周期未走完。不减仓：七个持有前提仅一条失效且属资本配置选择而非经营恶化、八项恶化信号零触发、核心生意（剔AI利润+19%）在变好、现价已贴悲观情景支撑。
4. **Q3财报为下一个关键验证点，盯三个硬指标**：① AI新产品拖累是否稳在105亿量级（封顶承诺第一次检验）；② 云收入增速是否续升（变现承诺检验）；③ 下半年回购节奏（让位声明落地程度）。辅助观察：国际游戏止跌与否、小微灰度数据、混元4发布及评测、绩后卖方目标价修正幅度。
5. **价格纪律**：458港元（悲观情景支撑，测算见第八节）以下属加仓评估区而非止损区——前提是第九节八项恶化信号继续零触发；股价接近中性情景目标（约780港元）时再评估部分止盈。
