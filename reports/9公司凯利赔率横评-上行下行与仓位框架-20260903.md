# 九公司凯利赔率横评：上行、下行与仓位框架

**编制日：2026-09-03 | 数据基准：各标的2026年8月下旬收盘，逐项标注 | 汇率：1 HKD = 0.8573 CNY，1 USD = 7.8 HKD / 7.1 CNY**

**一句话结论：九家中八家的凯利公式输出为正且全部指向满仓加杠杆（0.31～4.56），唯一的负值出现在估值透支的标的上（−1.58）。这组分布本身就是结论——凯利的数值不可用，符号可用。真正能拉开标的差距的不是期望回报，而是下行深度与路径是否内生。**

---

## 零、方法与它的边界

本文对九家公司套用同一套框架：四档情景赔率表 → 期望回报 → 凯利公式 → 敏感性测试 → 年化折算 → 路径判定。

**凯利公式在股票上的正确用法是取符号，不是取数值。** 原因在实测中很清楚：它把"浅下行"直接翻译成"高杠杆"，而浅下行恰恰是所有输入里最不可靠的一个——尤其当下行是被现金或净资产托住的时候。九次计算里八次给出100%以上的仓位建议，这不构成可执行的结论。

**负值则是可执行的**：它意味着在当前价格上，无论对这家公司的判断多正面，赔率结构都不支持买入。

**全文概率分配均为主观判断**，这是整套方法最薄弱的一环。读者应代入自己的概率重算，而非直接采用。

## 二、四个跨标的规律

**规律一：凯利排序与期望排序不一致，因为凯利被下行深度主导。**

```
期望排序：拼多多 > 美团 > 腾讯 > 快手 > 泡泡玛特 > MiniMax > 茅台 > 讯飞 > 寒武纪
凯利排序：拼多多 > 腾讯 > 茅台 > 美团 > 快手 > 泡泡玛特 > 讯飞 > MiniMax > 寒武纪
```

两组对照最能说明问题：**茅台期望仅+13.4%，凯利排第三（2.17），因为下行只有−36%；MiniMax期望+17.2%高于茅台，凯利却只有0.31，因为下行是−85%。** 上行+199%这个数字在凯利公式里几乎不值钱——它被85%的下行吃光了。

**规律二：赔率比比期望值更能分辨标的。**

九家中七家的赔率比挤在1.8～2.8，能拉开差距的只有两头：一头是厚现金压住下行（拼多多−19%），一头是估值透支放大下行（寒武纪上行仅+35%、下行−85%）。

**规律三：九家中只有两家是内生路径。**

腾讯与茅台——不需要第三方点头，继续经营即可走到目的地。**其余七家的关键变量都握在别人手里**：美团看竞争对手是否维持停战、快手看投资者是否同意上市、拼多多看各国关税政策、泡泡玛特看消费者对IP的偏好、MiniMax看AI应用市场成熟速度、寒武纪与科大讯飞看行业周期。

这解释了一个反直觉的结论：**腾讯期望值只排第三，却应获得最高权重——它是少数"判断对了就一定能兑现"的标的。**

**规律四：唯一的负凯利，出现在唯一一个上行小于下行的标的上。**

寒武纪按券商预测的2028年净利138.75亿、给40倍市盈率，对应市值5,550亿，**低于当前6,502亿市值**。这不是"贵一点"的问题——当前价格已把最乐观的预测吃掉之后还倒欠。

## 三、快手：分部折价加期权（重点展开）

快手是九家中结构最复杂、也是唯一需要逐条核对一手法律文件的标的。本节结论均由港交所公告原文重算，相关三份底稿见文末。

### 3.1 分部加总

基准：2026-08-24 收盘 33.02 港元、市值 1,428.7 亿港元（43.3 亿股）

```
净现金        939.4 亿人民币 ≈ 1,095.7 亿港元
              （可动用资金1,213亿 − 有息借款273.62亿，一手核算）
可灵 68.33% 股权   名义 959.4 亿港元（投后180亿美元×7.8×68.33%）
主业经调整净利      239 亿港元（剔除可灵亏损后约205亿人民币）
```

**关键修正一：可灵这个减数应下修。** 投资者持有的是带回购保护的股权（回购金额＝原始投资价格＋年化8%单利，且可灵集团承担连带责任），不是普通股。经核对公告，本轮认购的是北京可灵的**注册资本**，全文**未见优先清算权、棘轮条款、反稀释安排或IPO定价下限**。因此不宜套用优先股与普通股20%–40%的典型价差，**合理折让区间为15%–25%**：

| | 原口径 | 调整后 |
|---|---:|---:|
| 可灵普通股口径整体估值 | 180亿美元 | **135–153亿美元** |
| 快手 68.33% 对应 | 959.4亿港元 | **719–815亿港元** |
| 相对市值的隐含折价 | 56% | **53%–54%** |

折价依然巨大，但**"主业隐含估值为负"这个流传的说法，在普通股口径下不成立**。

### 3.2 赌赢的真实门槛是280亿美元，不是180亿美元

这是本次分析中最关键的一个数字，它推翻了"IPO按一级市场价定价即算赢"的直觉。

```
投资人投入            30 亿美元，取得投后 16.67%
五年后回购可得        30 × (1 + 8% × 5) = 42 亿美元
IPO 后持股（稀释后）   约 15%

IPO 优于回购的条件：   持股价值 > 42 亿美元
                       42 ÷ 15% ≈ 280 亿美元
```

**该门槛具备执行力**，因为股东协议载明：

> 持有超過 50% 認購金額的投資者就北京可靈及其控制實體的若干重大事宜擁有慣常同意權。

首次公开发售几乎必然属于需要投资者同意的重大事项。**若届时市场仅给出100–150亿美元定价，投资者具备否决IPO、等待死线行使回购权的动机与工具。** 那种情形下快手将同时承受两件事：拿出约42亿美元（约330亿港元）现金履行连带责任，以及可灵估值锚归零重来。

**因此"IPO按180亿美元定价"不是赌赢，而是触发回购博弈的灰色地带。**

### 3.4 三条死线（全部来自公告原文）

| 死线 | 日期 | 未达成的后果 |
|---|---|---|
| 增资交割 | **2026-12-29**（签署起180天） | 减数由资产退回为合同，全部推演失效 |
| 牌照三项 | **约2027年年中**（最迟付款日起九个月） | 触发回购权——唯一同时打击资产端与负债端的事件 |
| 上市 | **最迟上市日期或2031-10-30，以较早者为准** | 触发回购权 |

**"最迟上市日期"是独立定义的日期，公告释义章节未予披露。** 条款为两者取较早，故真实死线可能明显早于2031-10-30，本文按2031年折算的年化数据属偏乐观口径。

牌照三项为：完成收购海外运营公司100%股权、取得增值电信业务经营许可证、完成AI大模型及／或算法备案。**三项均为行政审批，不完全由公司控制。**

另需注意：递表本身不解除回购权。公告载明，即使在最迟上市日期前已递交申请，若出现递表后12个月内未完成发行、申请失效未及时重提、被拒或主动撤回，回购权照样复活。

### 3.5 时间对回报的稀释

```
+117% 兑现于 3 年    → 年化 29.3%
+117% 兑现于 5.3 年  → 年化 15.9%    （按2031-10-30死线）
+78%  兑现于 5 年    → 年化 12.2%
```

**同一判断，兑现时点从3年推到5.3年，年化折损接近一半。** 这是快手与内生路径标的最本质的差别——腾讯的回报来自每日发生的利润复利，快手的回报押在一个日期未定、还需第三方点头的单点事件上。

## 四、其余八家要点

**腾讯**（约450港元／市值约3.52万亿人民币）：核心业务剔除上市投资4,872亿后隐含市盈率10.4–11.8倍。Q2资本开支527.8亿（+176%），AI对利润拖累约105亿；**剔除新AI产品影响后Non-IFRS经营利润+19%至861亿**，含AI则为+9%。九家中路径可靠性最高。风险为AI投入回报节奏与回购规模缩减（已明确2026年减少回购转投AI）。

**拼多多**（$82.39／约8,321亿人民币）：Q2营收1,123.6亿（+8%）、归母净利272亿（−12%）、**经营现金流257亿（+19%）**——利润与现金流背离，说明下滑主要来自费用化投入。现金及短期投资4,361亿占市值52%。**Temu的收入与亏损从不单列**，四档情景中关于Temu的假设全部为外推。已发生的政策冲击：美国2026年5月起关闭中国直发通道，欧盟7月起每件征3欧元。

**美团**（78.05港元／约3,991亿人民币）：**2026 Q2市场份额美团43%、淘宝闪购42%、京东15%**——曾经70%以上的份额垄断已被追平至只剩1个百分点领先，**正常化利润不可能回到2024年的437.7亿**。但停战信号明确：七月三家达成五项共识、京东表示2026年投入下降、经营亏损从161亿（2025Q4）收窄至65亿（2026Q1）。

**泡泡玛特**（148.80港元／1,982亿港元）：H1营收171.73亿（+23.76%）与净利50.38亿（+10.14%）均低于市场预估（199.8亿／66.4亿）。**海外收入49.72亿同比−11.6%**（亚太−9.7%、美洲−16.5%），中国区+47.3%。**存货周转天数由2025全年123天升至半年度201天**，CEO在业绩会上表示今年大概率完不成20%营收增长目标。

**MiniMax**（市值134亿美元）：ARR轨迹为2026年2月1.5亿美元 → 5月3亿 → **8月8亿美元**；H1营收1.17亿美元（+283.1%），企业AI服务收入+703.1%。**当前市值/ARR ≈ 16.75倍**，与全球头部AI公司持平，非低估。关键反向证据：**7月Token消耗量为1月的20倍，而收入仅增3.83倍，隐含单位Token价格下降约81%。**

**茅台**（1,292.56元／1.62万亿）：2025年为上市以来首次营收净利双下滑（净利823.2亿，−4.53%），2026 Q2净利−6.9%。分红率79%、股息率约4%。**年化4.3%中，几乎全部来自股息。**

**科大讯飞**（41.35元／993亿）：H1营收116.23亿（+6.52%），归母净利−2.04亿，**扣非净利−6.37亿、亏损同比扩大74.88%**。境外营收+160%、合同额+27%为亮点。核心问题不在数字：成立二十余年至今扣非未盈利。

**寒武纪**（1,035元／6,502亿）：H1营收59.96亿（+108%）、归母净利23.11亿（+122.6%），增长确实强劲。但按当前市值折算，券商预测的2026/2027/2028年净利对应市盈率为132/74/47倍。**存货82.48亿占期末总资产45.32%（+66.83%）、预付款+291.37%**——总资产的45%押在存货上，是高杠杆的产能赌注。

## 五、三档分类与组合框架

**可考虑（凯利>1 且年化>9%）**：拼多多、腾讯、美团、快手、泡泡玛特

**不占位置（年化<6%）**：茅台（回报几乎等于4%股息）、科大讯飞（二十余年未盈利）、MiniMax（定价已合理，赌ARR能否再翻倍）

**明确排除**：寒武纪（期望为负，凯利为负）

**若组合仅有三个位置，一个可论证的分配是：**

```
腾讯   45%    唯一内生路径 + 可靠性最高
拼多多 30%    赔率比6.5最优，且是唯一不属同一生态的标的
美团   25%    期望第二，拐点可按季度验证

组合三年期望 ≈ +41.7%  →  年化 12.3%
```

**一个必须写明的结构性问题**：腾讯是美团与快手的大股东。同时持有这三家，实际分散度接近1.3只股票——真正的分散需要至少一个不属于该生态的标的，这也是拼多多在此框架中的独特价值。

**权重敏感度极低**：当各标的期望值集中在30%–50%区间时，权重从35%调到20%对组合期望的影响不足0.1个百分点。**选谁进组合，比给多少权重重要得多。**

## 七、方法论：本次两处翻车与修正

记录在此，因为错误本身比结论更有复用价值。

**翻车一：用上一财年确认收入给超高增长标的做基数。**

```
使用：MiniMax 2025财年收入 7,903.8万美元
实际：2026年8月 ARR 已达 8亿美元（约10倍）
后果：把公司当年就已越过的水平，当成了三年后的乐观情形
```

**修正规则：当同比增速超过100%时，财年确认收入已经失效，必须换成最新运行率，并在输出中注明基数口径。**

**翻车二：用估算市值往下推演三层结论。**

```
第一次修正后（收入基数填对、市值仍用估算）→ 期望 +160%，f* = 2.25
市值填对（134亿美元）后              → 期望 +17.2%，f* = 0.31
该标的在九家中的排序：从最好变为倒数第二 —— 基本面数据一个字未改
```

**修正规则：市值不接受估算。** 它是所有输入中最易获得的一个，同时是唯一同时决定上行空间与下行深度的一个。**在输出中标注"此项为估算、待核实"不能代替核实**——带着估算值往下推三层，等于在沙地上盖三层楼。

**两次错误方向相反**（一次过度悲观、一次过度乐观），说明单个基础数字的错误可以把结论推向任意方向。**因此基础数据的核实优先级，高于分析框架的精巧程度。**
