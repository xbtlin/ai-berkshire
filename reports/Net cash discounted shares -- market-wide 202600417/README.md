#1. Screening methods

##1.1 Strict caliber (used in this report)
```
Net cash = monetary funds + transactional financial assets + other short-term investments - interest-bearing liabilities (short-term and long-term borrowing + bonds payable)
Screening: net cash * Current total market value
```

##1.2 Wide-calibre (partial data source use, distinction noted in this report)
```
NCAV (Net Current Assets of Graham) = Current Assets - Total Liabilities
Screening: NCAV market value (including non-cash-flow assets, such as receivables/inventory, broader calibre)
```
