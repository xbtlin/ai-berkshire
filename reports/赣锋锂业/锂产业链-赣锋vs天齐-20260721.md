# 锂产业链全景：赣锋 vs 天齐

> **研究日期**：2026年7月21日

---

## 一、"锂矿双雄"对比

| | 赣锋锂业 | 天齐锂业 |
|------|:---:|:---:|
| 代码 | 002460 | 002466 |
| 模式 | **全产业链** | **资源为王** |
| 核心资产 | 1亿吨LCE(全球分散) | Greenbushes+SQM |
| 锂盐产能 | 28万吨 | 较低 |
| 电池业务 | ✅ 有 | ❌ 无 |
| 固态电池 | ✅ 布局 | ❌ 无 |
| 抗周期能力 | 🟢 更强(分散) | 🟡 更弱(集中) |
| 周期弹性 | 🟡 中等 | 🔴 极大 |
| PE(2026E) | ~10x | ~11x |

## 二、选谁

| 如果你 | 选 |

## 三、锂产业链利润分配

```
锂矿(赣锋/天齐) → 锂盐加工 → 正极材料(华友) → 电池(宁德) → 整车(比亚迪)
   毛利30-60%      毛利15-25%    毛利10-20%     毛利20-30%   毛利18-22%
```

**利润最厚的是上游锂矿——赣锋和天齐都在这里。** 但锂价周期让利润剧烈波动。

---

> **结论**：如果必须选一只锂矿股——赣锋是全产业链龙头，天齐是纯资源弹性。治理上两家都可以接受（不像融捷）。PE都~10x，都便宜。
