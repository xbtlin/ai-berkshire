二、被推翻的论断（详细）

2.1 论断一：「回购腰斩 = 论文破产」—— 推翻

看空报告第 5.2 节的核心指控：

🔴 从 FY25 的 $84 亿到 FY27 指引的 $50 亿，回购规模腰斩 41%。

这个指控用错了计量单位。

回购创造价值的机制是注销股份，不是花掉美元。同样一笔美元，在股价越低时买到越多股。Prosus 股价过去 12 个月跌了 28.6%——用美元衡量回购，等于用一把在缩短的尺子量东西。

换成正确的单位：公司官网股本时序表（一手数据）

期间 期初净 N 股（千股） 期末净 N 股 年化注销率
FY2025（2024-03-31 → 2025-03-31） 2,494,181 2,280,206 8.58%
FY2026（2025-03-31 → 2026-03-31） 2,280,206 2,145,428 5.91%
FY2027 实测（2026-03-31 → 2026-08-07，129 天） 2,145,428 2,105,025 5.33%（年化）

验算（financial_rigor.py）：

(2494181-2280206)/2494181*100 = 8.58
(2280206-2145428)/2280206*100 = 5.91
((2145428-2105025)/129*365)/2145428*100 = 5.33

三个必须说清楚的结论：

（1）FY26→FY27 的减速是 -9.8%，不是 -41%。 5.91% → 5.33%。看空报告把一个 10% 的减速讲成了"腰斩"。

（2）$50 亿指引不是"未来的削减"，是"当下正在发生的实况"。 年化注销 114,319 千股 × €37.395 = €4.27bn = $4.97bn——与 CFO 说的 "$5bn" 几乎精确吻合。也就是说，指引已经在执行中，市场已经看到了它的效果，而当前的 38.29% 折价已经包含了这个速率。 这不是"未来会变坏"，这是"现在就是这样，而现在就是 38% 折价"。

（3）$50 亿在当前市值下是 5.46% 的年化回购率。 对照：标普 500 的平均回购收益率约 2%，腾讯自身 2026 年约 1.5–2%。Prosus 减速之后的回购强度，仍是全球上市公司中的顶格水平。

一个看空报告没有意识到的凸性

回购增厚率的公式是 a = f·d/(1−f)，其中 f 是注销比例、d 是折价。在美元金额固定时，折价越阔，同样的钱买到的股份占比 f 越高，增厚率 a 越高。

折价 d $50 亿对应的 f 每股 NAV 年增厚 a
30% 4.81% 1.52%
38.29%（当前） 5.46% 2.21%
45% 6.12% 2.93%
51%（2022 峰值） 6.87% 3.76%

这意味着回购机器是一个负反馈系统：折价越走阔，机器创造价值越快。 看空报告的三情景模型把增厚率设成"乐观 3% / 中性 2.5% / 悲观 1.5%"——符号完全反了。悲观情景（折价 45%）对应的真实增厚率是 2.93%，不是 1.5%。

这是看空报告估值模型中唯一一处实质性建模错误。修正它之后（第七章），悲观情景目标价从 €30.28 上修到 €31.17。

我承认的部分

  • 减速本身是真的。8.58% → 5.33% 是 -38% 的真实减速，只不过它发生在 FY25→FY26，不是 FY26→FY27。
  • 减速的原因是资产负债表：净现金 +$19 亿 → 净债务 -$64 亿。这个约束是硬的（见 5.3）。
  • $5bn 是 CFO 口头指引，历史上 Prosus 有超额执行的记录，但我无法验证 FY27 是否会超额。这是需要每周跟踪的。

2.2 论断二：「这是套利不是投资」—— 推翻

看空报告 7.7 节的判词：

"它不是'买入并持有一家好公司'，它是'买入一个折价并等待折价收敛'。前者是投资，后者是套利。"

这句话的前提是：折价不收敛，你就不赚钱。这个前提是错的。

数学证明：折价恒定时，每股 NAV 仍在复利

设当前每股 NAV = n，股价 = P，折价 d = 1 − P/n。公司用现金回购并注销 f 比例的股份：

回购后每股 NAV = (n − f·P) / (1 − f)
增厚率 a = f·(n−P) / [n·(1−f)] = f·d / (1−f)

当前：f = 5.33%，d = 38.29% → a = 2.16%/年。

这个 2.16% 不需要折价发生任何变化就能拿到。 它是把"别人愿意用 62 分买你 1 块钱资产"这件事，转化成永久的每股价值。

压力测试：把所有多头假设全部关掉

情景（5 年） 假设 Prosus 回报
地狱情景 折价永久锁死 38.29%，全部资产零回报（腾讯 5 年不动、非腾讯 5 年不动） +11.3%（2.16%/年）
基础情景 折价永久锁死 38.29%，腾讯 +8%/年、非腾讯 +10%/年 +66.9%
同期直接持有腾讯 腾讯 +8%/年 +46.9%

验算：

(60.60*(1.0216**5)*0.6171/37.395-1)*100 = 11.28    # 地狱情景
(60.60*(1.0845**5)*(1.0216**5)*0.6171/37.395-1)*100 = 66.94
(1.08**5-1)*100 = 46.93

在"折价一分钱都不收敛"的假设下，Prosus 5 年跑赢腾讯 20 个百分点。 拆解：回购增厚贡献 16.9pp，非腾讯资产的超额回报贡献 3.4pp。

这就是"套利 vs 投资"之争的答案：套利需要价差收敛才兑现，而 Prosus 的核心回报来源在价差永不收敛时依然兑现。按定义，这是投资。

一个更硬的版本：即使非腾讯资产全部归零

看空报告的 1.5 节做过"非上市资产归零"的压力测试，但它只算了静态的地板折价（20%），没有算这个地板在回购下的动态演进。

假设所有非上市资产（$328 亿）+ 所有非腾讯上市资产（$76 亿）全部归零，只剩腾讯 - 净债务：

  • 每股净腾讯价值 = €46.92 − €2.82 = €44.10
  • 现价 €37.395 仍低于它 15.2%
  • 回购增厚（全部靠卖腾讯出资）：(44.10 − 0.0533×37.395)/(1−0.0533) = €44.48 → +0.86%/年

绝对地板：即使 Prosus 手里除了腾讯什么都没有、还倒欠 69 亿美元，回购依然以 +0.86%/年 的速度增厚你的腾讯敞口，而且这笔钱全部来自卖腾讯本身。

原理很简单：卖 €37.395 的腾讯，注销掉一份索取 €44.10 腾讯的股权。只要股价低于每股腾讯价值，卖腾讯回购自己就是净增持腾讯。

这一条看空报告完全没有触及。 它在 1.3 节算出了 €37.55 < €46.92 这个不等式，然后在 5.2 节算了回购，但从未把两者连起来。

关于"段永平买网易"这个类比

2.3 论断三：「市场给非腾讯资产 -160 亿美元估值」—— 推翻（作为"市场判断"的读法）

看空报告 1.4 节称这是"本报告最重要的单一数字"：

市值 $91.95bn − 腾讯 $114.90bn + 净债务 $6.90bn = -$16.05bn

（按 €37.395 重算为 -$16.43bn，2105.9e6*37.395/0.86/1e9-114.9+6.9 = -16.43）

这个数字在算术上正确，在推理上是伪像。

为什么是伪像

这个减法隐含了一个从未被声明的假设：Prosus 持有的腾讯股票，应该按 100% 市场价计入 Prosus 的价值。

这个假设站不住：

  1. 22.66% 的战略持股不是流通股。 它在任何交易中都会承受 blockage discount。Prosus 自己四年来卖出 $68.7 亿腾讯，都是通过大宗折价完成的。
  2. 所有控股公司对上市持股都有折价。 Investor AB 折价 15–30%，Exor 类似，软银 40–60%。这个折价适用于全部资产，不是"上市部分零折价、非上市部分负估值"。
  3. 反证：如果把 -$16.43bn 反过来算——假设非腾讯资产真值 0，那么市场对腾讯持股的折价就是 1 − (91.57+6.9)/114.9 = 14.3%。14.3% 恰好落在战略持股折价的常规区间内。 也就是说，同一个市值可以完全用"腾讯持股打 14% 折 + 非腾讯资产值 0"解释，也可以用"腾讯打 0 折 + 非腾讯值 -164 亿"解释。看空报告选了后者，并称之为"市场认为它倒欠 160 亿"——这是把一个分配自由度当成了市场的意见。

一句话：-$164 亿不是市场说的，是这个减法说的。

问题一：上行 Beta 从未被测量

看空报告的原话是"它在牛市里给你 0.77 的 Beta，在熊市里给你 1.19 的 Beta"。

0.77 不是测量值，是结构假设（腾讯占 NAV 77.4% 推出来的）。整份报告只测了一个下跌窗口。一个只观察了下跌的样本，不能得出"上涨时会怎样"的结论。

2022-06 → 2024-03 是天然的对照窗口。公司自己披露（看空报告 5.2 节引用）：

但我也承认一条重要的反向证据（关联腾讯报告 §8.3 提出，看空报告没有）：腾讯 2026 年进入重资本 AI 投入期 → 新兴市场风险偏好下降 → 控股公司折价同步走阔。这条宏观共因是真的，只是它解释的是相关性的一部分，不是全部。

5.1 「腾讯自身回购抬升 Prosus 持股比例」被错误计入超额收益

六、核心问题一：在什么条件下 Prosus 优于直接持有腾讯？

这是任务要求的"可证伪条件"。我给一个单一变量、每周可验证的答案。

6.1 推导

设： - d0 = 买入时折价 = 38.29% - d1 = 卖出时折价（唯一未知数） - a = 每股 NAV 年增厚率 = 2.16%（当前实测参数） - 假设非腾讯资产回报 = 腾讯回报（中性假设，剔除资产选择的影响）

则 Prosus 与腾讯的终期财富比：

Prosus / 腾讯 = (1+a)^n × (1−d1) / (1−d0)

令其 = 1，解出盈亏平衡退出折价：

d1_max = 1 − (1−d0) / (1+a)^n

6.2 结果：一张可以贴在屏幕上的表

持有期 盈亏平衡退出折价 d1_max 相对当前 38.29% 的缓冲
1 年 39.59% +1.30pp
3 年 42.12% +3.83pp
5 年 44.54% +6.25pp
10 年 50.16% +11.87pp

验算：(1-(1-0.3829)/(1.0216**n))*100

6.3 可证伪条件（这就是答案）

持有 3 年，Prosus 优于腾讯的充分条件是：退出时折价 < 42.1%。

持有 5 年：< 44.5%。持有 10 年：< 50.2%——即历史最阔水位。

注意这个条件里没有出现"折价收敛"四个字。折价可以走阔，只要走阔幅度小于阈值，Prosus 依然赢。

参照系： - 历史区间：30% – 51%（2022-06 峰值 51%，2024-03 谷值 30%） - 当前：38.29% - 2026-03（今年最阔）：约 42%（第三方口径）/ 42.8%（公司 FY26 年报口径）

⚠️ 对多头不利的一条：42% 在 2026 年 3 月刚刚被触及过。3 年的盈亏平衡线 42.12% 不是一个遥远的水位，是五个月前的实际水位。这是这个论文最薄的地方，我不掩饰。

  • 折价停在 38.29% 不动：依然赢腾讯 20pp（5 年）
  • 折价走阔到 42%：打平

8.2 联合概率与我的裁决

四个一票否决项中，V1/V2/V3 是可估的：

0.75 × 0.80 × 0.60 = 36%

但这个乘法是错的，因为它们不独立（V3 失败通常伴随 V2 失败；V1 与 L1 高度相关）。取相关性后我的估计约为 40–45%。

再叠加 L1（折价 <42.1%）：约 30–35% 的概率"一切按多头假设走"。

8.3 我的裁决：>10% 仓位在一种情况下成立，另一种情况下不成立

❌ 不成立：作为独立新增的仓位

10% 的独立仓位要求上述条件的联合成立，概率约 30–35%。对一个 30–35% 概率的事件下 10% 以上的组合权重，不符合任何合理的凯利比例。

而且看空报告有一条我完全同意：这是一笔中国互联网仓位，不是欧洲仓位。 如果组合里已有腾讯 + 美团 + PDD，再加 10% Prosus 是在已有集中上再集中。

✅ 成立：作为已有腾讯仓位的替代

这是我与看空报告分歧最大、也是我认为它最重要的一处误配。

看空报告和关联腾讯报告都给出"替代比例不超过腾讯仓位的 1/3"。这个 1/3 没有推导，是一个感觉。

正确的框架是把决策拆成两个独立问题：

决策 A：你要多少腾讯敞口？        ← 这是关于腾讯的问题
决策 B：用什么工具表达这个敞口？   ← 只有这个问题与 Prosus 有关

Prosus 只回答决策 B。 而对决策 B，条件只有一个（第六章）：退出时折价 <42.1%（3 年）。 不需要 V1（腾讯好不好是决策 A 的事），不需要 L2/L3/L4（那些只影响 22.6%）。

所以：如果你的决策 A 是"组合的 15% 放在腾讯敞口上"，那么用 Prosus 表达其中 10pp——即一个 >10% 的 Prosus 仓位——只需要 V2（回购不停，80%）+ L1（折价 <42.1%，65%）成立，联合概率约 55–60%，且赔率是"赢则 5 年多赚 20pp，输则少赚个位数"。

这是一个可以下的注。而"独立新增 10% Prosus"不是。
