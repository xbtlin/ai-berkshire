核心判断

最大风险不是十年后人们突然不需要快乐，而是他们仍然花钱买快乐，却不再用当前频率和价格购买泡泡玛特的产品；公司同时已按爆发期销量投入门店、组织、库存和内容。 情绪需求的持久性可以支持行业存在，不能直接支持任何一家公司的利润或当前股价。

风险要分成四层：

层次 较有把握的判断 不能由此推出的结论
人类需求 审美、赠礼、收藏、身份表达和社交会继续存在；这是推理，不是十年收入保证 情绪产品是消费刚需、金额不会下降
产品载体 实体物有触感、展示、赠礼和线下社交用途 当前搪胶毛绒挂件、盲盒购买方式会持续流行
具体 IP 可以跨年龄、地区、产品延续，也可以在爆红后回落 LABUBU 会始终处于热度顶峰
公司价值获取 多 IP、开发、供应链、直营和全球分发可降低单个角色的失败风险 只要行业增长，泡泡玛特就能永久保住份额、分成条件和利润率

一个人的情绪真实，不代表他购买的每个商品都有稳定复购。买第一只用于陪伴，买第二只用于赠礼，买一整套为了集齐、转售或社交展示，对应的是不同需求。公开报表无法拆开这些动机，不应把所有销量都说成炒作，也不应都说成长期情感依恋。

官方披露中国内地会员复购率 51.6%，定义是本期购买会员中本期购买两次及以上的占比，并非去年用户今年仍留存的比例，更不是海外留存率。它支持当期重复购买，不能单独证明十年客户生命周期。2026H1 业绩公告，PDF 第 22、30 页

推理：“LABUBU 下滑、公司仍增长”是平台论的重要正面证据；“近七成净增量由星星人贡献”又说明平台正在换主角，尚不能宣布摆脱爆款依赖。前者反驳“一个角色凉了公司必死”，后者反驳“IP 多了就自然稳定”。应继续看旧 IP 的绝对收入、同店、全价售罄和现金流，不能只看最大 IP 占比下降。

LABUBU 的冷热：一手证据能证明到哪里

2025 年热度确实曾扩散到转售市场：StockX 官方报告记录 LABUBU 成为平台热门收藏品，2025 年 6 月交易量超过当年 1 月两倍，7 月再创新高。这是平台成交证据，不代表全行业，也不能区分终端自用和投机。StockX 2025 年中报告

本次搜索获得 StockX 的 Have a Seat HEHE 页面快照：近三个月均价 14 美元、成交 10 次、标示零售价 22 美元。其样本小、款式特定、页面缓存时间并非报告时点，且跨市场税费不同，因此只能说明个别普通款已无稀缺溢价，不能据此写“全线崩盘”或计算全球热度跌幅。新款、隐藏款、整盒与散盒不可混用。StockX 具体商品页

最新正面边界：官方英国站仍在推出 THE MONSTERS CAT MODE ON，页面标示 2026-10-16 发售。持续出新品能证明运营仍在进行，不能证明消费者已接受或热度重新起飞。官方产品页

二级价格与经营收入之间有两种相反机制，必须分别跟踪：

  1. 健康正常化。供给补足，黄牛利润消失，真正喜欢的人更易按零售价买到；公司份额和收入可能提升。
  2. 需求透支。上涨预期曾吸引额外买家；跌价后他们同时停止购买并释放库存，与新品争夺购买预算。此时一级收入、折扣、库存和同店会随后恶化。

关键不在二级溢价本身，而在溢价归零之后，公司能否仍以有吸引力的毛利卖出足够多的新商品。最强证据是连续披露的全价销售、老客留存和现金回收，而不是某款“秒空”或社交媒体争论。

十年后：三条可检验路径

这些是条件推演，不是对 2036 年的事实预测，也没有足够统计依据为其赋精确概率。

路径 成立条件 到 2036 年可能呈现的形态 最早的辨别信号
少数经典 + 持续上新 核心角色获得跨代情感，供给纪律好，艺术家利益安排稳定 全球 IP 消费公司，旧角色仍有收入，新角色和授权拓宽场景；增长更平缓 多代 IP 在低炒作环境仍有真实销量；跨品类盈利，用户 cohort 留存可见
成功的潮流运营公司 新品研发和分发较强，但多数 IP 有明显寿命 反复产生成功系列、有周期的消费公司，利润率和估值低于“永续超级 IP”叙事 新品能补旧品下滑，但需要持续营销和渠道投入；收入波动不消失
爆款后收缩 产能和门店追随峰值，创新命中下降，客户转向替代品 保留部分品牌和粉丝，公司缩店、折价、减值；可能活着但股东回报差 多 IP 同时下降、现金转换恶化、库存和折扣上升、新店掩盖同店下滑

当前较稳妥的分析定位是第二条，第一条值得跟踪，第三条不能排除。 新 IP 接力已经发生，但跨代留存、逐项权利和多场景利润尚未充分证明。不应把十年模型建立在 2025 年爆发速度继续十年，也不应把某半年的下滑机械外推为归零。

换个更准确的问题：十年后不一定还有这么多消费者愿意买“今天的 LABUBU”，但泡泡玛特能不能成为当时消费者寻找新角色、买礼物和参加共同文化的常用入口？需要证明的是选择 IP 和经营社区的组织能力，而不只是当前有多少张可爱的脸。

为什么平台有价值，却不等于强锁定

推理：泡泡玛特的优势可以来自为艺术家解决开发、制造、质量、全球销售、营销和收款，让新角色更快触达已有消费者。这是一种组织和分发规模优势。消费者换买 Sanrio、Jellycat、游戏皮肤或另一品牌基本没有迁移成本；同一个消费者也可以同时拥有多个品牌。

社交传播可能形成正反馈：更多人认识角色，展示和交流更方便。但它不是通信网络那种“别人越多，我不用就越不方便”的强网络效应。潮流品还可能出现反向作用——过于普及损害独特感。共同文化和稀缺收藏有时相互促进，有时冲突；管理层必须在满足大众需求与保持系列吸引力之间调节供给。

门店多并不自动形成护城河。只有新 IP 经既有渠道销售时仍获得好的单位经济性，渠道才是资产；若必须用更多租金和推广换相同销售额，渠道规模会变成负担。

AI 与其他娱乐的替代：不要只问能不能画出更可爱的角色

以下是机制推理，不是已证实的收入冲击：

  • AI 能降低设计和内容试错成本，使好看角色、短视频和个性化陪伴的供给增加。受压的是“仅凭一张好看图片收溢价”的部分。
  • 私人生成角色缺少共享知名度、正品来源和线下社交共识；这些可能提高成熟 IP 的相对价值。实体触感和赠礼用途也不等同聊天机器人。
  • 数字陪伴、短剧、游戏、宠物、旅行会竞争时间和可选消费预算。替代不是功能完全相同才成立。
  • 若泡泡玛特自己用 AI 降低研发成本、把经典角色带入数字互动，它也可能受益；但不能在缺乏产品留存和付费证据时提前给 AI 平台估值。

真正应该监测的是预算迁移、购买频次、对正品溢价的接受度、跨场景体验的付费回报，而不是一项生成技术能否复制相似外观。

IP 权利是十年模型中的实质问题

已核实：2020 招股书披露与艺术家存在“版权转让”和“独家授权”两轨；MOLLY 的转让安排可见，获授权 IP 的期限和范围有差异。招股申请稿将 THE MONSTERS 列为独家授权，并列出当时约至 2030 年 4 月的期限。一般协议有地域/产品范围、到期协商和清库存期等限制。这属于历史合同披露，不能假定 2026 年仍完全没有修改，也不能把它写成全球全部品类永久所有权。公司官方最终招股书，业务章节；港交所 2020 招股申请稿，印刷页 204、226–228

风险机制：成功越大，艺术家越有议价能力，可能表现为分成率上升、权利边界收窄、最低保证提高，极端情况下不续约；不必走到失去角色，公司股东现金流就可能下降。双方投入了渠道、产品、名誉和共同商业利益，通常也有继续合作的激励，但互相依赖不是法律上“风险锁死”。

明确缺口：最新逐项合同全文、续约变化、星星人等 IP 的具体买断或授权性质、各 IP 分成没有充分公开。财报“艺术家 IP”不等同法律意义上的“全部版权自有”。拥有商标也不能直接推出拥有全部著作权、跨品类开发权或永久生产权。任何“已经买断 THE MONSTERS”“不续约还能无限期继续生产”的网传话术，必须有正式披露或可核对的原始发言才能纳入事实。

最新监管边界

中国《盲盒经营行为规范指引（试行）》禁止向未满八周岁者销售，对更大年龄未成年人要求监护人同意，并要求规范概率等披露。2026-09-11 总局公布六起典型案件，涉及虚假宣传、概率不透明、假冒和质量问题；这证明执法仍在继续，不是对成年人正规购买盲盒的全国禁令。2023 指引；2026 典型案例

新加坡内政部 2026-03-02 答复明确拟减轻盲盒的赌博诱导和过度消费风险，年龄限制及概率披露需继续研究；本次检索 GRA 的许可页面仍将 mystery boxes 具体条件列为后续公布。因此只能写监管正在形成、细则存在不确定性，不能写成已全面禁售。MHA 答复；GRA 许可页面

美国 CPSC 2025-08-18 的警告针对仿冒 LABUBU/Lafufu 的窒息风险，英国相关公告也明确是 counterfeit。不能混写为泡泡玛特正品被召回；假货仍会分流需求、提高维权成本并污染品牌声誉。CPSC 原文；英国召回公告

投资含义推理：若利润高度依赖重复抽取刺激，限制会伤害频次；若角色本身有价值，可转向明盒、赠礼、服饰和授权。这样的迁移能否保持利润，需要用销量和毛利验证。合规也可能淘汰弱小和假货对手，不能只算单向损失。

可证伪的跟踪表

下列触发条件为研究者的复核标准，不是公司指引或统计规律；同店、cohort 留存等部分项目目前披露不足，应直接标记未知。

论点 应跟踪的证据 何时应下调判断
平台接力有效 剔除第一大、第一增长 IP 后收入；多代 IP 的绝对金额 连续两个可比披露期主要依靠一个新 IP，旧 IP 群体同步衰退
消费者为角色付费 普通款全价销售、会员分代留存、赠礼和明盒表现 二级跌价同时伴随一级大面积折扣、重复购买下降
全球扩张有回报 地区同店、开店批次回收期、店均现金贡献 新店持续增加而成熟店收入和现金贡献下降
库存风险可控 存货增长对比销售、周转天数、减值、经营现金流 多个披露期存货快于收入、现金转换走弱；不以单一半年季节性下结论
IP 能跨载体变现 独立的授权收入、乐园/内容投入回报、跨品类利润 曝光和合作很多，但只增加费用，未产生可持续利润
股东保有经济利益 长期授权期限、分成、保底和续约披露 核心 IP 续约成本显著上升，或关键地域/品类权利丧失
热度有沉淀 在零转售溢价下仍有稳定购买、新客获得老角色 每次增长都必须重新制造供给短缺或大额促销

AI 对已披露历史数据的核对置信度较高；对十年后谁成为经典、消费者迁移和私有合同安排的判断明显较低。十年投资确定性取决于持续创造并保有现金流的能力，不能由资料数量、IP 数量或“人永远需要快乐”推导。
