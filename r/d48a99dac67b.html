趋势分析结论

营收增长：★★★☆☆ - 近5年营收CAGR约5.32%，增长温和但天花板已现 - 2023年增速最低（2.26%），2025年略有回升至5.61% - 包装行业需求稳定，但缺乏爆发性增长

净利润质量：★★★☆☆（趋势转负面） - 2024年净利润增长14.63%创近年新高，但2025年首次下滑6.33% - 扣非净利润4.09亿（-7.17%），降幅大于净利润——非经常性损益有粉饰作用 - 2026年Q1净利率进一步降至9.78%，创近3年新低

巴菲特关注点： "在营收增长时利润下降，是企业定价权丧失的典型信号。"

毛利率波动区间22-25%，反映原材料价格敏感型业务。据券商研报：合成树脂类占采购成本58.53%，原材料每升10%，毛利率下降约7.9pct。公司是价格接受者，无定价权。

盈利能力综合评分：★★★☆☆（趋势负面）

7. 金融严谨性验证

市值验算

股价: 11.4元
总股本: ~6.1249亿股（基于2025年报）
市值 = 11.4 × 6.1249 = 69.82亿元

PE验算

PE = 股价 / EPS(TTM) = 11.4 / 0.72 = 15.83倍
数据报告PE(TTM) = 15.87倍 ✅ 基本一致（差异<1%）

PB验算

PB = 股价 / 每股净资产 = 11.4 / 4.04 = 2.82倍（基于2025年报BVPS）
数据报告PB = 2.72倍（基于2026Q1 BVPS 4.19元：11.4/4.19=2.72）✅ 一致
