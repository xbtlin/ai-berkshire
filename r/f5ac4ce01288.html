研究问题：泡泡玛特 5 年后（到 2030 年）的净利润预测会是多少？含四个子问题——(1) 基于历史财务、券商预测与增长驱动测算 2030 净利润合理区间；(2) 消费者对潮玩产品的长期喜好是否可持续、盲盒/IP 收藏品的复购与留存趋势；(3) Labubu（THE MONSTERS 系列）热度周期处于什么阶段、是否会退潮及退潮时点与幅度；(4) IP 矩阵（MOLLY、SKULLPANDA、DIMOO、CRYBABY 等）能否接替 Labubu 的增长贡献，IP 孵化运营、海外扩张、品类拓展能否支撑持续增长。

完成日期：2026-08-10 方法：5 个搜索角度并行 → 抓取 21 个信源 → 提取 98 条声明 → 对 25 条核心声明做 3 票对抗式核验（需 2/3 反驳才推翻）→ 综合去重后保留 7 条结论。核验结果：25 条全部确认、0 条被推翻。 免责：本报告为研究记录，2030 净利润区间为基于券商 2026-2028 一致预期的外推测算，非券商原始预测，不构成投资建议。

一、执行摘要

没有券商直接预测泡泡玛特 2030 年净利润。三家券商（信达、第一上海、东吴）对 2026-2028 年归母/经调整净利润的一致预期落在 150-218 亿元 区间，增速由 2025 年的三位数爆发（归母 127.76 亿元、同比 +308.8%）逐年回落至约 15-20% 的常态化水平。

以 2028 年约 210-218 亿元为锚、按券商隐含的 15-20% 放缓增速外推两年，2030 年归母净利润的合理区间约 270-400 亿元人民币，中枢约 300-330 亿元 。若 IP 矩阵接力与海外扩张兑现则偏上沿；若 Labubu 快速退潮且其他 IP 未能显著补位则偏下沿甚至低于此区间。

消费者黏性与 IP 接力方面证据偏正面：Labubu 热度确已从 2025 下半年回落，但星星人已成为亚洲除 Labubu 外最受欢迎的 IP，MOLLY / SKULLPANDA / CRYBABY / DIMOO 等多个 IP 收入破 10-35 亿元、公司形成"一超多强"矩阵，降低了对单一 IP 的依赖。

核心不确定性有两点 ：Labubu 退潮的时点与幅度（当前占营收 38.1%、集中度过高曾引发财报后股价单日跌超 15%），以及非 Labubu IP 能否在海外市场持续接棒。这两点是 2030 预测偏差的最大来源。

二、核验结论（7 条，均经 3 票对抗式核验）

结论 1｜2030 净利润区间：270-400 亿元、中枢约 300-330 亿元（外推）

  • 置信度：高
  • 核验：3-0（多个一手研报），其中 2030 外推为综合分析、非研报原话
  • 证据：信达证券预计 2026-2028 归母净利润 150.5 / 181.0 / 217.5 亿元（增速 +17.83% / +20.21% / +20.21%）；第一上海预计 2026-2028 股东净利润 149.62 / 179.41 / 210.75 亿元（经调整口径 150.48 / 180.41 / 211.90 亿元）；东吴证券预计 2025-2027 归母 92.68 / 134.84 / 170.75 亿元、经调整上调至 100.3 / 144.9 / 182.9 亿元。三家 2028 锚点集中在 210-218 亿元。券商隐含增速已从 2025 年三位数降至 15-20%，以 2028 年约 215 亿元按 15-20% 外推两年得约 270-310 亿元（12-15% 更保守约 270-285 亿元、20% 乐观约 310 亿元），综合区间 270-400 亿元、中枢约 300-330 亿元。
  • 信源：信达研报 PDF、第一上海研报 PDF、东吴研报 PDF

结论 2｜最新基期已确立：2025 年营收 371.2 亿、净利约 127.76-130.1 亿、毛利率 72.1%

  • 置信度：高
  • 核验：3-0，多来源一致（英文引用存在"亿/billion"单位误译，中文数值正确）
  • 证据：2026-03-25 发布的 2025 年报经多来源交叉验证：营收 371.2 亿元（+184.7%）、首破 300 亿；净利润 127.76 亿元（+308.8%，母公司股东应占口径）或 130.1 亿元（+293.3%，年内溢利口径）、经调整 130.8 亿元（+284.5%）；毛利率 72.1%（前值 66.8%）。2024 基数营收 130.38 亿、净利 31.25 亿，2025 净利约为其 4 倍。券商实际 2025 预测（如东吴 92.68 亿、经调整 100.3 亿）反而低于真实值，说明基期偏保守、外推有上修空间。
  • 信源：新浪财经、华尔街见闻、新京报

结论 3｜高增长趋于常态化：CEO 目标 2026「不低于 20%」，增速逐年回落

  • 置信度：高
  • 核验：3-0（一手研报 + 发布会口径）
  • 证据：王宁在 2025 年报发布会将 2026 年定为"休整年"、目标增长"不低于 20%"。第一上海预测营收 2025-2028 为 371.20 / 444.99 / 520.92 / 597.74 亿元，增速 +184.7% / +19.9% / +17.1% / +14.7%；信达预测营收 371.20 / 452.98 / 544.99 / 649.82 亿元，增速约 +22% / +20% / +19%，EPS 由 9.61 升至 16.22 元。高增长逐步常态化是 2030 外推的基础假设。
  • 信源：华尔街见闻、第一上海研报 PDF、信达研报 PDF

结论 4｜IP 矩阵「一超多强」成形，降低单一 IP 依赖（乐观情形的关键支柱）

  • 置信度：高
  • 核验：3-0（半年报/全年报 + 研报），个别接力表述有分歧但主力 IP 事实成立
  • 证据：2025 全年 SKULLPANDA 35.4 亿、CRYBABY 29.3 亿、MOLLY 29.0 亿、DIMOO 27.8 亿、星星人 20.6 亿元，均同比增长；2025H1 有 5 个 IP 破 10 亿（MOLLY 13.6 / SKULLPANDA 12.2 / CRYBABY 12.2 / DIMOO 11.1 亿）、另 13 个艺术家 IP 过亿。第一上海指出星星人已成"亚洲市场除 Labubu 外最受欢迎 IP"，摩根士丹利估其 2026 中国销售或达 Labubu 约一半。东吴看好 Labubu 和 MOLLY 两个"有望常青"头部 IP 提供现金流与流量支撑。
  • 信源：新浪财经、新华网、华尔街见闻、第一上海研报 PDF

结论 5｜Labubu 热度已从 2025 下半年高点回落进入退潮早期，但仍是最大单一 IP、集中度过高构成核心风险

  • 置信度：高
  • 核验：3-0（财报 + 研报 + 媒体交叉验证）
  • 证据：THE MONSTERS 2025 全年营收 141.6 亿元（+365.7%）、占总营收 38.1%（2024 年为 23%），H1 为 48.1 亿元（+668%）、占 34.7%、唯一破 40 亿的头部 IP。单一 IP 集中度引发投资者担忧、财报发布后股价一度跌超 15%（CNBC 记收盘跌超 22%）。第一上海明确"Labubu 热度较去年下半年回落"，二级市场星星人二手价一度反超 Labubu、mini Labubu 二手价从峰值跌 24%。东吴列示"头部 IP 热度自然衰减但其他 IP 收入尚未贡献显著收入"为核心风险。退潮已启动但幅度/时点未定。
  • 信源：华尔街见闻、新浪财经、东吴研报 PDF、第一上海研报 PDF

结论 6｜海外扩张是当前最强增长引擎，但海外占比尚未过半、且 Labubu 热度高度由海外驱动

  • 置信度：高
  • 核验：3-0，"海外驱动"表述略有外延但载体数据准确
  • 证据：2025H1 美洲区营收 22.6 亿元（+1142.3%，线上 +1977.4%）、欧洲及其他区 4.8 亿元（+729.2%），全球门店 18 国 571 家。海外合计约 55.9 亿元占总营收约 40%，中国大陆约 82.8 亿元（约 60%）仍为主体——海外是增长引擎但非营收多数。东吴将"海外拓展不及预期"列为核心风险，海外扩张兑现度是 2030 区间上下沿的关键摆动因素。
  • 信源：新华网、新浪财经

结论 7｜券商普遍维持「买入」，估值给到 2026 年 20-30 倍 PE

  • 置信度：高
  • 核验：3-0（一手研报）
  • 证据：东吴给予 2026 年 30 倍 PE、对应 4346 亿元市值、较 2025/8/8 有 28% 空间、维持买入；第一上海目标价 226 港元（较 152.4 港元收盘价有 48.3% 空间）、基于 2026 财年经调整净利润 20 倍。东吴认为"短期市场过度关注 Labubu 边际热度、低估 IP 矩阵长期价值"。PE 区间 20-30 倍的分歧本身反映 Labubu 退潮与 IP 接力能否成立的市场不确定性。
  • 信源：东吴研报 PDF、第一上海研报 PDF

三、局限与告警

  1. 2030 数字是外推、非券商预测 。本报告 2030 区间（270-400 亿元、中枢 300-330 亿元）为基于 2026-2028 券商锚点按 15-20% 放缓增速的综合外推，误差随年限放大，属分析判断而非研报原话。
  2. 时效性 。2025 年报（2026-03 发布）与三份研报（2025-08 至 2026-05）为最新，但潮玩行业与单一 IP 生命周期波动快，Labubu 退潮速度可能在数季度内改变全部假设。
  3. 源质量瑕疵 。第一上海与东吴的 PDF 托管于阿里云 OSS 测试桶（testtoo1.oss-cn-hangzhou）而非东方财富官方域名，属托管异常，但核心数字经独立媒体交叉验证；多条英文引用存在"亿"误译为"billion"的 10 倍单位错误，被审的中文原始数值正确。
  4. 券商系统性低估 。券商 2025 实际预测（东吴归母 92.68 亿 vs 实际 127.76 亿）明显偏低，说明模型对爆发力存在系统性低估，外推可能偏保守。
  5. 接力证据的分类瑕疵 。THE MONSTERS × FIFA 被部分信源归为"Labubu 之外 IP"实属 Labubu 家族，接力证据中此点分类有误；"售罄"部分源于饥饿营销而非纯有机需求，作为长期黏性代理偏弱。
  6. 净利润口径不统一 。母公司股东应占 127.76 亿 / 年内溢利 130.1 亿 / 经调整 130.8 亿，跨券商比较时需注意可比性。

四、待解问题（研究盲区）

  1. Labubu 退潮的量化衰减曲线 ：从 2025 下半年高点回落后，THE MONSTERS 占比 38.1% 将在 2027-2030 如何演变？软着陆还是断崖式下滑？现有证据只确认"已回落"，未给出量化衰减曲线。
  2. 非 Labubu IP 的海外接棒能力 ：星星人、CRYBABY、MOLLY 等能否在海外复制 Labubu 的破圈成功？当前接力证据主要来自中国/亚洲市场，海外接棒能力未被数据充分验证。
  3. 新品类的利润增量 ：乐园、游戏、饰品对 2030 净利润的增量贡献有多大？现有核验声明几乎未覆盖城市乐园、游戏、饰品等品类拓展的财务数据与盈利模型。
  4. 利润率能否维持 ：2025 毛利率已达 72.1% 历史高位，规模扩张、海外占比提升、渠道结构变化对未来利润率的影响方向未明确；净利率走向比毛利率更关键。

    • 结论 3｜高增长趋于常态化：CEO 目标 2026「不低于 20%」，增速逐年回落
    • 结论 4｜IP 矩阵「一超多强」成形，降低单一 IP 依赖（乐观情形的关键支柱）
    • 结论 5｜Labubu 热度已从 2025 下半年高点回落进入退潮早期，但仍是最大单一 IP、集中度过高构成核心风险
    • 结论 6｜海外扩张是当前最强增长引擎，但海外占比尚未过半、且 Labubu 热度高度由海外驱动
    • 结论 7｜券商普遍维持「买入」，估值给到 2026 年 20-30 倍 PE
