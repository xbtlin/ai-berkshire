前置：信息丰富度评级、研究局限性与偏见自查

信息丰富度评级：A级（信息充裕）

腾讯上市22年，季度披露完整，券商覆盖密集。A级公司的陷阱是"共识过强"——市场在过去12个月把股价从683港元高点打到421港元（跌幅约38%），共识本身正在剧烈摇摆。本报告的重心因此放在反面检验：这次下跌是市场看错了，还是看到了财报里还没体现的东西。

AI研究局限性声明

  1. 资本开支的回报无法从公开资料验证。 2026年上半年资本开支847亿元，已超过2025年全年792亿元；这笔钱换来的混元模型、WorkBuddy、元宝等新产品的收入规模，公司未单独披露，只能通过"剔除新AI产品后的经营利润"反推投入强度。
  2. "新AI产品拖累"88亿/105亿元为管理层业绩会口径，经媒体转述，不在公告正文中，置信度中等。公告正文仅给出剔除新AI产品后的非国际准则经营利润861亿元。
  3. 与甲骨文的算力租赁协议（约70亿美元、10万张芯片、5年）为海外媒体报道，公司未公告，置信度中低。
  4. 游戏版号、平台监管、地缘制裁等离散事件无法量化概率，本报告以情景处理，不进折现率。
  5. 研究者无法接触产品内部数据（如WorkBuddy付费率、小微灰度效果），对新产品的判断主要依赖公司表述。

偏见自查

自查项 结论
确定性来自生意本质还是资料数量？ 存量生意（微信、游戏、广告）的确定性来自十余年经营数据；AI投入回报的"确定性"几乎为零，两者必须分开
资料减半结论会变吗？ 对存量生意不会；对AI部分本来就是低置信度
是否与市场共识雷同？ 卖方一致"强烈买入"、目标价均值约664港元，但股价持续下行——本报告刻意不采用卖方目标价，只用自算的情景
锚定风险 极易锚定2025年高点683港元或卖方目标价，下文估值完全从利润和现金流出发

第二模块：生意本质

2.1 一句话定义

腾讯是一家向14亿人的社交关系收"过路费"的公司：游戏、广告、支付、小程序电商都只是这张关系网上的不同收费口。

2.2 收入拆解：三个引擎，三种性质

引擎 2025年收入占比 性质 可持续性
游戏（本土1,642亿+国际774亿） 约32% 内容生意+社交分发；长青游戏（王者荣耀、和平精英、三角洲行动）是"数字体育场" 高，但单品有生命周期，需持续出新
社交网络（1,277亿） 约17% 会员、直播、虚拟物品 中，增速已降到个位数
营销服务（1,450亿） 19.3% 注意力变现；广告加载率仍远低于同行 高，2026年在加速
金融科技及企业服务（2,294亿） 30.5% 支付通道费+理财消费贷导流+云 支付稳；云受益AI

2.3 盈利能力趋势

  • 毛利率：43.9%（2021）→56.2%（2025）→58%（2026Q2）。五年提升超过12个百分点。
  • 非国际准则经营利润率：27.3%→37.3%，2026Q2回落到37%，是因为新AI产品拖累；剔除后升到42%。
  • 销售费用率2025年仅5.6%，管理费用率（含研发）18.1%。

毛利率高的原因：自研游戏的边际成本接近零、广告库存来自自有流量、视频号不需要像抖音那样大量买内容。毛利率高于网易（游戏为主、无广告）而低于纯广告平台，因为金融科技（支付通道成本）和云（服务器折旧）稀释了整体毛利。

2.4 商业模式画布

  • 订阅/复购型为主：游戏内购是高频复购，长青游戏可连续运营十年；广告是按效果持续采购；支付是交易抽成。
  • 平台而非硬件：几乎无库存（存货6.85亿元，对比收入可忽略）。
  • 新变量：AI把腾讯从轻资产平台推向"重资产+平台"。2026年上半年资本开支/收入达21.1%，2025年为10.5%。这是这门生意本质上最大的一次变化。

2.5 生态粘性

微信的锁定不在功能而在关系链：用户迁移需要说服全部联系人一起迁移，这在实践中不可能。微信支付、小程序、视频号、搜一搜全部寄生在这张关系网上，且彼此强化（小游戏买量→视频号广告→小店成交→支付手续费）。

2.6 经营杠杆

2023—2025年收入增长23%（6,090→7,518亿元），非国际准则经营利润增长46%（1,919→2,807亿元）。经营杠杆约2倍。2026年这个杠杆第一次被主动"关掉"：收入+11%，非国际准则经营利润只+9%。

生意本质追问：这门生意好在哪？——好在它不需要花钱获取用户，用户本来就在，每多一种变现方式就是纯增量。 AI投入的风险恰恰在于：腾讯第一次需要在一个它没有天然入口优势的领域（大模型能力本身）花大钱竞争。

第三模块：护城河

3.1 五类护城河逐项验证

类型 强度 证据 五年趋势
网络效应 极强 微信月活14.39亿，五年仍在增长；视频号总使用时长同比增长超过20% 稳定，略增强（视频号补齐短视频短板）

3.2 护城河的结构性判断

腾讯有两条护城河，性质完全不同：

  1. 关系链护城河（微信）：过去十年没有任何对手撼动，抖音做社交失败，阿里来往失败。
  2. 内容运营护城河（游戏）：长青游戏数量在增加（三角洲行动在2026年进入长青游戏行列），说明不是吃老本。

AI对两条护城河的威胁不同：对关系链的威胁是"入口替代"——如果用户通过AI助手直接完成购物、订餐、查询，小程序和搜一搜的流量会被分走；对游戏的威胁是"生产成本下降"——AI降低开发成本后，中小团队也能做出高品质游戏，腾讯的研发规模优势缩小。

3.3 十年判断

  • 微信关系链护城河：十年后仍在的概率高（我们估计约85%）。摧毁它需要一种新的通信范式，而AI助手目前是"在微信里"而不是"替代微信"——公司已在微信内部小范围测试智能体"小微"。
  • 游戏护城河：十年后仍在但变窄的概率较高。玩家时间和社交关系才是游戏的核心资源，AI降低的是生产成本，不是用户获取成本。
  • 大模型：腾讯不需要成为第一，只需要"够用+便宜+嵌入自家场景"。

护城河追问：10年后这条护城河还在吗？什么能摧毁它？——能摧毁微信的不是另一个聊天软件，而是"不需要聊天就能办事"的智能体入口。 这也是腾讯不惜让自由现金流转负也要投AI的真正原因：这笔钱本质是护城河维护费，而不是新业务投资。

4.3 跨学科验证

  • 网络效应理论：通信类网络效应（梅特卡夫型）是所有网络效应里最强的，因为价值随节点数平方增长，且不跨网络互通。
  • 技术采纳曲线：大模型应用在中国仍处于早期大众阶段，现在决定的是入口格局，所以各家都在烧钱。这解释了为什么腾讯"不能不投"。
  • 竞争博弈：字节、阿里、腾讯的算力竞赛是典型的囚徒困境——单方面不投会丢入口，大家都投则行业回报率下降。

4.4 偏误自查

  • 叙事偏差："AI投入是护城河维护费"是一个好听的故事，但同样可以被讲成"错失AI后的恐慌性补课"。区分的标准只有一个：投入能否在2027—2028年体现为收入。
  • 锚定效应：容易把"12倍市盈率"和"历史低位"直接画等号。但如果未来三年折旧大幅上升，今天的市盈率是在一个即将被压低的利润上算的。
  • 幸存者偏差：腾讯过去每次大跌后都反弹，但这不保证这次也一样。

4.5 空方最强论点

"腾讯正在从一家每年回购800亿港元的现金牛，变成一家借钱买算力的重资产公司，而它的AI产品在中国排不上第一梯队。" 这个论点的数据支撑：净现金一个季度减少约60%、2026年6月新发债、回购缩量、管理层拒绝给出盈利时间表。

反过来想追问：我最可能在哪里犯错？——最可能错在低估资本开支的持续时间。 管理层说"主要是今年和明年"，但字节、阿里不会停，腾讯也很难停。聪明人不买腾讯的理由不是业务变差，而是"不知道要交多少年的AI税"。

第六模块：行业与文明趋势

6.1 是否处于范式转移

是。AI是继移动互联网之后的第三次入口迁移（PC门户→移动应用→智能体）。历史上每次入口迁移都会重新洗牌：PC时代的门户在移动时代全部边缘化；移动时代腾讯靠微信完成了自我颠覆。

历史类比 当时的霸主 迁移后
PC→移动 门户网站、PC端QQ 腾讯靠微信自我颠覆，成功过渡
功能机→智能机 诺基亚 被淘汰
搜索→推荐 百度 被字节分走大部分注意力
移动→智能体 微信？ 答案未知，这是腾讯投资的核心问题

6.2 可寻址市场与天花板

  • 中国在线广告、游戏、移动支付都已是成熟市场，腾讯在其中的份额很高，存量增长天花板在于名义GDP增速加份额提升。
  • 增量来自：①视频号广告（时长同比增长超过20%，加载率低）；②小店电商技术服务费；③国际游戏（2025年超过100亿美元）；④AI订阅与云。
  • 新AI产品（WorkBuddy、CodeBuddy）的付费模式是订阅加按量充值，公司称付费部分毛利率已与腾讯云整体持平（业绩会口径）。

6.3 价值链位置

腾讯位于"应用+分发"层，这是中国互联网价值链中利润最厚的一层。AI时代价值链会变成"芯片→算力→模型→应用→分发"：腾讯在芯片层完全依赖外部（受制裁限制，只能租用海外算力），在模型层追赶，在应用和分发层拥有最强资产。AI时代的利润最终会流向芯片和分发两端，模型层可能是消耗战。 腾讯如果能守住分发端，就不必在模型层赢。

6.4 技术路线与集中度风险

  • 先进芯片获取受美国出口管制约束，海外租赁是当前的变通路径，政策风险高。
  • 客户集中度低：广告主分散，游戏玩家分散；供应商集中度高：算力芯片集中在少数厂商。

行业趋势追问：站在20年后回看，腾讯是"这个时代的标准石油"还是"昙花一现的3Com"？——更可能是"这个时代的电信运营商+娱乐公司"：关系链像电话网络一样持久，但如果错失智能体入口，增长会像运营商一样停滞。它不会是3Com，但也未必是新时代的霸主。

估值 近12个月非国际准则12.3倍，核心业务约10倍，隐含增速仅为实际增速的三分之一左右 高

8.2 最终决策：分批买入

策略 建议
空仓者 450港元以下分三批建仓：现价先建三分之一；11月18日第三季度业绩若资本开支环比不再大幅上升或剔除口径差额不扩大，加第二批；370港元以下或2027年第一季度确认资本开支见顶时加第三批
持仓者 继续持有，不追加超过既定仓位上限；股价回到650港元以上可考虑把仓位降回常规水平
卖出信号 ①季度"剔除新AI产品"利润与报告利润差额超过200亿元，且管理层仍不给上限；②微信月活连续两个季度同比负增长；③回购全年低于200亿港元同时继续发债买算力；④股价超过750港元而利润未跟上
加仓信号 ①2027年上半年资本开支同比回落；②腾讯云或新AI产品开始单独披露收入且同比翻倍；③回购恢复到季度百亿港元以上；④股价跌破370港元而核心业务增速仍在双位数

8.3 四个维度的最终判断

生意本质：腾讯的生意本质没有变，变的是它第一次需要为维持入口地位支付高昂成本。用户本来就在，这一点比任何AI模型排名都重要。

护城河：关系链护城河十年后大概率仍在。AI投入应被理解为护城河维护费——贵，但比失去护城河便宜。

反过来想：最大的错误不会是"腾讯倒下"，而是"腾讯连续五年把增量利润全部交给算力，股价长期横盘"。买入者要为这个情景留出耐心和仓位余量。

估值：12倍市盈率买一个核心利润增长15%以上的生意，即使打七折折算AI损耗，安全边际依然存在。

8.4 AI分析置信度 vs 投资确定性

结论 AI分析置信度 投资确定性 依据
核心业务（游戏、广告、支付）健康且在加速 高 高 一手财报连续多个季度数据
当前估值处于历史低位区间 高 高 工具验算
AI投入规模与持续时间 中低 低 管理层口头表述，无量化指引
AI投入的最终回报 低 低 新产品收入未单独披露
微信不被智能体入口替代 中 中 依赖对行业格局的推理，非数据

区分说明：本报告关于存量业务和估值的结论基于充分数据；关于AI的结论基于有限信息的推理。高置信度的数据（便宜、核心强）与低确定性的变量（AI投入何时见顶）并存——这正是股价跌到这里的原因，也是潜在超额回报的来源。

限制

  1. 未建模的离散风险：大股东Prosus持续减持（2025年末22.80%→2026年6月末22.60%）对股价供需的压制未纳入估值模型。
  2. 游戏监管重击、AI入口替代以情景处理；VIE失效、美国制裁升级与算力断供归入尾部档，均未进入折现率。
  3. 非国际准则口径剔除了股权激励（近12个月约275亿元），十年估值已扣除；三年三情景仍基于非国际准则每股收益，乐观程度相应偏高约10%。
  4. 新AI产品的拖累数字、甲骨文协议为非公告来源。
  5. 同行估值仅取单一来源（stockanalysis）。
