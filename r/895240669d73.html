估值检查（skill 4.2.1节）：

红灯条件核查： - PS > 30x 且增速 < 100%：PS约10x，远低于30x；增速+90.1%，接近100%豁免线 → 不触发 ✅ - 市值 > TAM的20%： - 保守定义（仅EML激光器）：当前TAM约$20-30B；20% = $4-6B；市值约$28-35B > $4-6B → 🔴 边界触发 - 合理定义（全光子产品线：EML+VCSEL+工业+电信）：TAM约$80-150B；20% = $16-30B；市值约$28-35B ≈ 边界，不明显触发 - 判断：TAM定义存在合理争议；Lumentum收入$3B+说明其可触达市场远大于单一EML，故不触发硬红灯，标注"⚠️ TAM黄灯，需精确核查市值后重新判断" - 市值 > 5年乐观预测10倍：5年CAGR 30% → FY2031收入约$9B；净利率15% → NI约$1.35B；10x = $13.5B；市值$28-35B >> $13.5B → 🔴 触发（但注：5年后实际NI可能更高，CAGR 30%较保守）

结论：因前向PE可接受（52x + PEG 0.58）、PS合理（约10x）、高速增长（90% YoY），但5年预测10倍检验触发。综合判断：★★★（需以实际市值重新验证TAM/5年测试；不触发强制★★封顶，因TAM定义存在合理争议且增速接近豁免线）。

黄灯条件： - 前向PE = 52x：高于30x，但PEG = 52 ÷ 90 ≈ 0.58（PEG < 1 = 增速支撑估值）✅

绿灯： - PS约10x（接近<10x绿线）且增速+90% → 接近绿灯 ✅

估值安全边际检验（10年25x PE退出法，基于估算市值$30B）： - 买入市值：$30B（估算） - 10年10%年化目标：$30B × 2.59 = $77.7B - 25x PE退出需年净利润：$77.7B ÷ 25 = $3.1B - 15%净利率对应所需收入：$20.7B（约今日$3B的6.9倍） - 所需CAGR：($20.7B / $3B)^(1/10) - 1 ≈ 21.2%/年 - AI光互联持续10年20%复合增速的可信度：中等（2025-2028需求明确，2029-2032需新应用接力） - 结论：安全边际勉强成立，依赖AI基础设施长周期假设。不乐观情景（增速降至12-15%）下不足。
