8 月 26 日和 8 月 31 日，MiniMax 和智谱先后交出上市后第一份完整中报。两家同一个月在港交所敲钟，同一个报告期，同一条赛道。

把两份报表换算到同一个货币口径，会看到一组几乎重叠的数字。

一、四个几乎重叠的数字

1H2026 智谱 MiniMax 差异
研发开支 21.31 亿元 = 3.17 亿美元 2.97 亿美元 智谱多 6.8%
经调整净亏损 19.64 亿元 = 2.923 亿美元 2.930 亿美元 差 0.26%
员工薪酬（含股份支付） 4.82 亿元 = 0.717 亿美元 0.689 亿美元 智谱多 4.1%
经营现金净流出（推算） 约 32 亿元 = 约 4.8 亿美元 约 4.3 亿美元 同一量级

剔除股份支付和金融工具重估之后，两家在同一个半年里的真实亏损差 0.26%。不是挑出来的巧合，研发、薪酬、烧钱三项也全部落在 ±7% 以内。

2026 年上半年做一家前沿大模型公司的门槛因此很清楚： 每半年 3 亿美元研发、3 亿美元经调整亏损、4 至 5 亿美元现金消耗 。两家路径完全不同的公司，被同一条成本曲线约束到了同一个数量级。

差别在于这笔一样的钱换回了什么。

二、一样的钱，智谱换回了更多

1H2026 智谱 MiniMax 智谱 / MiniMax
收入 1.420 亿美元 1.166 亿美元 1.22 倍
毛利 0.374 亿美元 0.208 亿美元 1.80 倍
毛利率 26.4% 17.9% +8.5pp
增量毛利率（对 2H2025） 12.0% 6.5% 1.85 倍

增量毛利率是把最近半年新增的收入和新增的毛利相除，看新钱的赚钱效率。两家都远低于各自的报表毛利率，说明新增收入比存量更不赚钱。但智谱的新钱效率是 MiniMax 的 1.85 倍。

再看两家贴身竞争的那条赛道，B 端开放平台／API：

B 端 API 智谱 MiniMax
1H2026 收入 1.228 亿美元 0.739 亿美元
占总收入 86.5% 63.4%
半年环比 +411.6% +341.1%
2H2025 基数 约 0.23 亿美元 0.168 亿美元

起跑线接近，半年后智谱是 MiniMax 的 1.66 倍，增速还更快。

总收入的环比斜率反而是 MiniMax 更陡（+139.8% 对 +78.8%） ，原因是智谱主动砍掉了本地化部署业务，该分部环比下滑 65.4%。MiniMax 的非 API 业务（海螺 AI 等 C 端产品）环比只增长 33.9%，同比 +100.9% 靠的是低基数，高毛利的 C 端已经明显失速。

两家的结构变化是同一个方向、不同的起点：智谱从卖私有化部署转向卖 API，MiniMax 从卖 C 端订阅转向卖 API。智谱转得更彻底。

三、共同的病：毛利率在同一个半年里同时塌陷

毛利率 2H2025 1H2026 变动
智谱 37.7% 26.4% -11.3pp
MiniMax 33.7% 17.9% -15.9pp

智谱这边有一组细节值得单独看。云端毛利率从 2H2025 的 22.4% 只提升到 1H2026 的 24.6%， 在收入环比增长 4.1 倍的条件下，只多了 2.2 个百分点 。同期公司披露 API 平均售价上调了约 101%。

收入翻了四倍、价格翻了一倍，云端毛利率只挪动 2.2 个百分点。 反推成本：收入环比 +411.6%，成本环比 +397.2%。 成本几乎与收入等比例扩张，规模效应在环比维度上基本没有出现。

两家公司、两套技术路线、两个客户结构，得到同一个结果。这就不是公司问题了，是行业问题：

Token 单价下行 + 推理算力成本刚性 + 调用结构向更长更复杂的任务迁移，三股力量把这门生意的毛利率压在 20% 上下。

做个参照：成熟的云计算业务毛利率在 60% 以上，SaaS 在 70% 以上。 今天的大模型 API 生意，毛利结构更接近算力转售，而不是软件。

四、共同的动作：把现金变成预付算力

两张资产负债表上金额异动最大的科目是同一个。

智谱 MiniMax
期末余额 预付计算服务费 12.44 亿元 （另有其他非流动资产 9.12 亿元） 预付款项等 2.66 亿美元
半年增幅 +969.5% 流动 +913.7% ／非流动 +11,266%
相当于半年收入 约 2.3 倍 2.1 倍
明细披露 无 无

两家在同一个半年里，把相当于两倍多半年收入的现金提前付给了算力供应商，而且都没有披露任何构成明细。

2026 年上半年，算力供给紧张到了模型公司必须先付钱才能锁产能的程度。 这笔钱是成本前置，今天不进损益表，未来以成本和折旧的形式压在后续期间的毛利率上。

路径选择不同。智谱内生资本开支仅约 0.29 亿元，公告明示"无任何未履行的资本承担"，算力全部走服务采购，同时往国产芯片走，自述已实现 10 万级国产芯片规模化推理。MiniMax 开始自建，物业厂房设备从 157 万美元增至 7,491 万美元，半年增长 46.7 倍，同时深度绑定阿里云，采购年度上限从 1.15 亿美元上调至 3.00 亿美元。

有一个对 MiniMax 有利的细节要替它说清楚： 开放平台 7,393 万美元收入里，来自关连方阿里巴巴的只有约 50 万美元（0.7%） ，其余全是真实第三方需求。

五、跑道，最实质的一处差异

换算为美元 智谱 MiniMax
2026-06-30 类现金 6.70 亿 13.23 亿
七月融资 配售净额 40.0 亿 配售 12.05 亿 + 可转债 8.21 亿 = 20.26 亿
备考流动性 约 46.7 亿 约 33.5 亿
年化经营烧钱（推算） 约 9.5 亿 约 8.6 亿
已知刚性偿付 银行贷款 3.31 亿（无担保，可续） 2027 年到期可转债 8.29 亿（零息）
扣除后跑道 约 4.6 年 约 2.9 年

智谱期末现金只有 MiniMax 的一半，七月那笔配售改变了全局： 19,780,000 股新 H 股，每股 1,588 港元，净额 313.75 亿港元 ，是它 6 月 30 日账上现金的 6.8 倍、上半年收入的 28.5 倍，摊薄只有 4.4%。此外 A 股科创板拟募资不超过 150 亿元仍在推进。

MiniMax 七月同样融了两笔，但 可转债 2027 年到期、期限不足 18 个月、转换价 335 港元 。若届时不能转股，就是 8.29 亿美元的现金流出。已知金额、已知时点的硬约束，智谱没有对应项。

补一句自我修正。七月之前包括我们自己在内的判断是"智谱跑道不足 2 年，回 A 融资是生存必需"。 七月这笔 272 亿元人民币的配售把这个判断推翻了。 对处在融资窗口开启期的公司，用现金跑道做核心风险指标是脆弱的。

六、收入质量与组织效率，各占一半

智谱 MiniMax 谁更好
应收周转天数 约 149 天 60.8 天 MiniMax
减值损失／收入 2.9% 0.95% MiniMax
合约负债／半年收入 31.7% 15.7% 智谱
按时点确认收入占比 89.6% 70.7% MiniMax
人均年化创收 28.9 万美元 41.0 万美元 MiniMax
人均年化薪酬 14.6 万美元 24.3 万美元 各有取舍

MiniMax 回款明显更好。智谱背着历史本地化项目制应收的包袱，新增应收又主要来自云端大客户账期：本报告期本地化收入只有 1.29 亿元，应收账款净额却增加 4.80 亿元，增量必然来自 API 业务的大客户信用。智谱这里还有一处没解释的矛盾， 6 个月以上账龄桶半年增长 248.6%，坏账拨备率却从 10.6% 降到 7.3% 。

智谱的收入能见度更好，订阅预收占半年收入 31.7%，是 MiniMax 的两倍厚。

组织上 MiniMax 是 568 人，智谱 981 人。但两家有一个完全一致的结构： 研发开支的绝大部分不是人，是算力。 智谱研发 21.31 亿元对全公司薪酬 4.82 亿元，非人力占比约 84%；MiniMax 约 77%。用互联网软件公司的人效框架看这两家，会得到错误结论。

七、估值：市值差 4.57 倍，收入差 1.22 倍

按 2026 年 8 月 31 日收盘市值，两家均为港股，可直接比较：

智谱 MiniMax 倍数
市值 5,564 亿港元 1,219 亿港元 4.57 倍
1H2026 收入 1.420 亿美元 1.166 亿美元 1.22 倍
市销率（滚动 12 个月） 约 324 倍 约 94 倍 3.44 倍

上面六节呈现的事实是：智谱在收入规模、毛利率、增量毛利率、B 端赛道份额、资金跑道上占优；MiniMax 在回款质量、人均效率、总收入环比斜率上占优；两家在烧钱强度、研发投入、毛利率塌陷方向、预付算力的黑箱、披露完整性上高度雷同。

这些差异能否支撑 3.44 倍的市销率差距，本文不给答案。

八、结论与检验点

这是两家被同一条成本曲线约束、正在向同一条 B 端赛道收敛、同时遭遇毛利率塌陷的公司。 上半年它们花掉了几乎一样多的钱，智谱换回了多 22% 的收入、多 80% 的毛利和多 66% 的 B 端 API 份额，MiniMax 换回了更好的回款质量和更高的人均效率。智谱的资金安全垫是当下最实质的质地差异，MiniMax 的 2027 年可转债是最实质的时间约束。

但比两家相对优劣更重要的，是两份报表共同指向的那个事实：大模型 API 生意目前的毛利结构更接近算力转售，不是软件。在毛利率结构稳定下来之前，这门生意还不具备可估值的条件。
