重点事实核对

  • 当前 API、发布日期权重和更新后的 API 快照分别判断。DeepSeek-V4 的后续 API 版本不自动视为与初始公开权重逐字节一致；Qwen3.8 API 的能力也不直接套到其公开文本权重上。
  • GLM-5.3 与 GLM-5.2 的仓库张量总数均为 753,329,940,480。报告未把 GLM-5 原版的 40B 激活参数直接当作 5.3 的新披露。量化打包、额外预测层等统计口径仍需工程层面核对。
  • Kimi K3、Qwen3.8、GLM-5.3、MiniMax M3 和 Mistral Modified MIT 的商业条款分别读过正文；不同阈值涉及的收入期间、关联方范围和适用业务不同。
  • NVIDIA Nemotron 3 Ultra 当前模型卡链接 OpenMDW 1.1，Super 链接 NVIDIA Nemotron Open Model License；两者分别列示。Solar Open 权重采用 Upstage Solar License，代码的 Apache 2.0 不能替代权重许可。
  • 独立能力分数引用 Artificial Analysis 的 2026-09-03 Astra 专题，保留模型档位、工具环境与日期。厂商代码评测保留来源及不同测试环境限制，未把两个指数或两种证据混成统一总排名。
  • 未找到官方参数的 GPT、Claude、Gemini 等旗舰保留“未披露”。ERNIE 5.1 的约 0.8T 明确是基于官方相对比例的推算。

算术与文档核查

按项目要求运行 python3 tools/financial_rigor.py calc --expr ... 共 44 次，覆盖 4 个固定 token 用量的 API 费用示例、1 个参数比例推算和 39 个权重存储量单元格。输出保存为 算术记录。

此外，用 Python Decimal 从十进制字符串独立核对全部 44 项，并将存储表的 39 个单元格逐个与计算结果比较，全部一致。工具的显示行会对金额保留两位小数，因此 GLM 费用采用完整值 0.184 美元。2.4/3 的工具内部输出出现浮点尾差，Decimal 结果为精确 0.8；未将尾差带入报告。此次没有修改项目计算工具。

两份报告均运行了项目审计提取器：

python3 tools/report_audit.py extract --report <报告路径> --seed 20260906 --dry-run

旗舰报告提取 108 个数据点、抽样 17 个；参数报告提取 183 个数据点、抽样 28 个。原始输出保存为 旗舰报告抽检提取和 参数报告抽检提取。

这个工具主要针对财务报告，运行成功不等于技术事实审计通过。 它会把 GPT-6 中的版本号识别成负数，把模型编号当成财务数据，并提示查询股票数据网站。因此，此次仅保留提取结果，参数与许可逐项回到官方技术来源核对，没有据此生成虚假的“全部审计通过”结论。

补充文档检查包括表格列数、文件内链接目标存在性、厂商行数、计算表一致性及证据清单生成。结果保存在 文档检查记录。

尚未验证的部分

本次未付费调用模型做统一测试，未下载 TB 级完整权重，未验证每款模型的训练可复现性，也未代表用户接受受限仓库许可。模型卡宣称的长上下文上限不保证每个账户和硬件配置均能达到。

API 定价只列本次成功核实的官方费率，不包含所有地区、托管商、订阅套餐和临时优惠。闭源旗舰的未披露参数、部分更新型号的精确激活量及各版本权重与 API 的对应关系，仍然保留为空白。两份报告是有时间截止的技术资料，后续版本和许可证修改需要重新核验。
