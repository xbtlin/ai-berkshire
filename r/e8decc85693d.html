6. 分部正常化利润（研究估计）

目的：把TTM归母330亿元里的公允价值变动、股份薪酬、汽车与芯片主动投入分开，得到可用于市盈率分母的"正常化税后归母"。

第一步，取公司经调整净利润TTM作起点：391.66 + 122.91 − 215.06 = 299.51。公司经调整口径已剔除投资公允价值变动（TTM净剔除−129.08）、投资者金融负债价值变动（+32.40）、收购无形资产摊销（+1.44）与相应所得税（+11.54），并加回股份薪酬（+53.22），来源为两份公告的非国际准则调节表。

第二步，扣回股份薪酬（不做税盾，公告未披露其可抵扣部分）：299.51 − 53.22 = 246.29（正常化A，含汽车分部亏损）。

第三步，汽车与AI分部经营亏损归零：四季经营损益+7、+11、−31、−26，TTM合计−39亿元；TTM实际税率 = (80.80+30.96−48.05)/(496.47+172.94−275.71) = 16.2%；246.29 + 39×(1−16.2%) = 278.98（正常化B）。

第四步，再把芯片投入归零：按公司公开口径2025年约60亿元；278.98 + 60×(1−16.2%) = 329.27（正常化C）。这一步假设性最强，60亿是新闻口径而非报表数。

对照：手机×AIoT分部推算经营利润，2026Q1 = 178.16 − 792.77×14.9% ≈ 60.0亿，2026Q2 = 168.17 − 840.26×14.2% ≈ 48.9亿（毛利与营业费用率均出自公告，费用率为公司披露的分部口径）；2025Q3、Q4未披露分部费用率，不推算。两季年化约220亿元，加互联网以外的财务收入、补贴等，与正常化A的246亿元在同一量级。

若汽车分部已转盈（如2025Q3、Q4），正常化利润与报表利润的差异来源就只剩三项：公允价值变动（TTM+144.27，报表口径）、股份薪酬（53.22）、其他收益净额与补贴类其他收入（TTM其他收入55.21、其他收益净额22.06，其中补贴具有周期性）。换句话说，报表归母330亿 ≈ 正常化A 246亿 + 公允价值等非经营净贡献约84亿。

7. 2036年度利润的业务驱动情景

统一公式：各业务2026研究收入基数 × 十年收入增长因子 × 2036经济净利率 + 常态净利息收益。 经济净利率已负担研发（含芯片）、股份薪酬、足额折旧、营销、总部分摊、税项，不含公允价值变动。

2026全年研究收入基数：智能手机1750、IoT与生活消费1100、互联网服务370、智能电动汽车及AI等1050。参考2026上半年实际（863.9、559.6、185.1、447.6）与下半年季节性、55万辆目标的折扣（研究估计2026交付45至50万辆、ASP约23万元）。不是公司指引，也不是上半年机械翻倍。 2026校核：1750×2% + 1100×5% + 370×45% + 1050×(−3%) + 40 = 265亿元，落在正常化A（246）与B（279）之间。
