3. 股价跌破 220 后，这些投资会取消吗？——不会（两笔都不会）🟢

问题 结论 机制
配售 95 亿会取消吗 不会 一般授权直配、当晚按 268 固定价分配，承配人拿到即受约束；价格风险定价即转移，破发是承配人自担的市场风险，非可撤销事由。MAC 条款仅投行可行使、门槛为战争/停市级，个股跌 17% 够不上
可转债 65 亿会取消吗 不会，公司照拿 65 亿现金 CB 与配售相互独立、互不为条件，已按面值认购完成，现金与股价无关
CB 持有人会怎么做 不转股，持有到 2027 到期收本金 现价 222 << 转换价 335，深度价外；零息债"债底"保护下，理性选择是持有到期收回本金
对公司的净影响 预期约 1940 万股转股稀释大概率不发生，但 65 亿现金已到手（股权融资变到期还的债） —

4. 可转债的本质：公司零息借款，代价是卖了一份自家股票的看涨期权 - 投资人肯 0 利息借钱，是换来"股价涨过 335 就转股赚钱"的期权；转换价 335 = 期权行权价，天生定在发行时股价（参考价约 297）的约 +12.6% 溢价上，所以高于现价 - 转换价 335 是"换股兑换比率"，不是现金赎回价；到期不转股按面值 100% 收回本金（零息、无利息），不存在"每股 335 现金" - 三种情形： - 股价长期 < 335（当前 222 即此档） → 期权作废，公司等于零息白用一年钱，到期用现金还 65 亿本金；对 CB 投资人最差（白干一年、不如买货基） - 股价冲过 335 → 投资人转股，相当于公司以 335 卖股、老股东被稀释（若届时股价远高于 335 则等于贱卖股权） - ⚠️ "零息"前提：若为纯零息、按面值发行与赎回则真 0 成本；不排除"零票息 + 到期溢价赎回（如约 102%）"结构带来个位数隐含年化——赎回价是否恰为 100% 未从港交所原文确证 - 一句话：这轮 160 亿里，95 亿配售是"真稀释"（股数增约 10%、公司拿 95 亿）；65 亿可转债现在是"名义股权、实为债"（没人会转，大概率到期用现金还本金）
