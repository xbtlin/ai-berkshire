一句话结论

MiniMax 是中国大模型"六小虎"里最像一家产品公司、而非纯模型实验室的一家：语音最强、文本走"开放权重＋极致性价比"错位竞争、视频掉队、消费App出海最彻底。它的模型绝对能力属第二梯队，靠低价在 OpenRouter 打出高吞吐、低毛利的次头部位置。护城河不是某一条又宽又深的河，而是 "全栈多模态 × 成本效率 × 出海分发"三个中等深度差异点的叠加——能带来先发和规模优势，但抵御不了巨头的资本与分发碾压，属于会随时间被侵蚀的组合型壁垒，而非越挖越深的结构型壁垒。

巴菲特："我要找的是被宽阔护城河围绕的经济城堡。" —— MiniMax 有城堡（产品线最宽），但护城河是几道浅沟的叠加，不是一条深堑。

MiniMax 现役旗舰 Hailuo 2.3（2025-10）未进入任一榜可见前列（文生视频前25、图生视频前12 都没有）。历史高点是 Hailuo 02 于 2025-06 冲到图生视频 #2，一年内被全面反超。官方主打 WorldModelBench"物理冠军"和成本（约 $0.28–0.30/条，对比 Runway ~$1.20、Sora ~$3.50），但无原生音轨、榜单已掉队。参见同目录快手可灵报告——视频是一条"三个月换一次王座"的红海，海螺在其中只剩"中游 + 便宜"。

MiniMax 有音乐生成模型，但目前无被广泛采用的第三方音乐榜，无排名数据。

各模态水平小结：语音 ★★★★｜文本-Agent ★★★｜视频 ★★｜——一句话画像：性价比/开放权重路线的第二梯队全能选手，语音最强、文本靠低价错位、纯推理与视频落后头部。

三、OpenRouter 真实分量：按 token 是准头部，按美元是中游

OpenRouter 是全球开发者用真金白银"投票"的地方，最能反映一个模型的真实调用量。

⚠️ 数据可信度警示：OpenRouter 官方 rankings 页为动态加载、无法程序化取精确值；下列用量/花费数字全部为二手汇总，且源间互相冲突（部分站点疑似 AI 内容农场），只能锁定"量级与相对位置"，不可作硬引用。唯一一手可硬引的是定价与规格。

3.1 Token 使用量（绝对量 + 排名）【估计，二手，中低可信】

口径 数值 排名 来源/日期
MiniMax-M3 token 吞吐 ~4.53 万亿/月 编程类 #2；全站约前 10–15 codesota 2026-06
MiniMax 家族合计 — 约占全站 3.8% codesota 2026-06

参照系【二手】：全站总量 2026 年中约 100 万亿 token/月；按 token 榜首是 DeepSeek V4 Flash（~10.9万亿/月），中国系模型合计约占全站 46%，DeepSeek 单家 ~17.6%。MiniMax 不是 DeepSeek 那种统治级 #1，也不是长尾，是靠编程/Agent 场景和低价撑起的次头部。

3.2 token × 价格 = 花费量（≈第三方收入代理）【估计，写明算法】

以相对最可信的 M3 ≈ 4.53 万亿 token/月为基数，用官方定价校验： - 假设编程/Agent 流量 输入:输出 ≈ 75%:25% - 输入：0.75 × 4.53M(百万) × $0.30 ≈ $1.02M - 输出：0.25 × 4.53M × $1.20 ≈ $1.36M - 合计 ≈ $2.4M/月，与二手来源直接给出的 $2.5M 吻合 → 量级可信

结论：MiniMax 在 OpenRouter 的月度推理花费约 $2.4–2.9M/月，全站占比约 3.8%，年化约 $29–35M（2026年中），几乎全部由 M3 撑起。

关键结构性事实——按 token 排名远高于按美元排名：全站按美元 spend 头部是 Claude Sonnet 4.6（$20.9M/月）、Opus 4.8（$16.3M），Anthropic 占全站美元约 67%（量少价高）；MiniMax 恰好相反——量大、价低、毛利薄。这既是它的打法，也是它的软肋：token 份额可以很高，但换不成同等比例的收入。

四、商业基本面【事实，来源港交所披露＋2025年报】

4.1 上市与估值（校正一个常见误解）

  • 2021-12 成立于上海，创始人闫俊杰（CEO，出自商汤），早期由米哈游投资。
  • 融资：A轮（2023-06）>$2.5亿（腾讯领投）→ B轮（2024-03）$6亿（阿里领投，投后 $25亿）→ B轮延伸（2025-07）~$3亿（投后 ~$40亿）。
  • 2026-01-09 正式登陆港交所（00100.HK），被称"史上最大 AI 大模型公司 IPO"，发行价 165 港元，公开发售 1837 倍超额认购，14 家基石（阿里、阿布扎比 ADIA、Mirae、易方达等）。首日盘中一度涨超 50%，市值一度约 750–760 亿港元（≈$98亿）。
  • 上市数月后再融资约 $20亿（新股+可转债）。

校正：同目录快手报告里"MiniMax 独立上市、估值约 40 亿美元"——那 $40亿 是 IPO 前（2025-07）的一级市场估值，不是上市市值。它已上市，市值随行情大幅波动：IPO 日约 $98亿、3 月峰值约 $525亿（4100亿港元）、7 月解禁后回落到约 $117亿（910亿港元，详见第七节）。

4.3 月度 ARR 走势与 2026 营收预测（用户重点·来源已分级核验）

季度节奏 — 前三季季均 $5.14M Q4 直接翻倍

① B端贡献了约 90% 的毛利，却只占 33% 的收入【🟢事实+推算】：2025 年 B端毛利 ≈ $18M，而全公司总毛利仅 $20.1M——占 67% 收入的 C端（陪伴+视频 App）毛利率只有 4.7%、贡献约 $2.5M。MiniMax 表面是家 C端出海公司，利润表上其实是家 B端 API 公司：C端走量讲故事，B端赚钱。

② B端是最快、且在加速的一条腿：占比 2024 全年 28.6% → 2025 全年 32.8% → 2025 Q4 单季 41%；增速全年 +197.8%、Q4 单季提速到 +278%。驱动来自 M2.7 + Coding Plan + 企业客户破 100 万。Q4 B端已到约 $42M 年化 run-rate。

③ B端 ARR 的口径陷阱（对比智谱务必看这条）⚠️： - 官方披露的 $1.5亿(2月)/$3亿(5月) ARR 是全公司总口径，含 C端订阅，不是纯 B端。 - 硬数字：B端 2025 年底退出 run-rate 约 $42M（~$0.42亿）（由 Q4 $10.54M 单季推出，🟢可靠）；B端-only ARR 官方未单列，粗估 2026 年中约 $0.5–1.2亿【估计】。 - 和智谱不可直接比：智谱 $2.5亿 是纯 MaaS/API ARR——单论 B端，智谱仍是 MiniMax 的约 2–4 倍；MiniMax $3亿 总 ARR 有一大半靠 C端撑。

把 B端当独立公司：一门 $26M 收入、69% 毛利、~200% 增速的类 SaaS 生意，质地漂亮，但绝对体量小；两个夹击是——DeepSeek/GLM 开源价格战会压 69% 毛利，且高吞吐里有一块是 OpenRouter 上低价的 coding/agent 流量（量大价低，未必长期守住 69%）。

落点：MiniMax 真正的当期利润与估值锚，是这条 33%、69% 毛利、翻倍增长的 B端曲线——能否在价格战里守住毛利、并把占比从 41% 顶上 50%+。C端是流量/数据的护城河候选，B端才是眼下赚钱的引擎。

五、核心问题：MiniMax 能满足什么别人满足不了的需求？

【观点，基于上述事实】MiniMax 的独特处不在任何单点最强，而在三者同时做出规模：

  1. 全栈多模态一家做齐——文本推理 + 视频（海螺）+ 语音/音乐 + Agent/编程 + C端陪伴App。DeepSeek（纯推理）、Kimi（语言/Agent）、智谱（语言）都没有同等宽度；只有阿里/字节这种巨头才有可比广度。"一家创业公司做到巨头级产品宽度"本身是稀缺的。
  2. "廉价的百万级上下文 + 原生多模态"打包进开放权重（M1/M3）——满足"既要长上下文、又要多模态、还要能自部署、还便宜"的组合需求。
  3. 出海陪伴App的真实付费用户与数据——Talkie 过半美国用户、总口径 ARR 已达 $3亿（2026-05）、海外收入 >70%，这是纯 API 型对手（DeepSeek）不具备的分发与数据资产。

所以它满足的"别人满足不了"的需求，本质是一个组合需求：想要多模态全家桶、又要极致便宜、又要能自部署、还带出海消费入口——单看每一项都有更强的专才，但打包在一起、还便宜，目前只有 MiniMax 这一档创业公司在提供。

六、护城河逐条盘点：证据强弱 + 反面

# 候选护城河 证据强弱 说明 易被复制性
1 线性/闪电注意力的成本-长上下文经济学 ★★★★ 有论文+工程实证：M1 全 RL 训练仅 512张H800、3周、~$53万；100万上下文、算力为 R1 的 30%；M2 价格为 Claude 8% 架构优势可被复制，DeepSeek/Qwen 也在做稀疏/线性注意力

4 AI陪伴App数据+分发（Talkie/星野） ★★★ 有真实收入与用户 留存下滑 + 监管下架，陪伴类忠诚度与合规风险双高

【核心判断】MiniMax 没有一条又宽又深的护城河，它的壁垒是"多个中等深度差异点的叠加 + 早期形成的出海消费数据/分发飞轮"。 证据最强的是"成本-长上下文经济学"和"出海占比"；最弱、最易被侵蚀的是"开放权重"和"Agent 低价"——而后两者恰恰是它当前 OpenRouter 分量的来源。这是个隐忧：撑起它今日声量的那部分，护城河最浅。

反面·被碾压的四条风险线： 1. 财务未自我造血：2025年 $79M 收入 vs 经调整 $2.5亿 亏损；2026 全年收入预计也仅 $2.2–3.0亿，IPO 后又配售+可转债融约 $20亿，高度依赖持续融资。 2. 开源=零锁定→价格战通缩：模型开源意味着客户零迁移成本，DeepSeek/GLM 的 MIT 免费会持续压 MiniMax 的 API 变现。 3. 投资人即对手：阿里既是最大机构股东、又用 Qwen 正面竞争；字节（豆包/Seedance）、腾讯的资本+分发是碾压级投入。 4. 消费App监管/地缘风险：Talkie 美区下架、陪伴类隐私审查、出海高占比放大此风险。

八、结论：三段式判断

① 独特价值 —— MiniMax 是中国大模型公司里唯一把"全栈多模态 × 极致成本效率 × 出海消费分发"三者同时做出规模的一家，是"最像产品公司"而非"纯模型实验室"的一家。这是它能在 OpenRouter 拿到编程类第二、又能上市成"最大 AI 大模型 IPO"的底层原因。

② 核心护城河 —— 没有一条又宽又深的护城河；壁垒来自"多个中等深度差异点的叠加 + 出海消费数据/分发飞轮"。 证据最强的是成本-长上下文经济学和出海占比，最弱的是开放权重和 Agent 低价。这类系统性组合壁垒能带来先发与规模优势，但抵御不了巨头的资本与分发碾压——是会随时间被侵蚀的组合型壁垒，不是越挖越深的结构型壁垒。

③ 主要风险与落点 —— 商业化与竞争的双重挤压：财务尚未自我造血、开源价格战持续商品化、阿里/字节/腾讯正面碾压、消费App监管地缘风险。投资判断应紧盯两个变量：ARR 增速能否持续跑赢烧钱（官方口径 ARR 已从 2 月 $1.5亿 冲到 5 月 $3亿，年底券商测算 $8–10亿，vs 经调整年亏 $2.5亿），以及出海合规是否失控。 在护城河会被侵蚀的前提下，MiniMax 的价值取决于它能否在壁垒被填平之前，把出海消费飞轮转到自我造血——这是一场和时间赛跑的生意。

李录："投资的本质是理解一门生意的长期竞争格局。" —— MiniMax 的长期格局，赌的不是模型永远领先（它不会），而是在被商品化之前，先用多模态和出海把用户习惯锁死。这一点，和快手可灵那篇的落点是同一句话：在一个技术三个月换一次王座的行业里，唯一不贬值的资产，是客户改不掉的习惯。
