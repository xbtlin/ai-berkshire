分析视角：竞争格局、行业演变、逆向思维 研究日期：2026年5月16日

一、行业全景：中国OTA市场的竞争格局

1.1 市场规模与格局

2025年中国在线旅游市场规模突破1.5万亿元。按GMV计算的市场份额分布：

平台 GMV份额 核心优势 主战场
携程 ~56% 品牌+商旅+国际化 一二线城市+出境游
同程旅行 ~15% 微信入口+下沉市场 三四五线城市
美团 ~13% 本地生活场景延伸 酒店+周边游
飞猪 ~8% 阿里生态+年轻用户 度假+海外酒店
抖音 ~3%（快速增长） 内容种草+直播 景区+度假酒店

1.2 行业特征

芒格强调要理解行业的"生态位"。中国OTA行业有几个关键特征：

  1. 赢家通吃倾向强：携程以56%份额占据绝对主导，OTA是典型的规模效应行业
  2. 但非一家独大：不同于搜索或社交，旅行决策多元化，允许差异化玩家存在
  3. 新进入者威胁真实存在：抖音用全新模式切入，证明行业并非铁板一块
  4. 从佣金战转向效率战：行业已过了粗放竞争期，进入精细化运营阶段

二、同程的竞争定位：夹缝中的第三名

2.1 错位竞争策略

同程旅行的核心生存策略是错位竞争——避开与携程在高端市场的正面对决，深耕携程"不屑于做"或"做不好"的下沉市场。

维度 携程 同程 美团
目标用户 商务+高端 大众+下沉 本地生活
核心产品 机票+高星酒店 火车票+中低星酒店 到店酒旅
获客方式 品牌+搜索 微信入口 外卖导流
ARPU 高 中低 中
毛利率 高（32%+） 中（约70%毛利率） 中
净利率 高（25%+） 中（17.5%） 低（OTA部分）

2.2 同程的比较优势

对比携程的优势： - 下沉市场触达能力更强（微信小程序零门槛） - 火车票/汽车票领域市场份额更高 - 获客成本更低（依托微信自然流量）

对比美团的优势： - 旅行场景更垂直、更专业 - 交通业务（机票+火车票）是美团的短板 - 长途旅行场景覆盖更好

对比抖音的优势： - 确定性需求满足能力更强（用户已有明确出行计划时） - 交通票务供应链成熟度高 - 售后服务体系相对完善

三、竞争动态：各方在做什么？

3.1 携程的"下沉"

携程已明确将下沉市场列为战略方向，通过： - 推出"携程旅行"之外的低价产品线 - 加大在三四线城市的地推和广告投入 - 利用品牌势能吸引下沉酒店供应商

对同程的影响： 携程的下沉是"降维打击"，品牌力和供应链整合能力优于同程。但携程的下沉是"第二曲线"而非主业，投入力度和持续性存疑。

3.2 美团的"旅行化"

美团从本地生活延伸到旅行，优势在于： - 超高频的外卖/到店流量 - 自然的"周边游"场景延伸 - 酒店业务已形成规模（尤其中低星）

对同程的影响： 美团在中低星酒店领域与同程直接竞争，且美团的流量更大、频次更高。但美团的旅行用户多为"周边游短途"，长途出行场景仍是同程的优势区。

3.3 抖音的"颠覆"

抖音2025年生活服务GMV超8500亿，同比增长59%： - 通过达人探店、景区直播改变用户决策路径 - 在目的地营销和度假酒店领域形成独特优势 - 2026年目标增速50%，持续高速扩张

对同程的影响： 抖音对同程的冲击可能比对携程更大。原因在于：同程的下沉市场用户恰好是抖音的核心用户群——三四五线城市、价格敏感、决策容易受内容影响。抖音不需要"抢走"同程的用户，只需要在用户旅行决策的上游（信息获取阶段）截流。

3.4 12306与航司直销

铁路12306和各航空公司持续优化直销渠道： - 12306功能日益完善，用户体验改善 - 航司通过自有APP、小程序直接触达用户 - OTA在交通领域的中间价值被持续压缩

四、芒格的逆向思维：什么情况下同程会失败？

4.1 "反转"思维——假设同程失败了，原因会是什么？

  1. 微信入口被取消或弱化：腾讯战略调整，不再给予同程排他性入口
  2. 下沉市场饱和：三四五线城市用户渗透率见顶，增长空间耗尽
  3. 抖音重塑决策链路：用户不再通过OTA平台决策，而是在内容平台完成种草到下单的全流程
  4. 价格战重启：行业竞争加剧，各方重回烧钱模式，利润率崩塌
  5. 技术变革：AI彻底改变旅行预订模式，传统OTA失去存在价值

4.2 上述风险的概率评估

风险 概率 影响 综合
微信入口变化 低（20%） 极高 ★★★☆☆
下沉市场饱和 中高（60%） 中等 ★★★★☆
抖音截流 中（40%） 高 ★★★★☆
价格战重启 低（15%） 高 ★★☆☆☆
AI颠覆OTA 低（10%） 极高 ★★☆☆☆

4.3 "如果我不能拥有这家公司，我会怎样攻击它？"

如果我是美团/抖音，我会： - 在微信生态内做旅行入口（美团已有微信小程序） - 用更高频的场景（外卖/短视频）持续触达同程的用户 - 在酒店供应端给予更高佣金比例，挖走同程的供应商 - 用内容（短视频/直播）在决策上游截流

同程能防守多少？ 部分能防守（微信入口的排他性、火车票供应链的深度），但在酒店和度假领域防守难度较大。

五、行业演变：未来3-5年会发生什么？

5.1 芒格的"世俗智慧"应用

趋势一：AI重塑旅行决策 - 未来用户可能通过AI助手完成旅行规划和预订 - 同程的"程心大模型"是应对措施，但AI时代的竞争壁垒可能重新洗牌 - 关键问题：AI时代，用户入口会变吗？

趋势二：内容电商侵蚀搜索电商 - 旅行决策从"搜索型"向"推荐型"迁移 - 抖音/小红书等内容平台成为旅行灵感来源 - 传统OTA需要从"货架"升级为"内容+货架"

趋势三：下沉市场从增量转存量 - 后疫情旅行复苏红利消退 - 下沉市场用户增长趋缓，竞争转向存量用户的ARPU提升 - 同程需要证明能在存量竞争中胜出

趋势四：轻资产酒管成为新赛道 - 同程收购万达酒管+艺龙酒店科技，布局酒店品牌管理 - 如果成功，将从OTA佣金模式拓展到酒店品牌管理费模式 - 这是携程也在做的方向，竞争不会轻松

5.2 同程在行业演变中的位置

有利因素： - 下沉市场旅行渗透率仍有提升空间（vs一线城市已饱和） - 大众旅游市场增速仍高于高端旅游市场 - 微信生态的流量成本远低于公开市场获客 - 酒管业务如果整合成功，将提供新的利润增长极

不利因素： - 行业增速自然放缓是大趋势 - 竞争对手纷纷布局下沉市场 - 内容平台对传统OTA的冲击是结构性的

六、行业竞争综合评分

竞争格局稳定性 ★★★☆☆

OTA行业格局整体稳定（携程一家独大），但在同程所在的细分市场（下沉+中低端），竞争正在加剧。抖音和美团的进入带来了结构性变化。

同程的竞争位置 ★★★☆☆

第三名的位置相对稳固（短期内不太会被超越），但距离第一名差距巨大。面临上有携程压顶、下有美团/抖音围攻的"夹心"困境。

行业长期吸引力 ★★★★☆

旅行是长坡赛道，随着人均收入增长和休闲需求升级，行业长期增长确定性高。但OTA环节的价值占比可能因去中介化和内容化趋势而被压缩。

同程的应对能力 ★★★☆☆

管理层在积极应对（AI、国际化、酒管），但资源有限、多线作战，执行效果有待观察。

综合行业竞争评分：★★★☆☆（3.0/5）

芒格可能会说：这是一个"还不错的行业里的第三名"。行业本身有长期增长的确定性，但同程的竞争地位并非不可撼动。最大的风险不是某个单一竞争对手，而是行业底层逻辑的变化——当用户的旅行决策从"搜索型"变成"推荐型"时，传统OTA的护城河就会被重新定义。
