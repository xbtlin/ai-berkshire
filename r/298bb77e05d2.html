筛选条件：晨星经济护城河评级为"宽"（Wide Moat），且公允价值相对现价的上涨空间 ≥ +74%

数据截止：2026-08-17（美股价格为 2026-08-14 收盘）

覆盖市场：美股、港股、A股、欧洲、日本、澳洲、加拿大、巴西、台湾、新西兰

一、口径换算

"公允价值比现价高 +74% 以上"换算成晨星的 Price/Fair Value 口径：

上涨空间 = 公允价值 / 现价 - 1 ≥ 0.74
        → 现价 / 公允价值 ≤ 1 / 1.74 = 0.575
        → 折价 ≥ 42.5%

即 P/FV ≤ 0.575 。

这个门槛比晨星"五星"更严。晨星五星只要求折价到不确定性评级对应的档位，高不确定性股票折价 30%–40% 即可获五星，因此五星股中相当一部分够不到本次门槛。

三、反推法的误差验证

对两家同时拥有"公开发布公允价值"和"官方 P/FV"的公司做对照：

WiseTech Global A$38.00 ÷ 0.29 = A$131 A$130（2026-07） 0.8%

误差均在 1% 出头，方法可用。

另有一次双路径互证：腾讯用 ADR 口径（公允价值 $102）与用港股口径反推（HK$795）算出的上涨空间同为 +77% 。

反推法的前提：晨星自 2026-06-05 以来未调整该股公允价值。对已知期间有调整的（如阿里巴巴于 2026-07-08 下调至 $241），一律采用公布值而非反推值。

勘误（2026-08-17）：本报告初版称阿里公允价值"于 2026-07-06 上调（此前约 $219）"，该说法错误，现已更正。$219 是笔者由 6 月指数 P/FV 反推的推断值，并非晨星发布数据。经核对 24 份晨星股票分析师报告原件确认：晨星是下调——道琼斯 2026-07-08 原标题为"Fair-Value Estimate Cut by 7% to $241"，前值 $258（2025-11-18 设定）。$219 在晨星 ADR 序列中从未出现。详见 reports/Alibaba/阿里巴巴-晨星估值视角-20260817.md 。

这一更正同时暴露了反推法的一个失效场景：当指数 P/FV 与个股公允价值的口径或时点不一致时，反推会得出根本不存在的数值。阿里当时反推得 0.566 而晨星实际为 0.514，笔者已察觉不一致但误判为"公允价值上调所致"，方向判断反了。凡是反推值与公布值冲突的，一律以公布值为准，且不得据反推值倒推变动方向。

五、逐家简介与护城河理由

1. WiseTech Global（ASX:WTC）— +208%

澳洲物流软件公司，核心产品 CargoWise 是国际货代（海运空运、报关合规）的操作系统。

晨星护城河理由：转换成本 + 网络效应。货代一旦把全球操作跑在 CargoWise 上就极难迁移；物流业当前数字化率很低，而物流服务市场天然选择低成本供应商，数字化作为降本核心手段是必然趋势——要么企业主动数字化以保持竞争力，要么被数字化领先者夺走份额。

为什么折价这么深：股价一年跌约 70% 。创始人 Richard White 因涉嫌签证欺诈与人口贩运被澳大利亚联邦警察调查，2026 年 7 月卸任执行主席（保留董事与首席创新官职务），叠加市场对 AI 冲击软件公司的普遍恐慌。晨星因领导层变动把公允价值下调 6% 至 A$130，未来十年收入复合增速预测从 21% 降至 20% 。

关键点：下调之后，它仍然是全球折价最深的宽护城河股。晨星明确表态"尽管股价反弹，股票因 AI 恐慌仍显著低估"。

2. 耐克 B 类（NYSE:NKE）— +131%

全球运动鞋服龙头。

晨星护城河理由：品牌无形资产与长期定价权。晨星明确表态，直营转型失误和运动休闲趋势降温"并未实质损害"全球品牌无形资产或长期定价权。

估值路径：公允价值从 $112 → $102 → $94 逐级下调，但同期股价跌得更快。现价 $40.73，52 周区间 40.00–80.17，处于多年低位附近。晨星 DCF 模型假设三年内随运动科技创新推出、渠道库存折扣正常化，恢复至中个位数收入增长和十几个点的营业利润率。

3. Prosus（AMS:PRX）— +88~105%

荷兰上市的科技投资控股公司，净资产值约 2,110 亿美元。

晨星护城河理由：初次覆盖即给宽护城河，公允价值 €77 。其超过 80% 的净资产值来自持有腾讯 23% 的股权——护城河实质上是穿透过来的。

投资含义：本质是"折价买腾讯"，同时享受腾讯自身折价与控股公司折价的双重叠加。这也是它和腾讯同时出现在本名单的原因。若持有腾讯，需注意这两个标的高度相关，不构成分散。

4. 莱茵金属（ETR:RHM）— +97%

德国国防承包商。

晨星护城河理由：初次覆盖即给宽护城河（初始公允价值 €343，后经多次上调）。

基本面：2025 年国防收入增长 29% 至 99 亿欧元，营业利润增长 33% 至 18.4 亿欧元，利润率扩张至 18.5% 。现有订单覆盖 2026 年指引收入约 91%，2027 年覆盖 50%–66%，收入可见度高。晨星因德国采购从框架合同转向固定合同、现金流假设改善，将公允价值上调至 €2,380 。

注意：股价已从 52 周高点 €2,008 回落至 €1,210 。这个折价是股价腰斩打出来的，不是估值上调打出来的——需要判断市场在定价什么风险。

5. 阿里巴巴（NYSE:BABA / HK:9988）— +95%

淘天电商网络效应 + 阿里云。

晨星评级：五星，高不确定性评级 。公允价值 $241 —— 注意这是下调后的数字：2026-07-08 由 $258 下调 7%，完整轨迹为 $100 → 128 → 163 → 150 → 156 → 153 → 179 → 267 → 258 → 241 。港股 9988 现价 HK$122.80 。

需要注意的两点：其一，晨星模型以人民币计价，同期人民币升值 4.56%，掩盖了真实降幅——按人民币口径实际下调约 10.7%，而非表面的 6.6% 。其二，"五星"只隔 0.014：高不确定性档的五星门槛是 P/FV ≤ 0.60，阿里为 0.5137；若不确定性评级升至"极高"（门槛 0.50），公允价值一分不改，星级当天就掉到四星。

风险信号：高不确定性评级是本名单中唯一被晨星明确标注的——意味着晨星自己认为其估值区间很宽，DCF 结果对假设高度敏感。

6. Elekta B 类（STO:EKTA B）— +84~101%

瑞典放疗设备商。

晨星护城河理由：设备转换成本 + 技术无形资产。与西门子医疗形成双寡头，晨星预计未来十年全球放疗设备装机中两家合计约 95% 。

投资论文核心：押在 Unity 平台（磁共振引导放疗）上。晨星认为在数据有限的情况下，Unity 正在兑现疗效承诺。成败取决于三点——Unity 持续放量、改版产品与软件的成功、抵御西门子医疗竞争的能力。

估值：公允价值 SEK 108（2026-02 口径，当时折价约 50%），反推值 SEK 99 。现价 SEK 53.60 。

7. Campbell's（NYSE:CPB）— +141.7%

美国包装食品公司，罐头汤、Pepperidge Farm 饼干、V8 果蔬汁、Rao's 意面酱等品牌的持有者。

晨星数据：公允价值 $56（2026-03-20 设定，分析师 Erin Lash），现价 $23.165，P/FV 0.414，五星、Medium 不确定性、宽护城河 。

为什么重要：这是全球折价第二深的宽护城河五星股，仅次于 WiseTech，比耐克还便宜。而且它是 Medium 不确定性——按晨星方法论 Medium 档只需 30% 折价即给五星（P/FV ≤ 0.70），Campbell's 实际 0.414，在自身风险档位下的超额安全边际是全表最厚的 。

注意：本报告初版遗漏了这家公司，属数据源覆盖问题而非口径问题。它完全满足筛选条件，且其量化公允价值 $41.51 与分析师口径分歧达 −25.9%（量化星级仅三星），使用前建议自行深入研究。

8. 洋河股份（SZ:002304）— +92.2%

A股白酒。本名单中唯一符合条件的 A股标的 。

晨星数据：公允价值 ¥78（2026-04-28 设定，分析师 Jennifer Song），现价 ¥40.58，P/FV 0.520，五星、Medium 不确定性、宽护城河 。

数据更正：初版使用的 ¥75.4 是反推值，实测值为 ¥78，反推偏低 3.3% —— 即洋河实际比初版所写更便宜。

12.5 方法论教训：反推法的失效场景

初版大量使用"本币价格 ÷ 官方 P/FV"反推公允价值。经实测校验，该方法在洋河（−3.3%）、腾讯（+1.9%）上误差可接受，但存在一个致命失效场景：

当反推值与公布值冲突时，不能据反推值倒推变动方向。 阿里当时反推得 P/FV 0.566 而晨星实际 0.514，笔者已察觉不一致，却误判为"公允价值上调所致"——方向完全反了。

修订后的规则：

用途 数据源
公允价值、星级、不确定性、护城河、FV 设定日、分析师姓名 晨星筛选器 API（FairValueEstimate / StarRating / FairValueDate）
调整的理由、DCF 分解、十年预测、评级方法论 分析师报告原件 PDF（API 不携带这些）
交叉校验 用 API 的 FairValueDate 比对 PDF 页眉时间戳，不一致即说明 PDF 已过期

API 与 PDF 没有口径差异，只有时效差异——硕腾的 API 字段 FairValueDate = 2026-08-07 03:56:23 与 PDF 页眉 7 Aug 2026 03:56, UTC 精确到秒完全一致，证明两者读的是同一字段。风险全在 PDF 一侧：券商镜像只在有人请求时生成，不是每日归档，任意一份都可能已被后续修订取代。

反推法自此降级为校验手段，不再作为取数手段。

十三、分析师公允价值 vs 量化公允价值

深度研究中发现，晨星对同一只股票同时维护两套估值：分析师公允价值（FairValueEstimate，由具名人类分析师用三阶段 DCF 得出，星级由它驱动，也是公开页面展示的那个）与量化公允价值（QuantitativeFairValue，纯统计模型输出，对应独立的量化星级）。

晨星的官方定位是：有分析师覆盖时以分析师口径为准，量化口径用于覆盖分析师够不到的长尾标的。所以本报告用分析师口径筛选是正确的，不需要改。 但两套口径的分歧值得单列。

经此更正，真正站得住的只有两条：WiseTech 是九家中唯一被独立研究认定为绝对高估的（证据为公司口径现金流不含税与利息，真实自由现金流收益率 2.10% 低于澳洲国债）；阿里接近合理定价。其余七家的负面表述均过头。

准确的表述不是"晨星公允价值没用"，而是：它是一套均值回归工具，而过去十年是均值回归最不灵的十年。

15.3 公允价值本身的稳定性

阿里巴巴的晨星公允价值轨迹（经 24 份分析师报告原件页眉逐份核对）：

$100 (2024-08) → 128 → 163 → 150 → 156 → 153 → 179 → $267 (2025-09) → 258 → $241 (2026-07)

13 个月内从 $100 到 $267，区间 2.67 倍。 一家成熟公司的内在价值不会在 13 个月内变动 2.67 倍——该数列中相当一部分是在跟踪情绪与新闻，而非测量内在价值。

硕腾：五个月从 $171 砍到 $102（−40.4%），同期股价 $125.64 → $77.27（−38.5%），几乎 1:1 跟随股价。

但需注意反例：阿里同期公允价值 −9.7% 而股价 −29.4%，耐克公允价值 −16.1% 而股价约 −49%，WiseTech 公允价值 −5.8% 而股价约 −70% 。四家里三家，晨星在股价崩塌时基本没动公允价值。 深度折价恰恰是这种"不动"制造出来的。

所以晨星公允价值的特征是"黏"，不是"追涨杀跌"。 而黏本身是中性的——可能是有定力（市场错了它对），也可能是锚定不放（现实变了它没跟上）。本报告的证据不足以区分这两者。

15.5 本节未能做到的部分

MOAT 的业绩测的是"护城河评级 + 公允价值 + 指数规则"的组合，无法把公允价值的准确性单独剥离。 指数还含约 0.46% 管理费与换手成本，也会拖累业绩。

样本窗口仅十年（stockanalysis 历史数据上限），而 MOAT 实际 2012 年 4 月上市，2012–2016 段未纳入检验。

真正干净的检验尚未进行：取晨星历史公允价值全库，测算"设定后 1/3/5 年，股价相对当时公允价值的实际收敛程度"——系统性够不到即为偏乐观，超过即为偏保守。该检验需要晨星历史数据库权限，本次未能完成。

因此本节的结论应严格限定为：这套方法在过去十年的实盘中未能战胜指数，且公允价值数值本身不够稳定，故不适合当作精确的价值锚。它不构成"晨星公允价值系统性偏高"的证明。

十六、这份筛选的正确用法

当线索用，不当答案用。

十家公司在深度复核后，估值中枢全部低于晨星公允价值，差异从 28% 到 294% 不等。但同时，五家仍有 24%–50% 的独立口径上涨空间。这两句话不矛盾——它说明晨星的折价幅度需要自己重算，但折价本身往往是真的。

统计意义上的便宜，与生意意义上的便宜，是两回事。这份名单只回答第一个问题。

十七、多头红队轮：五份对抗性检验

17.1 为什么要跑这一轮

第十四节 14.5 已说明：九份深度研究的任务描述由笔者拟定，其中七份把"质疑晨星"直接写进目标，且无一份要求多头论证，构成系统性偏差。承认偏差不等于修正偏差，故对独立口径上涨空间 >23% 的四家（Prosus、洋河、腾讯、莱茵金属）、以及唯一被判绝对高估的 WiseTech，各派一个红队做对抗性检验。

红队的任务定义刻意不是"论证买入"，而是：攻击既有看空报告的每一条论断，并被明确告知——"若某条看空论据经检验站得住，你必须明说它站得住，不许为了立场硬拗；一份攻击 8 条、推翻 3 条、承认 5 条的报告，比全面翻案的报告有价值得多。"

每份红队报告均须产出逐条裁决表（推翻 / 部分成立 / 完全成立 + 证据），并同样通过 report_audit.py 15% 抽样准出。

17.3 五家各自最重要的一处推翻

Prosus —「套利不是投资」被数学推翻。 折价恒定不变时，每股 NAV 仍以 a = f·d/(1−f) = 2.16%/年 增厚。压力测试：折价永久锁死 38.29% 且全部资产零回报，五年仍 +11.3%；折价锁死 + 腾讯年涨 8%，五年 +66.9% 优于直接持腾讯的 +46.9% 。回报不依赖折价收敛。 另发现看空方模型把增厚率符号设反——折价越阔，同样美元买到的股份占比越高、增厚越快，而看空方在悲观情景里设了最低增厚率。

洋河 —「折价更深是模型伪像」的分母选错了。 详见 14.1c。换五年均值利润口径后结论反转：晨星 FV/五年均利，洋河 16.42x vs 茅台 29.29x 。

腾讯 — 看空方的"中性"其实是深度看空。 把其 SOTP 从 EV/Sales 换算成 EV/非IFRS经营盈利：悲观 8.14x / 中性 11.78x / 乐观 15.83x，而晨星 HK$780 对应 17.43x 。看空方自己写"17.4 倍并不离谱"，却给了一个比"不离谱"低 32.4% 的中枢且从未解释差额来源——因为 EV/Sales 口径把它藏住了。另查出方法论硬伤：用网易 P/S 4.76 去锚定 EV/Sales，而网易 EV/Sales 实为 3.42（净现金占市值 29%），凭空多给自己 39% 的"保守空间"。

莱茵金属 — cost-plus 论证坐实。 详见 14.2c 的通用动力内部分部对照。

WiseTech — 看空方混淆了两件不相干的事。 现金流口径造假完全成立且更严重（红队找到零误差路径：797.8 − 361.3 = 436.50 精确等于公司口径，436.50 − 69.5 = 367.00 精确等于法定 OCF；四个报告期全部吻合，1H26 高估已达 42.1%）。但这条完全不能解释 A$33 与 A$130 的差距——用税后口径干净的模型，仅凭晨星的 20% 收入增速即可推出 A$135。分歧 100% 来自增速假设，0% 来自现金流口径。 看空方把"公司披露不老实"与"晨星模型算错了"混为一谈，两者没有因果关系。

红队并非单向翻案，三份主动补强了对多头不利的证据：
