研究日期：2026年7月21日 | 分析对象：通义千问 Qwen / 通义实验室（现 Token Foundry 事业部）/ 阿里云AI

一、实力 ★★★★☆（4.5/5）

模型能力 - 2026年模型迭代节奏极快：2月春节发布 Qwen3.5 系列（397B总参数、激活仅17B的稀疏MoE，LMArena盲测中国第一、全球第五，🟡 CSDN/知乎技术社区，2026-02）；随后 Qwen3.6 成为开源旗舰（Apache 2.0协议）；5月20日阿里云峰会发布 Qwen3.7 系列，Qwen3.7-Max-Preview 为万亿参数模型，LMArena文本榜Elo约1450，进入"准前沿"梯队，与 Claude Opus 4.7/4.8、GPT-5.5 Pro、Gemini 3.1 Pro 大致同档（🟡 swfte/LMArena追踪站，2026-07）。 - 财报层面官方确认：Qwen3.6-Max-Preview 在 Artificial Analysis 登顶"最佳国产模型"，Qwen3.6-Plus 获 OpenRouter 全球大模型周调用量冠军（🟢 阿里FY2026Q4财报披露，新浪科技，2026-05-14）。 - 关键战略变化：Qwen3.7（Max/Plus）仅云端提供、未开源权重，开源前沿停留在 Qwen3.6（🟡 InsiderLLM等多家追踪站，2026-07）。这是 Qwen 首次出现"最强模型不开源"的迹象，需持续跟踪。

开源生态 - 截至2026年1月，Qwen 在 HuggingFace 累计下载约7亿次，2025年内超越 Meta Llama 成为全球下载量第一的开源模型家族；衍生模型超18万个（含Qwen标签合计超20万），超过 Google 与 Meta 之和（🟡 多家外媒/HF报告汇总，2026-01）。HuggingFace 2026春季报告：中国开源模型占过去一年Hub下载量41%，由 Qwen、DeepSeek 驱动（🟡）。 - 与 DeepSeek 的分工：DeepSeek 以"前沿能力+MIT协议+极致低价"做闭源平替、破圈叙事更强；Qwen 以"全尺寸谱系（0.6B到万亿）+Apache 2.0无限制商用"做开发者底座。Llama 存量最大但旗舰光环已失（🟡 多家横评，2026上半年）。

C端产品 - 通义App于2025年11月14日更名升级为千问App，公测23天MAU破3000万，2026年1月破亿，2026年3月达1.66亿，居中国AI原生App第二（豆包3.4亿、DeepSeek 1.3亿）（🟡 QuestMobile 2026Q1报告）。夸克PC端1.1亿装机量为千问导流，千问App已与淘宝、天猫生态全面打通（🟢 财报）。

B端与Agent/编程 - 百炼（Model Studio）平台客户数同比增长8倍，千问系列模型服务超100万家客户（🟢 官方/财报口径，2026-03）。 - Qwen3-Coder-480B-A35B 为开源最强代码模型之一；2026年3月 Qwen3-Coder-Next 技术报告显示，依托阿里云2万个并行可执行环境做智能体强化训练，SWE-bench Verified 超70%，开源模型中最先进水平（🟢 arXiv技术报告，2026-03）。Qwen Coding Plan（订阅制编程方案）已上线。

结论：模型进入全球第一梯队边缘（开源第一、闭源准前沿），开源生态全球心智第一，C端从掉队追至第二，B端商业化领跑国内。短板是最顶尖闭源模型仍与 OpenAI/Anthropic/Google 有半代差距，C端与豆包差距仍达一倍。

二、估值/市值 ★★★★（4/5）

AI/云基本面（FY2026，截至2026年3月，🟢财报） - 集团全年营收首破1万亿元，净利润1021亿元；Q4阿里云收入416.26亿元（+38%），外部商业化收入增速40%，为9个季度最快，高于AWS、比肩Azure。 - AI相关产品季度收入89.71亿元，ARR突破358亿元（约53亿美元），占阿里云外部收入首破30%，连续11个季度三位数增长；管理层预计约一年内占比过半。另一口径：AI模型与应用服务（含百炼）ARR预计6月季度破100亿元、年底破300亿元（🟢 业绩会）。 - Gartner：2025年阿里云中国IaaS份额32.8%，第一且提升（🟢）。

资本开支 - 三年3800亿元AI基建计划执行中：过去4个季度AI基建+产品研发投入已超1000亿元，全球新增8个AI/云数据中心及可用区；CFO徐宏称"服务器上架速度跟不上订单增长"，吴泳铭明确投入将"远超3800亿"，五年目标云+AI年收入1000亿美元、算力资产达2022年的10倍以上（🟢 业绩会，2026-05）。平头哥自研"真武PPU"已规模化量产，超10万卡部署于公共云（🟢 财报）；另有"交付47万片"说法（🟡 钛媒体，口径冲突，全部列出）。 - 代价：FY2026Q4出现经营亏损，管理层定性为投资（🟡 TIKR/外媒），利润与自由现金流承压。

市值与AI拉动 - 2025年9月股价161.6港元、市值重回3万亿港元（AI叙事驱动年内翻倍）；此后半年显著回撤；2026年7月8日单日暴涨12.2%至107.5港元，市值重回2万亿港元——催化剂为FY2027Q1前瞻（云增速升至约45%、云EBITA margin升至低双位数）、与美国司法部6亿美元和解、AI布局（MiniMax战略持股等）（🟢/🟡 新浪财经/财联社，2026-07-08）。当前市值较峰值仍回撤约三分之一。 - 分部估值：高盛将阿里云每ADS估值从36美元上调至43美元（🟡）；有观点称阿里云单体估值可超4000亿美元（🔴 乐观推算，仅供参考）。

结论：AI是阿里估值重估的唯一主线，云+AI基本面兑现度高（增速、占比、margin三升），但股价对AI叙事波动极其敏感，市值仍处于"AI信仰回撤后修复期"，AI贡献尚未稳定沉淀进市值。

三、团队 ★★★（3/5）

核心人事剧变（2026年上半年是分水岭） - 周畅：更早前已被字节以八位数年薪挖走，十余人随行（🟡 多家媒体；《财经》澄清其并非通义大模型技术负责人，存在口径争议）。 - 林俊旸出走：2026年3月3日提出离职，3月4日凌晨在X宣布卸任（"bye my beloved qwen"）。32岁、阿里最年轻P10、Qwen开源的灵魂人物。直接原因是组织调整中管理权限被压缩（Qwen团队从垂直整合被拆为预训练/后训练/文本/多模态的水平分工），根本原因是新模型未达管理层预期；高层紧急答疑称"无关政治斗争"（🟡 36氪独家/量子位/InfoQ，2026-03）。 - 连锁流失：后训练负责人郁博文等随后离职加入字节Seed（任视觉多模态后训练负责人）；字节Seed成为通义骨干主要去向。千问核心团队仅100余人，字节Seed超1500人（🟡）。阿里对策：天价年薪抢人+竞业协议"锁喉"（🔴 知乎独家爆料）；同时从 Google DeepMind 挖来 Gemini 研究员周浩接管后训练（🟡 量子位，2026-03）。 - 组织重构（吴泳铭亲自挂帅）：2026年4月成立集团技术委员会（吴泳铭任组长），通义实验室升格为通义大模型事业部（周靖人执掌，卸任阿里云CTO），李飞飞升任阿里云CTO，吴泽明任集团CTO；6月8日再合并通义大模型事业部与未来生活实验室成立 Token Foundry 事业部，吴泳铭直管，周靖人升任集团首席科学家并筹建AI未来研究院（🟢 官方公告/澎湃/财联社）。3个月成立3个AI事业部，形成ATH事业群统筹、千问事业部（C端）、悟空事业部（B端）的架构。

结论：组织执行力和资源集中度大幅提升（CEO直管、技术派掌权），但代价是开源时代的"英雄团队"瓦解——Qwen最具全球声望的技术领袖流失至最直接的竞争对手字节。新班子（周靖人+周浩+空降人才）能否延续Qwen迭代势能，是未来12个月最大的不确定性。

四、护城河 ★★★★（4/5）

逐项评估： 1. 开源生态（最强项，★★★★★）：全球下载量第一、衍生模型第一、Apache 2.0最宽松协议，海外开发者占国产模型调用近半。这是花钱买不到的全球心智。风险：Qwen3.7闭源化若成为常态，生态信任将被DeepSeek（持续开源前沿）侵蚀。 2. 算力与云客户基础（★★★★★）：中国IaaS份额32.8%第一、3800亿+资本开支、自研PPU芯片降低对英伟达依赖、百万企业客户存量——这是国内任何AI创业公司和字节都难以复制的B端护城河。 3. 电商场景数据（★★★☆）：千问与淘宝天猫打通，电商Agent想象空间大，但"交易数据→模型能力"的转化尚未看到硬证据。 4. 分发入口（★★★☆）：夸克（PC 1.1亿装机）+钉钉+淘宝多入口，千问MAU 1.66亿证明导流有效；但对比字节（抖音喂豆包3.4亿MAU），阿里的流量池明显更浅。 5. 模型本身（★★★）：模型能力不是护城河——半年内Qwen被DeepSeek V4、Kimi、GLM轮番贴身竞争，领先窗口以月计。

结论：护城河组合=「开源心智×云算力×企业客户」，B端极深，C端偏浅。

五、企业文化 ★★★（3/5）

  • 负面：2026年6月钉钉员工7万字离职长文《置身钉内》引爆对阿里高压管理、大公司病的舆论，罕见地迫使阿里合伙人委员会公开回应"组织文化需要尊重与信任"（🟡 新浪财经，2026-06）。林俊旸事件折射同一问题：管理层用KPI和组织手术对待需要长周期的基础研究团队，与字节Seed"重金+宽松+规模"的抢人打法相比处于文化劣势。千问App"30亿红包换流量"也引发"用电商打法做AI"的商业化焦虑质疑（🔴 知乎专栏）。
  • 正面：吴泳铭改革展现罕见决断力——CEO亲自下场直管模型研发（腾讯、字节均未如此），技术派全面掌权，砍掉"1+6+N"遗留的诸侯割据；从夸克到千问的快速切换、23天3000万MAU，证明大公司组织能力仍在；2026届秋招7000+offer中AI岗超6成，人才补给管道粗壮（🟢 官方）。
  • 判断：阿里文化正处于"电商运营文化"向"技术研究文化"的痛苦转型中，改革方向正确但研究氛围的修复慢于组织架构的调整速度。

最重要的5个发现

  1. AI商业化兑现是真实的：AI收入连续11个季度三位数增长、ARR 358亿元、占云外部收入30%且一年内预计过半、云EBITA margin不降反升——阿里是中国AI资本开支转化为收入效率最高的公司（🟢）。
  2. Qwen开源王座与闭源转向并存：拿下全球开源下载第一（7亿次）与衍生模型第一（18万+）后，最强的Qwen3.7未开源——阿里正在测试"开源获客、闭源变现"的边界，这将重塑其全球开发者关系。
  3. 核心团队实质性换血：周畅、林俊旸、郁博文等Qwen功勋相继流向字节Seed，通义进入"后英雄时代"，由吴泳铭直管+周靖人+DeepMind系空降兵重建。
  4. 资本开支上不封顶：3800亿三年计划已被管理层口头突破（"远远超过"），五年云+AI收入目标1000亿美元，自研PPU芯片10万卡级部署——阿里在赌国内最大的一笔AI基建。
  5. 市值坐过山车：2025年9月3万亿港元（AI信仰顶点）→2026年中回撤→7月8日暴涨12%重回2万亿港元，AI叙事的兑现与证伪直接主导股价，波动远未结束。

看多理由

  1. 云+AI进入"加速增长+利润率扩张"双击（FY27Q1云增速前瞻约45%、margin低双位数），管理层预计AI占云收入一年内过半。
  2. 开源生态全球第一的开发者心智，是Token经济时代最便宜的获客渠道，百炼客户8倍增长已在验证。
  3. 市值较峰值回撤约1/3，美国司法部和解消除多年监管悬顶，若以阿里云单体4000亿美元级估值看，AI/云价值未被充分定价。
  4. 吴泳铭集权后战略聚焦度为阿里近十年最高，自研芯片对冲算力封锁风险。
  5. C端千问1.66亿MAU+电商场景打通，Agent电商变现路径是同行不具备的独占场景。

看空理由

  1. 核心人才持续流失至字节Seed，Qwen团队仅百余人对阵1500人的Seed，下一代模型迭代能力存疑——林俊旸离职的导火索正是"模型不及预期"。
  2. 资本开支上不封顶导致经营利润与自由现金流承压（FY26Q4已现经营亏损），若AI收入增速放缓，估值将遭双杀。
  3. DeepSeek以MIT协议+1/100的价格持续冲击，Qwen开源领先窗口极短，且Qwen3.7闭源化可能自毁生态护城河。
  4. C端被豆包压制（MAU差一倍），30亿补贴换来的用户留存质量未经验证。
  5. 《置身钉内》暴露的组织文化问题短期难解，与顶尖研究人才的需求错配。

信息盲区

  • Qwen3.7未开源是暂时（Preview阶段）还是战略转向，官方无明确表态；
  • 林俊旸最终去向未披露；周畅"是否为技术负责人"存在《财经》与多家媒体的口径冲突；
  • Token调用量数据严重冲突（国产模型合计日均4.19万亿 vs 钛媒体转述阿里"日均140万亿"），后者疑似口径或转写错误，均需以后续官方披露为准；
  • 千问App付费转化率、留存率无公开数据；3800亿capex的实际已支出总额（仅有"4季度超1000亿"的投入口径，含研发）无精确拆分；
  • 阿里云分部独立估值无官方口径，4000亿美元说法为🔴推算。
