前置：研究条件声明

信息丰富度评级：A级（信息充裕）

美团上市8年，季度披露分部损益，券商与媒体覆盖密集。A级的陷阱是结论容易与市场共识趋同。本报告的应对：把重点放在"补贴战终局"这一共识分歧最大的变量上，用分部利润率反推市场隐含假设，而不是复述"外卖大战熄火"的流行叙事。

AI研究局限性声明

  1. 订单量与市场份额不可得：美团自2025年起不再披露即时配送订单量；淘宝闪购、京东外卖的份额只有第三方估算，口径不一。本报告不使用任何份额数字，竞争判断基于三家公司各自的财务披露与管理层表述。
  2. 单均经济效益只能定性：管理层只说"由负转正"，未给数字，报告不做无依据的单均测算。
  3. 对手亏损不可完全拆分：阿里自2026年6月季度起把即时零售并入"阿里巴巴电商集团"，不再单列利润。
  4. 正常化利润是推演，不是预测：亏损期估值用正常化口径，假设全部写明，读者可替换。

偏见自查

  • [x] 确定性来自生意本质还是资料数量？——资料极多，但关键变量（终局利润率）恰恰是资料最少的部分，因此估值给宽区间。
  • [x] 资料减半结论会变吗？——不会。核心结论只依赖三组一手数字：2024年核心本地商业利润率20.9%、2025年转为-2.6%、2026年二季度回到7.9%。
  • [x] 是否与共识雷同？——市场流行"二季度扭亏=战争结束"。本报告的不同判断：二季度是全年季节性最好的季度，管理层已明确三、四季度利润率环比下行；战争烈度下降不等于利润率回到战前。
  • [x] 是否存在被低估的可能？——存在：账上净现金加投资组合约占市值22%，市场可能低估了资产负债表的缓冲。

第二章 生意本质

2.1 一句话定义

美团是中国城市里"30分钟内把附近的东西送到你手上"和"告诉你附近哪家店值得去"的双边撮合平台，靠骑手网络密度赚履约钱，靠流量与点评赚商户的广告与佣金钱。

2.3 盈利结构的变化

  • 毛利率：2021年23.7% → 2024年38.4%（规模效应+社区团购收缩）→ 2025年30.4%（补贴计入成本）→ 2026Q2 33.5%。
  • 销售费用率：2024年19.0% → 2025年28.2% → 2026Q2 23.6%。补贴战的成本一半在毛利（骑手与用户补贴），一半在销售费用（营销）。 二季度销售费用率仍比2024年高4.6个百分点，说明补贴远未回到战前。

2.4 商业模式与粘性

维度 判断
模式 平台撮合 + 自建即时配送网络 + 部分自营零售
复购 极高频（外卖周频甚至日频），但高频不等于高粘性——消费者多平台比价成本几乎为零
商户侧锁定 中等：餐饮商户普遍多平台经营，但美团的点评内容、榜单（必吃榜基于15亿条真实评价）和会员体系形成软锁定
骑手侧 规模最大的网络，但骑手可同时接多家平台订单

2.5 经营杠杆

核心本地商业的成本主体是骑手成本（随单量线性）与补贴/营销（可调节）。2024年证明：在补贴受控时，收入增长20.9%、利润增长35.4%（386.99→524.15亿）。反向同样成立：2025年收入仅增4.2%，补贴失控使利润率下降23.6个百分点。这门生意的经营杠杆不来自固定成本摊薄，而来自"不需要花钱买单量"。

生意本质追问：这门生意好在哪？——在没有对手愿意赔钱时，它是中国最好的本地服务收费站之一（2024年核心利润率20.9%）；它的弱点是这个收费站的"不可替代性"不如想象中强，2025年证明有足够资本的对手可以在几个月内买走大量订单。好生意，但不是不可攻击的生意。

3.2 补贴战检验出的真相

2025年是一次真实的护城河压力测试。结论分两半：

  1. 外卖的"防守护城河"被证明存在：两个资本最雄厚的对手合计投入数百亿，美团核心利润虽归零，但管理层称在订单量与交易额上仍"环比扩大领先"、核心用户与核心商户未受明显影响；2026Q2配送收入重回+13.1%。对手没能把美团打成第二。
  2. 但"收费护城河"被证明很薄：守住份额的代价是把利润率从20.9%打到-2.6%。护城河保护的是份额，不是利润率。能守住城池，但守城期间收不了过路费。

3.3 十年判断

十年后美团大概率仍是中国本地即时服务的第一名（规模、密度、运营经验难以复制）。但"第一名能赚多少"取决于对手的战略定位：阿里把淘宝闪购定位为提升淘宝月活的流量入口（阿里财报称闪购带动淘宝月活跃消费者提升），这意味着对手的补贴有"用户获取成本"性质，不以外卖本身盈利为目标——这种对手不会因为外卖亏钱而退出。

能摧毁护城河的力量：（1）超级入口型AI助手绕过美团应用直接下单，把美团降为履约供应商；（2）监管对佣金率实施价格管制；（3）抖音在到店领域持续以内容流量分走商户广告预算。

护城河追问：10年后这条护城河还在吗？——份额护城河在，利润护城河会比2024年窄。估值必须按"窄护城河、高份额"定价，而不是按战前的"宽护城河、高利润"定价。

4.3 偏误自查

  • 叙事偏差："二季度扭亏"标题容易让人线性外推。实际上2026Q2核心利润率7.9%，比2025Q2的5.7%高，但比2024年全年20.9%低13个百分点。
  • 锚定效应：股价从2024年最高213.4港元跌到70港元，"便宜了三分之二"的锚定毫无意义——利润中枢已经变了。
  • 幸存者偏差：拿"美团赢过2015年那场战"推论"这次也会赢"，忽略了对手性质的变化。

4.4 空方最强论点

"美团的利润率永远回不到20%了。" 理由：（1）阿里和京东都把外卖当作主业的引流工具，而非独立盈利单元，不需要外卖本身赚钱；（2）监管新规禁止"低于成本销售"，客观上保护了第二、三名不被挤出；（3）骑手社保让每单成本永久上升；（4）抖音分走到店的高毛利广告。四点叠加，核心利润率稳态可能只有10%左右。

反过来想追问：我最可能在哪里犯错？——最可能犯的错是高估终局利润率。如果稳态核心利润率是8%而不是13%，基准估值要下调约30港元/股。聪明人不买的理由很简单：在终局未明之前，任何"正常化利润"都是猜测，而现价已经隐含了约13.7%的稳态利润率（见第七章反向估值），并不便宜。

第六章 行业与文明趋势

6.1 范式判断

即时零售（30分钟送达一切）是一次消费基础设施升级，但不是文明级范式转移——它是对传统零售履约的效率替代。真正可能改变美团位置的范式是AI智能体：

  • 当前形态：用户打开美团应用→搜索→比价→下单。美团掌握入口，向商户收广告费。
  • 智能体形态：用户对通用助手说"帮我订一份附近评分高的川菜"→助手调用各平台接口→美团可能退化为履约方，广告收入（商户服务收入的核心）被削弱。
  • 美团的应对：自研 LongCat 大模型、应用内助手"小团"、面向商户的智能体（CatPaw平台）。管理层表态"不做算力工厂"，重点用AI重塑组织与产品。

这是一把双刃剑：美团拥有通用助手最缺的东西——真实履约网络和商户数据；但阿里（千问助手已接入淘宝闪购）同时拥有大模型与即时零售，竞争维度从"补贴"升级到"入口"。

6.2 可触达市场与天花板

  • 核心本地商业2025年收入2,608亿元，增速从2023年的28.7%降至2025年的4.2%，主因补贴战压低变现；2026上半年恢复到5.1%，二季度单季10.1%。
  • 即时零售仍在扩张：阿里即时零售2026财年收入785.2亿元，同比增长47%（阿里财报口径，含盒马）。美团闪购、闪电仓、小象超市均处于高增长期。
  • 天花板判断：外卖渗透率已高，增长主要来自非餐即时零售与下沉市场；到店酒旅面临抖音分流与消费疲软（管理层称部分品类客单价受宏观拖累）。收入层面还有十年增长，利润层面的天花板由竞争格局决定，而不是需求。

6.3 价值链位置

美团处于"商户—平台—骑手—消费者"的中枢，向商户收佣金与广告，向消费者收配送费，向骑手付报酬。上游商户极度分散（超过800万商户），议价力弱；下游消费者分散但价格敏感；真正与美团争夺价值的不是上下游，而是同层级的平台对手与监管。 监管持续把价值从平台向骑手（社保）和商户（禁止强制补贴分摊）转移。

行业趋势追问：站在20年后回看，美团是这个时代的基础设施，还是昙花一现？——更可能是"本地履约基础设施"，类似公用事业：不可或缺，但利润率受竞争与监管双重约束。成为"标准石油式"垄断者的窗口在2024年已经关闭。

8.4 四个维度的最终判断

生意本质维度：这是一门在和平时期非常好的生意，在战争时期非常普通的生意。2025年之后，投资者必须假设"和平"不是默认状态。

护城河维度：美团证明了自己守得住，但守城成本由股东承担。护城河保护的是份额，利润率要靠对手的理性来赏赐。

反过来想维度：最危险的错误是把二季度旺季的7.9%当成新起点线性外推。三季度管理层已预告旺季营销加码、骑手补贴增加、职业伤害保障成本上身，利润率大概率环比回落。

估值维度：现价隐含约13.7%的稳态核心利润率，等于已经替"战争结束、利润恢复六成以上"付了钱。好公司，合理价，没有安全边际——等更好的价格或更确定的终局。

8.5 最关键的三个检验点

  1. 2026年三季度业绩（约11月下旬）：核心本地商业利润率能否在旺季投入后守住5%以上。
  2. 补贴规范十条正式稿：是否保留"不得长期大额补贴""不得低于成本销售"条款，以及执法力度。
  3. 京东、阿里下一季财报：外卖/即时零售亏损是否继续收窄——对手减亏的速度就是美团利润恢复的速度上限。

8.6 AI分析置信度与投资确定性

结论 AI分析置信度 投资确定性 说明
补贴战烈度已见顶 高 中高 三家财报同时减亏，一手数据充分
核心利润率稳态13% 中 低 这是推演，取决于对手战略与监管执行，无一手数据可证
现价隐含约13.7%利润率 高 — 纯计算，假设透明可替换
美团10年后仍是第一 中高 中 规模与密度优势明确，AI入口风险难以量化
观望建议 中 — 建议的价值在于价格纪律，而非对终局的预测

一句话区分：本报告关于"过去发生了什么"的结论基于充分的一手数据（AI置信度高）；关于"终局利润率是多少"的结论是有限信息下的推理（投资确定性低）。估值区间宽（悲观20.9港元到乐观114.6港元）正是这种不确定性的诚实反映。
