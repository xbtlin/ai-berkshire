AI研究局限性声明

  1. 本报告只用交易所原件与可复核计算，不使用任何既往研究报告的数字或结论。

第二模块：生意本质

一句话定义

用自研的多模态大模型，把算力加工成按 Token 计价的"智能"，批发给开发者和企业（开放平台），同时零售给海外消费者（Talkie、海螺）。本质上是一门"算力加工"生意：原料（GPU时）向云厂商买，成品（Token）在全球最卷的市场里卖。

收入拆解与商业模式

渠道 计费方式 毛利特征（招股章程期间） 当前趋势
开放平台/API 按Token用量；Token计划（包月套餐，含编程套餐）；专属推理资源池；模型授权 2024年63.2%，2025前三季度69.4% 收入占比升至63.4%，但毛利率推算降至约16.6%–25.3%【有据推算，置信度中】
海螺AI（视频） 订阅+充值 AI原生整体2025前三季度仅4.7% 增长主力之一，面临好莱坞版权诉讼
Talkie/星野（陪伴） 广告为主+订阅 同上 平台期
MiniMax智能体/Code 订阅 体量小 新方向

开放平台毛利率推算过程（工具计算）：上半年总毛利20.813百万美元 = AI原生收入42.644×m₁ + 开放平台收入73.929×m₂。若AI原生毛利率m₁=5%（延续招股期水平），则m₂≈25.3%；若m₁=20%，则m₂≈16.6%。无论哪种假设，开放平台毛利率都从约69%塌到25%以下。旁证：智谱同期 API 毛利率24.6%。业绩会媒体转述管理层称"下半年毛利率环比改善，但回不到2025年下半年水平"。

为什么塌：①Token计划是包月低价套餐，重度编程用户的实际调用量远超套餐价所对应的成本；②国内外价格战（DeepSeek开源免费、豆包低价）；③媒体转述 M3 发布时定价翻倍、一周后改为"永久半价"，说明没有提价能力。

客户粘性

  • 开放平台：API接口高度标准化（多数兼容通用接口格式），开发者在 OpenRouter 等聚合平台上切换模型只需改一行配置。粘性弱。
  • 客户集中度在下降：前五大客户占收入从2024年44.1%降至2025年18.7%，最大客户从30.9%降至12.5%——好事（降低依赖），也意味着收入更多来自长尾开发者，这类用户对价格最敏感。
  • 消费端：Talkie 每付费用户5美元，海螺56美元；陪伴类应用的留存靠内容与角色生态，生成类应用的留存靠"模型是否仍是最好的那个"。

经营杠杆

费用/收入 2025上半年 2026上半年
研发 408.6% 254.7%
销售及分销 107.9% 23.1%

费用率在下降，但研发绝对额半年增加1.73亿美元，远超毛利增加的0.17亿美元。且2026上半年1.88亿美元自建算力资本开支不进损益（以折旧方式慢慢进入），经调整净亏损低估了真实消耗。所谓经营杠杆，要等到"毛利增量 > 研发增量"那一天才成立，目前差距是10倍。

生意本质追问：这门生意好在哪？——好在需求真实且爆发（Token消耗半年20倍）。差在卖的是同质化商品，而成本跟着用量线性上涨：用户越多、调用越重，亏得越多，除非单位推理成本下降速度快于价格下降速度。目前公告数据显示，价格降得比成本快。

护城河追问：10年后这条护城河还在吗？——以今天的证据，MiniMax 没有一条能保证10年存在的护城河。能摧毁它的东西就在眼前：大厂把模型当作云和广告的引流品免费送（阿里通义千问、字节豆包、谷歌），以及开源模型把"足够好"的智能价格打到接近电费。

偏误自查

  • 叙事偏差："AGI公司""Token消耗20倍"的叙事很强，但财务数字显示是"越卖越亏"的结构。
  • 锚定效应：3月高点1,330港元、IPO价165港元都是锚。现价相对高点跌81.7%、相对IPO仍涨47.2%（工具计算）——两个锚给出相反的"便宜/贵"感受，都与内在价值无关。
  • 幸存者偏差：我们记得的是赢家（英伟达、OpenAI），而同期"第二梯队模型公司"的平均结局并不好。

空方核心论点

  1. 增长是买来的：B端占比翻倍，综合毛利率却下降，说明新增收入的毛利率远低于老收入。
  2. 年化8亿美元不可直接用于估值：媒体质疑可能按单周收入×52计算；即便口径真实，也是包月套餐在爆发期的峰值。
  3. 现金是借来的一年：备考33.6亿美元中约8.6亿美元一年后要还；按管理层"未来18个月额外月均9,260万美元研发支出"的计划，扣除可转债后的跑道只有约13.4个月（见第七模块）。
  4. 同行估值更高不等于 MiniMax 便宜：可能是整个板块被高估。

反过来想追问：我最可能在哪里犯错？——在"成本下降速度"上。如果自建算力和下一代模型（媒体转述 M3.1 推理成本约为 M3 的三分之一）让单位成本在一年内降到三分之一，而价格只降一半，毛利率会快速回到40%以上，那么当前价格就是便宜的。聪明人不买的原因：没人能提前知道成本曲线和价格曲线谁跑得快，而财报已经连续两个季度显示价格跑得更快。

第六模块：行业与文明趋势

范式转移判断

大模型是真正的范式转移——这一点不需要论证，Token消耗半年20倍就是证据。但范式转移的价值不一定由模型公司获得。历史上电力、互联网带宽、云计算都是范式转移，价值大头流向了：①瓶颈资源（发电与电网、光纤管道铺设早期的赢家极少）；②掌握用户入口的应用与平台。

价值链位置：模型层被两头挤压

层级 代表 议价能力 MiniMax 的处境
算力层（芯片、云） 英伟达、阿里云 强（供给受限） MiniMax 前五大供应商占采购57.5%，最大单一供应商23.3%；阿里云既是供应商又是股东
模型层 MiniMax、智谱、DeepSeek、海外前沿 弱（同质化、开源冲击） 开放平台毛利率推算从约69%降到25%以下；智谱API毛利率24.6%
应用层 编程工具、智能体、内容平台 中强（握有用户与场景） 编程工具可在多个模型间切换，模型只是可替换零件

结论：模型层的利润正在被算力层（成本刚性）和应用层（可替换性）两头挤压。MiniMax 的出路是向上做应用（海螺、MiniMax智能体/Code、Talkie）以获得用户关系，或向下自建算力降低成本——它两件事都在做，但两件事都极度烧钱。

TAM与天花板

  • 全球大模型API与订阅市场的规模在快速扩大，但价格在以每年数倍的速度下降，收入层面的市场规模增速远低于Token量增速。
  • MiniMax 的可寻址市场受两重限制：中国公司身份使其难以进入欧美大企业与政府客户；国内市场则面对阿里、字节以云和广告补贴模型。它真正的主场是全球中小开发者与海外消费者——这个市场大，但对价格最敏感。

技术路线风险

  • 若"更大参数+更多强化学习"的路线持续有效，资本规模决定胜负，MiniMax 每半年3亿美元研发与海外头部公司不在一个量级。
  • 若"效率路线"（稀疏激活、推理优化）成为主导，MiniMax 有相对优势——这是它最好的赌注。

行业趋势追问：站在20年后回看，这家公司是"这个时代的标准石油"，还是"昙花一现的3Com"？——以今天的证据，更接近后者的风险结构：技术强、组织好，但处在价值链被挤压的一层，且没有大厂的生态补贴。能改变结局的只有一件事：把某个消费产品（海螺或智能体）做成拥有用户关系的平台。

四个维度的最终判断

生意本质：这是一门需求极好、生意结构很差的买卖。Token是商品，商品生意赚钱靠成本最低，而成本最低的位置目前属于有云、有芯片、有广告补贴的大厂。

护城河：能力强不等于有护城河。MiniMax 三年内做出了全球一流的多模态模型，这证明了团队；但同一份财报也证明了，它卖不出溢价。

反过来想：最大的错误可能是低估了成本下降速度——如果单位推理成本一年降到三分之一，今天的结论会被推翻。但在财报证实之前，不应为这个可能性支付溢价。

估值：市场要求它5年做到约70亿美元收入、25%净利率。这不是不可能，而是今天没有任何一个财务数字支持这个路径。好公司也要等好价格。

三条最关键结论

  1. 增长是以毛利为代价换来的：开放平台收入半年翻4.4倍，但综合毛利率从33.7%降到17.9%；推算开放平台毛利率从约69%塌到25%以下。
  2. 现金宽裕是表象：备考现金约33.6亿美元，其中约8.6亿美元是2027年7月到期的可转债；按管理层的算力投入计划，扣除可转债后跑道约13.4个月，2027年下半年大概率再融资。
  3. 当前价格隐含了极乐观的路径：概率加权内在价值约163港元，现价高出约49%；即使相对智谱便宜三分之二，也只是"板块整体贵"中的相对便宜。
