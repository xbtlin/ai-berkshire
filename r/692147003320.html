检验日期：2026-09-04｜数据截至：2026-09-03 收盘

本报告检验亚历山大·埃尔德《以交易为生》（第2版）提出的冲力系统（Impulse System）是否具备预测力。结论为否定，四组检验与一组安慰剂对照全部支持该结论。报告同时记录了数据核对过程中发现的两处数据源错误。

摘要

检验 样本 核心发现
颜色与未来收益 28 只 / 24,461 观测 红柱后 13 周收益 4.80%，高于无条件的 4.41%，无区分度
交易模拟 28 只 / 最长 19.4 年 买入持有年化 12.1%，照禁令做 8.2%，仅绿柱持有 5.2%
定投加仓 28 只 / 7,000+ 期 红柱不买再补买，终值比是 1.000，无差异
建仓时点等待 5,809 次红柱事件 等待平均少赚 1.28 个百分点，胜率 30.8%，t = −4.62
安慰剂对照 同上 闭眼固定等 3 周与看颜色等的结果一致，颜色贡献为零
中国资产子样本 6 只 / 5,317 观测 表面出现单调排序，循环移位检验 p = 0.110，不显著

支持该系统的一面：它在长期上涨的个股上确实呈现出正向排序；它降低了组合波动与最大回撤；它作为行为约束工具的价值无法用收益数据证伪。

反对该系统的一面：上述波动下降完全由敞口减少解释，按波动率放大到同等风险后仍然跑输；正向排序在扩大样本后消失；其"两重确认"的两个输入来自同一条价格序列，不构成独立信息。

一、被检验对象

冲力系统是《以交易为生》第 2 版新增的 K 线着色方法，规则为：

颜色 成立条件 系统含义 禁令
绿 13 周期 EMA 高于前值，且 MACD 柱高于前值 趋势与动能同向向上 禁止做空
红 13 周期 EMA 低于前值，且 MACD 柱低于前值 趋势与动能同向向下 禁止做多
蓝 两条件不同时成立 力量分歧 不禁止

MACD 参数取作者公布的默认值 12/26/9。系统的设计意图是限制交易而非产生入场信号（来源：StockCharts ChartSchool 对 Elder Impulse System 的定义）。

配套的三重滤网用法为：周线定方向，日线找反向波浪，日内触发入场。本报告检验其第一层，即周线颜色的信息含量。

二、文献背景

技术分析的实证证据需要分三层看，混在一起会得出错误印象。

第一层：动量本身有稳健证据。 Jegadeesh & Titman (1993) 的横截面动量与 Moskowitz, Ooi & Pedersen (2012) 的时间序列动量被反复复制，动量因子后被纳入 Carhart 四因子模型。行为学机制包括信息反应不足（Bernard & Thomas 的盈余公告后漂移）与处置效应。趋势具有惯性这一命题本身不缺证据。

第二层：把动量固化为具体交易规则后，证据显著减弱。 Brock, Lakonishok & LeBaron (1992) 在道指 1897 至 1986 年数据上发现均线规则具备预测力。Sullivan, Timmermann & White (1999) 使用 White 的 Reality Check 自举法扣除数据窥探偏差后，结论反转：在 26 类规则扩展成的全集中，最优规则的表现落在随机搜索可产生的范围内，且 1987 年后样本外失效。Park & Irwin (2007) 综述 95 篇现代研究，正面 56 篇、负面 20 篇、混合 19 篇，但作者指出正面结果普遍存在数据窥探、事后择优与成本低估问题。Lo, Mamaysky & Wang (2000) 用核回归量化图形形态，发现存在统计信息量，同时说明其实际价值存疑。

第三层：冲力系统本身没有同行评议的检验。 检索未发现任何学术论文测试过 Impulse System。其参数（13、12、26、9）无理论推导来源，12/26/9 出自 Gerald Appel 1970 年代按当时一周六个交易日设定。

本报告补的是第三层的空白。

3.2 数据源与口径

主数据源为雅虎财经图表接口（query1.finance.yahoo.com/v8/finance/chart），取 indicators.adjclose（乘法后复权，还原拆股与分红）。周线由日线按 ISO 周聚合而成，非接口直出。

交叉核对源为东方财富 K 线接口（push2his.eastmoney.com）。

复权口径差异需要说明：东方财富的前复权（fqt=1）采用加法复权。以贵州茅台 2018-01 为例，其前复权价恒等于原价减去 284.80 元，绝对价差保留但百分比收益率被扭曲。计算收益率与 EMA/MACD 必须使用乘法复权，故以雅虎口径为准。

3.4 检验设计

指标全部手工实现，未使用 pandas、numpy 或 TA-Lib。EMA 采用标准递推 E_t = C_t·k + E_{t-1}·(1−k)，k = 2/(n+1)，首值取首个收盘价。前 30 根周线作为预热期不参与统计。

四组检验：

  1. 条件收益：按当周颜色分组，统计未来 1 / 4 / 13 周收益，与无条件均值比较。
  2. 交易模拟：周线定色，次周执行，单边成本 0.1%。三种策略为买入持有、非红才持、仅绿才持。
  3. 定投加仓：每 4 周投入 1 份现金流。策略 A 到点即买；策略 B 红柱时持币、首根非红柱补买；策略 C 仅绿柱买。闲置现金按年化 2% 计息，期末未投出的现金按面值计入。三者投入总额相同，直接比终值。
  4. 建仓时点等待：在每根红柱周，策略 A 当周收盘买入，策略 B 等到首根非红柱收盘买入，两者持有至同一终点（26 / 52 / 156 周）。

安慰剂对照：在红柱周固定等待 2 / 3 / 4 周后买入，不看颜色。若其结果与"看颜色等"一致，则颜色本身的信息贡献为零。

显著性处理：重叠窗口使观测非独立，故不报告朴素 t 值，改为先按标的求均值再做跨标的 t 检验。第六节另用循环移位置换检验处理自相关问题。

六、循环移位显著性检验

第五节的正向结果需要区分真实信号与小样本噪声。子样本仅 6 只标的，且彼此高度相关（三只中国互联网平台、两只白酒），常规 t 检验功效不足。

采用循环移位置换检验：将颜色序列相对收益序列循环平移一个随机长度，保留两条序列各自的自相关结构，仅打断二者的时间对应关系，重复 2,000 次构造零分布。

中国资产子样本的 p 值为 0.110，在 5% 水平不显著。其零分布区间跨度达 7.96 个百分点，随机平移颜色序列有约 11% 的概率产生不低于实测值的"信号"。

宽样本的零分布区间仅 2.51 个百分点，样本量增加使噪声下降，同时实测值本身收敛至零附近。

七、结论

可测部分的结论为否定。 冲力系统的颜色在 24,461 个宽样本观测上与未来收益无统计关联；按其禁令交易在四组检验中全部跑输买入持有；其等待规则的全部效果由固定延迟解释，颜色的边际贡献为零。中国资产子样本上出现的正向排序未通过循环移位检验（p = 0.110）。

该结论的适用边界。 本报告检验的是预测力与收益贡献，不检验以下命题：该系统作为行为约束工具是否降低了使用者的冲动交易频率；使用者是否因持有一套显式规则而改善了情绪管理。这两项在收益数据中不可观测，本报告既不支持也不反对。

一项需要与结论分开陈述的观察。 若使用者确实需要一条"延后数周再决策"的纪律，本报告的安慰剂对照显示，直接设定固定延迟即可获得同等效果，且在宽样本上最坏情形更好（0.6512 对 0.6447）。附加颜色判断不提高准确率。

方法论层面的三点观察（属于分析而非实证结果）：

  1. 13 周期 EMA 与 MACD 柱均为同一条收盘价序列的线性滤波，相关性高。要求两者同时成立并不构成两次独立验证。
  2. 蓝色柱在样本中占 36%，且不施加任何禁令。事后复盘时该状态可解释任何结果，削弱可证伪性。
  3. 参数 13、12、26、9 无理论推导来源。在参数空间内搜索可在任意区间找到表现良好的组合，此即 Sullivan, Timmermann & White (1999) 用自举法扣除的部分。

八、局限

  1. 幸存者偏差。34 只标的（28 + 6）全部为检验日仍在交易的公司，由人工选定。该偏差高估买入持有的表现，对择时系统不利。但第 4.1、4.4、5.1、5.3 节的检验为标的内部按颜色分组或同一时点两策略对比，受该偏差影响较小。主结论依赖后者而非交易模拟。
  2. 重叠窗口。5,809 次红柱事件的持有期相互重叠，非独立观测。已改用跨标的聚合 t 值（自由度 27 与 5）并补充循环移位检验，但标的间的同期相关未修正，真实 t 值应低于报告值。
  3. 成本处理不完整。交易模拟计入单边 0.1% 成本，定投与等待检验未计入交易成本与税负。补足后仅会加大等待策略的劣势。
  4. A 股市场结构差异。贵州茅台与五粮液存在涨跌停限制与 T+1 制度，会截断单周极值并改变动量形态。将港股美股的检验结论直接外推至 A 股需谨慎。
  5. 单一主数据源。取数依赖雅虎财经一家，东方财富仅用于核对未用于重算。若雅虎存在系统性偏差，本检验无法识别。已发现的两处错误说明该风险真实存在。
  6. 未检验其他时间框架。本报告仅检验周线。日线与月线的结论未测试。

附录：核心算法

def ema(values, n):
    k = 2 / (n + 1)
    e, out = None, []
    for x in values:
        e = x if e is None else x * k + e * (1 - k)
        out.append(e)
    return out

def impulse(closes):
    """返回每根K线的冲力颜色。前30根为预热期，不参与统计。"""
    e13  = ema(closes, 13)
    macd = [a - b for a, b in zip(ema(closes, 12), ema(closes, 26))]
    hist = [a - b for a, b in zip(macd, ema(macd, 9))]
    out = []
    for i in range(len(closes)):
        if i < 30:
            out.append('x')
        elif e13[i] > e13[i-1] and hist[i] > hist[i-1]:
            out.append('G')   # 绿：禁止做空
        elif e13[i] < e13[i-1] and hist[i] < hist[i-1]:
            out.append('R')   # 红：禁止做多
        else:
            out.append('B')   # 蓝：不禁止
    return out

周线由日线按 ISO 周（datetime.isocalendar()[:2]）聚合，取每周最后一个交易日的后复权收盘价。

循环移位检验：设颜色序列 C 与未来 13 周收益序列 R 等长，随机取平移量 k ∈ [30, len(R)-30]，用 C[(i+k) mod n] 与 R[i] 配对重算绿红收益差，重复 2,000 次得零分布。
