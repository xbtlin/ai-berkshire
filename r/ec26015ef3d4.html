智谱与 MiniMax 2026 年中报的质地对比

2026 年 8 月 26 日和 8 月 31 日，MiniMax 和智谱先后交出了上市后的第一份完整中报。两家公司同一个月在港交所敲钟（MiniMax 1 月 9 日，智谱 1 月 8 日），同一个报告期，同一个赛道，同一批投资人在看。

把这两份报表换算到同一个货币口径之后，会看到一组几乎重叠的数字。

一、口径统一：这两份中报为什么可以直接比

口径不统一，后面所有的数字都是沙子。

时间窗完全一致：都是 2026 年 1 月 1 日至 6 月 30 日，都是未经审计、由核数师按《香港审阅准则第 2410 号》审阅（智谱毕马威、MiniMax 安永），都出具无修改结论。

汇率：智谱以人民币列示，MiniMax 以美元列示。本文换算全部采用两家公司自己公告里用过的汇率：1 美元 = 6.72 元人民币 （智谱中报正文自用，如"总收入约 9.54 亿人民币，约 1.42 亿美元"）、 1 美元 = 7.837 港元 （MiniMax 公告自用）。两条汇率隐含的港元兑人民币约为 0.775，与智谱七月配售公告里的实际结算汇率 0.867 存在约 1% 的口径差，源于取数时点不同。 1% 的误差不影响任何一个量级判断，但它存在。

市值直接可比：两家都在港交所主板上市，市值均以港元计价，无需换算。

一处共同的披露缺口 ：两家的中期业绩公告 都没有附现金流量表 （港股中期业绩公告非强制披露）。本文所有涉及现金流的数字，均由资产负债表变动与损益表非现金项目推算得出，已逐处标注。这是两家公司共同的问题，不是某一家的问题。

二、四个几乎重叠的数字

指标（1H2026） 智谱 MiniMax 差异
研发开支 21.31 亿元 = 3.17 亿美元 2.97 亿美元 智谱多 6.8%
经调整净亏损 19.64 亿元 = 2.923 亿美元 2.930 亿美元 差 0.26%
员工薪酬（含股份支付） 4.82 亿元 = 0.717 亿美元 0.689 亿美元 智谱多 4.1%
经营现金净流出（推算） 约 32 亿元 = 约 4.8 亿美元 约 4.3 亿美元 同一量级

经调整净亏损 2.923 亿美元对 2.930 亿美元，两家公司在同一个半年里，剔除股份支付和金融工具重估之后的真实亏损，差距是 0.26%。不是挑出来的巧合。研发、薪酬、烧钱三项也全部落在 ±7% 以内。

2026 年上半年做一家前沿大模型公司的门槛因此很清楚： 每半年 3 亿美元的研发投入、3 亿美元的经调整亏损、4 至 5 亿美元的现金消耗 。两家路径完全不同的公司，被同一条成本曲线约束到了同一个数量级。

差别在于这笔一样的钱换回了什么。

三、分野一：同样的投入，智谱换回了更多收入和毛利

指标（1H2026） 智谱 MiniMax 智谱 / MiniMax
收入 9.54 亿元 = 1.420 亿美元 1.166 亿美元 1.22 倍
毛利 2.52 亿元 = 0.374 亿美元 0.208 亿美元 1.80 倍
毛利率 26.4% 17.9% +8.5pp
增量毛利率（对 2H2025） 12.0% 6.5% 1.85 倍

增量毛利率的算法是把最近半年新增的收入和新增的毛利相除，看新钱的赚钱效率。

  • 智谱：增量收入 4.204 亿元，增量毛利 0.504 亿元 → 12.0%
  • MiniMax：增量收入 6,796 万美元，增量毛利 442 万美元 → 6.5%

两家都远低于各自的报表毛利率，说明 两家新增的收入都比存量收入更不赚钱 。但智谱的新钱效率是 MiniMax 的 1.85 倍。

再单独看两家贴身竞争的那条赛道，B 端开放平台/API：

B 端 API 业务 智谱（开放平台及 API） MiniMax（开放平台及其他企业服务）
1H2026 收入 8.25 亿元 = 1.228 亿美元 0.739 亿美元
占总收入 86.5% 63.4%
半年环比增速 +411.6% +341.1%
2H2025 基数 1.61 亿元 ≈ 0.23 亿美元 0.168 亿美元

起跑线接近（2H2025 分别约 2,300 万和 1,680 万美元），半年后智谱跑到 1.23 亿美元，MiniMax 跑到 0.74 亿美元，智谱是 MiniMax 的 1.66 倍，且增速更快。 在两家正面相撞的这条赛道上，智谱上半年赢了。

四、分野二：总收入的增长斜率，MiniMax 更陡，但要拆开看

增速口径 智谱 MiniMax
总收入同比 +399.7% +283.1%
总收入 半年环比 +78.8% +139.8%

同比智谱快，环比 MiniMax 快。 同比是失真的。智谱 1H2025 的云端收入只有 2,910 万元，任何数除以这个基数都会得到夸张的倍数。环比才是最近半年的真实斜率。

但环比也要拆开：

业务拆分（半年环比） 智谱 MiniMax
B 端 API +411.6% +341.1%
非 API 业务 本地化部署 -65.4% AI 原生产品（C 端） +33.9%

智谱总收入环比慢，是因为它 主动砍掉了本地化部署业务 ：企业级通用大模型收入同比腰斩 54.6%，本地化部署环比下滑 65.4%。公司的解释是"更强调质量和行业选择"。

MiniMax 的非 API 业务（海螺 AI 等 C 端产品）环比只增长 33.9%，同比 +100.9% 靠的是低基数。高毛利的 C 端业务已经明显失速。

所以两家的结构变化是同一个方向、不同的起点 ：智谱从"卖私有化部署"转向"卖 API 调用"，MiniMax 从"卖 C 端订阅"转向"卖 API 调用"。两家都在把身家押到同一条 B 端赛道上。智谱转得更彻底（86.5% 对 63.4%）。

这里有个说不通的地方。智谱本地化业务的毛利率在下滑 （环比 44.4% → 37.9%，其中企业级通用大模型从 58.5% 掉到 42.3%）。如果真是"主动选择高质量客户"，毛利率应该上升而不是下降。看上去是需求侧确实在往云端迁移，公司在被动追认。

五、共同的病：毛利率在同一个半年里同时塌陷

毛利率 2H2025 1H2026 变动
智谱 37.7% 26.4% -11.3pp
MiniMax 33.7% 17.9% -15.9pp

两家公司在同一个半年里，毛利率同时出现两位数百分点的塌陷。

智谱这边还有一组细节。云端毛利率从 2H2025 的 22.4% 只提升到 1H2026 的 24.6%， 在收入环比增长 4.1 倍的条件下，只多了 2.2 个百分点 。同期公司披露 API 平均售价上调了约 101%。

收入翻了四倍、价格翻了一倍，云端毛利率只挪动了 2.2 个百分点。 反推云端成本：收入环比 +411.6%，成本环比 +397.2%。成本几乎与收入等比例扩张，规模效应在环比维度上基本没有出现。

两家公司、两套技术路线、两个客户结构，得到同一个结果。这就不是公司问题了，这是行业问题：

Token 单价下行 + 推理算力成本刚性 + 调用结构向更长更复杂的任务迁移，三股力量夹在中间，把这门生意的毛利率压在 20% 上下。

做个参照：成熟的云计算业务毛利率在 60% 以上，SaaS 在 70% 以上。 今天的大模型 API 生意，毛利结构更接近算力转售，而不是软件。

六、共同的动作：把现金变成"预付算力"

两张资产负债表上金额异动最大的科目是同一个。

预付算力类科目 智谱 MiniMax
科目名称 预付计算服务费及其他 预付款项、其他应收款及其他资产
期末余额 12.44 亿元 （另有"其他非流动资产"9.12 亿元） 2.66 亿美元 （流动 1.65 亿 + 非流动 1.01 亿）
半年增幅 +969.5% 流动 +913.7% ／非流动 +11,266%
相当于半年收入的 约 2.3 倍（含其他非流动资产口径） 2.1 倍
明细披露 无 无

两家公司在同一个半年里，把相当于两倍多半年收入的现金，提前付给了算力供应商，而且 两家都没有披露任何构成明细 。

2026 年上半年，算力供给紧张到了模型公司必须先付钱才能锁产能的程度。 这笔钱的性质是成本前置：今天不进损益表，未来以成本和折旧的形式压在后续期间的毛利率上。

两家在算力上的路径选择不同：

智谱 MiniMax
自建算力 物业厂房设备 8.55 亿元，但半年增量 1.99 亿元中 3.61 亿元来自两笔收购 ，内生资本开支仅约 0.29 亿元 物业厂房设备从 157 万美元增至 7,491 万美元，半年增长 46.7 倍
资本承担 公告明示 "无任何未履行的资本承担" 未单独披露
算力供应结构 走国产芯片路线，自述已实现 10 万级国产芯片规模化推理，单 token 推理成本较年初降 80% 高度绑定阿里云
关连方算力 联营公司北京数道智算（持股 7.31%，提供算力服务） 阿里巴巴持股 11.36% ，同时是最大单一供应商

智谱是"全租、零资本承诺、往国产芯片走"。 好处是灵活、可随时缩量；坏处是量价未锁定，第三方算力中断或涨价的敞口完全开放（公司自己在风险提示里单列了这一条）。

MiniMax 是"开始自建 + 深度绑定阿里" 。8 月 26 日与中报同日发布的关连交易公告披露：阿里云采购年度上限从 1.15 亿美元上调至 3.00 亿美元 （2027 年 4.00 亿、2028 年 5.00 亿）；1H2026 已采购 7,560 万美元，而同期向阿里巴巴销售 API 只有约 50 万美元，净支出关系 151 比 1。

有一个对 MiniMax 有利的细节要替它说清楚： 开放平台 7,393 万美元收入里，来自关连方阿里巴巴的只有约 50 万美元（0.7%） 。它的 B 端增长是真实第三方需求，不是关联方输血。这一条把收入质量的可信度提上去了不少。

七、分野三：跑道，这是最实质的质地差异

流动性（换算为美元） 智谱 MiniMax
2026-06-30 类现金 44.99 亿元 = 6.70 亿美元 13.23 亿美元
期后融资（7 月） 配售净额 313.75 亿港元 = 40.0 亿美元 配售 12.05 亿 + 可转债 8.21 亿 = 20.26 亿美元
备考流动性 约 46.7 亿美元 约 33.5 亿美元
年化经营烧钱（推算） 约 9.5 亿美元 约 8.6 亿美元
已知刚性偿付 银行贷款 22.25 亿元 = 3.31 亿美元（无担保，可续） 2027 年到期可转债 8.29 亿美元（零息，硬约束）
扣除后跑道 约 4.6 年 约 2.9 年
还在路上的钱 A 股科创板拟募 不超过 150 亿元（约 22.3 亿美元） 股东特别大会再次刷新一般授权

智谱期末现金只有 MiniMax 的一半，但七月那一笔配售改变了全局： 19,780,000 股新 H 股，每股 1,588.00 港元，净额 313.75 亿港元 。这笔钱是它 6 月 30 日账上现金的 6.8 倍、上半年收入的 28.5 倍，摊薄只有 4.4%。

MiniMax 七月同样融了两笔（配售 3,560 万股 A 类股 @268 港元 + 65 亿港元零息可转债），但 可转债 2027 年到期、期限不足 18 个月、转换价 335 港元 。若届时不能转股，就是 8.29 亿美元的现金流出。已知金额、已知时点的硬约束，智谱没有对应项。

两家都不存在短期生存问题，但智谱的资金安全垫明显更厚。七月之前的市场共识（包括我们自己在 7 月 6 日那份对比里的判断）是"智谱跑道不足 2 年，回 A 融资是生存必需"。 七月这笔 272 亿元人民币的配售，把这个判断彻底推翻了。

同时也要指出： 两家下半年都确定提速 。MiniMax 自述七月两笔募资净额的约 80%（约 16.2 亿美元）将在 2027 年底前投入 AI 基础设施与研发，"月均额外支出约 9,260 万美元"；智谱的算力表内敞口（预付 21.6 亿元 + 应付 14.27 亿元 = 35.8 亿元）仍在膨胀。上表的跑道年数按上半年速度线性外推，实际都会更短。

八、分野四：收入质量，各有各的短板

收入质量指标 智谱 MiniMax 谁更好
应收周转天数 约 149 天 60.8 天 MiniMax
应收账款 / 半年收入 82.1% 33.6% MiniMax
金融资产减值损失 / 收入 2.9% 0.95% MiniMax
坏账拨备率变动 10.6% → 7.3%（下降） 减值同比放大 17 倍 都在恶化方向
合约负债 / 半年收入 31.7% 15.7% 智谱
按时点确认收入占比 89.6% 70.7% MiniMax

这一栏没有赢家，两家各有一半。

MiniMax 的回款质量明显更好 ：应收周转 61 天对智谱的 149 天。智谱背着历史本地化项目制应收的包袱，同时新增的应收又主要来自云端大客户账期。本报告期智谱本地化收入只有 1.29 亿元，应收账款净额却增加了 4.80 亿元， 增量必然来自 API 业务的大客户信用 。这说明它 8.25 亿元 API 收入里，有相当比例不是开发者预付，而是给大企业的账期。

智谱这里还有一处需要在年报追问的矛盾： 6 个月至 1 年的账龄桶半年增长 248.6%、1 至 2 年增长 179.7%，而坏账拨备率反而从 10.6% 降到 7.3% 。长账龄在放大而拨备在下降，两个方向相反。

智谱的收入能见度更好 ：合约负债（订阅预收）占半年收入 31.7%，是 MiniMax 的两倍厚。这是 Coding Plan 订阅制在报表上的硬证据。MiniMax 的合约负债只有 1,829 万美元、占半年收入 15.7%，几乎没有递延收入蓄水池。

但智谱按时点确认的收入占比更高（89.6% 对 70.7%） ，意味着它的收入更依赖按量计费的瞬时消耗，受客户模型选型、价格战、单个大客户调用波动的影响更直接。

九、分野五：组织形态，人少钱多 vs 人多钱少

组织指标（1H2026 年化） 智谱 MiniMax
员工数 981 人 568 人
半年员工增幅 +11.1%（对 1H2025 的 883 人） +32.7% （对 2025 年末 428 人）
人均年化薪酬（含股份支付） 约 14.6 万美元 约 24.3 万美元
人均年化创收 约 28.9 万美元 约 41.0 万美元
薪酬 / 收入 50.5% 59.1%
研发开支 / 收入 223.4% 254.7%

MiniMax 人少、人贵、人均创收高；智谱人多、人便宜、人均创收低。 MiniMax 的人均年化薪酬是智谱的 1.66 倍，人均创收是智谱的 1.42 倍。

但两家有一个完全一致的结构： 研发开支的绝大部分不是人，是算力。

  • 智谱：研发开支 21.31 亿元，全公司总薪酬（含股份支付）只有 4.82 亿元。即便假设研发人员拿走全公司七成薪酬（约 3.4 亿元），研发开支里仍有约 17.9 亿元（84%）是训练算力
  • MiniMax：研发开支 2.97 亿美元，全公司薪酬 0.689 亿美元，非人力占比约 77%

这两家都不是人力密集型公司，是算力密集型公司。 用互联网软件公司的"人效"框架去看它们，会得到错误的结论。

十、估值：市值差 4.6 倍，收入差 1.2 倍

市销率（按上半年年化） 约 253 倍 约 67 倍 3.79 倍

市值差 4.57 倍，收入只差 1.22 倍，市销率差 3.44 倍。

这是本文所有对比里，最需要读者自己做判断的一组数。上面九节呈现的事实是：智谱在收入规模、毛利率、增量毛利率、B 端赛道份额、资金跑道上占优；MiniMax 在回款质量、人均效率、总收入环比斜率上占优；两家在烧钱强度、研发投入、毛利率塌陷方向、预付算力的黑箱、披露完整性上高度雷同。

这些差异能否支撑 3.44 倍的市销率差距，本文不给答案。

本文遵循不写股价涨跌与分析师预期的原则 ，市值仅作为市销率的分母基准列出，取数时点为 2026 年 8 月 31 日收盘。两份中报均在港股收盘后发布（MiniMax 8 月 26 日 17:41，智谱 8 月 31 日 18:56）。

2026 年 7 月 6 日我们做过一次两家的对比，当时的结论以"把判断权交给 8 月的中报"收尾。现在中报出来了，逐条对账：

十二、一句话定性

这是两家被同一条成本曲线约束、正在向同一条 B 端赛道收敛、同时遭遇毛利率塌陷的公司。 上半年它们花掉了几乎一样多的钱（经调整净亏损差 0.26%），智谱用这笔钱换回了多 22% 的收入、多 80% 的毛利和多 66% 的 B 端 API 份额，MiniMax 换回了更好的回款质量和更高的人均效率。 智谱的资金安全垫（4.6 年对 2.9 年）是当下最实质的质地差异，MiniMax 的 2027 年可转债是最实质的时间约束。 但比两家相对优劣更重要的，是两份报表共同指向的那个事实：大模型 API 生意的毛利结构更接近算力转售，不是软件。

十三、下一份财报（2026 年报，2027 年 3 月）该盯什么

共同的三个 ：

  1. 毛利率能否止跌 。智谱看云端能否突破 30%（现 24.6%，两个半年只走了 2.2pp）；MiniMax 看能否在 17%-18% 止跌（现 17.9%）。若两家继续同向下滑，行业结论成立；若一家止跌一家继续跌，才是公司层面的差异。
  2. 预付算力科目的明细 。智谱 12.44 亿元 + 9.12 亿元"其他非流动资产"，MiniMax 2.66 亿美元，两家都是黑箱。中期报告（不是业绩公告）的附注里会披露，这是最先能验证的一项。
  3. 经营现金流出与经调整净亏损的倍数 。MiniMax 1H2026 为 1.47 倍，智谱推算约 1.63 倍。倍数持续高于 1.4，说明预付算力的现金前置是常态而非一次性，实际烧钱要按经调整亏损乘以 1.5 左右来估。

智谱单独的两个 ：

  1. 合约负债 / 收入能否守住 30% （现 31.7%）。上升则订阅制转型成立，回落至 20% 以下则说明增长仍靠一次性调用堆量。
  2. 应收拨备率与 1 年以上账龄 。拨备率继续降而长账龄继续涨，需要直接质疑收入质量。

MiniMax 单独的两个 ：

  1. 阿里云 2026 全年实际采购额对 3.00 亿美元上限 。若逼近上限（即下半年达 2.24 亿、为上半年 3 倍），FY2026 经调整净亏损可能超过 8 亿美元。
  2. 2027 年可转债的处置路径 ，以及 7,491 万美元设备转固后的折旧台阶（1H2026 折旧仅 233 万美元，明显未满期计提）。

十四、如果只能选一个

结论

两家都不该买。若必须在两者之间选一个，选 MiniMax。理由是价格，不是生意。

生意质量上智谱更好，前面十三节的数据在这一点上是一致的。但投资决策不是评选优秀企业，是拿价格换未来的现金流。 智谱今天的市销率是 MiniMax 的 3.44 倍，而它的生意好不到 3.44 倍。

一、为什么说两家都不该买

买入门槛绕不开三件事：生意的经济特征看得懂、护城河可验证、价格留出安全边际。这两家在第一条就卡住了。

看不懂的不是技术，是毛利率。 一门生意最基本的经济特征是它赚多少毛利。这两家的毛利率在最近半年分别移动了 -11.3 和 -15.9 个百分点，增量毛利率一个 12.0% 一个 6.5%，都只有报表毛利率的一半。 一门每半年毛利率结构变动超过 10 个百分点、且新增收入赚钱效率只有存量一半的生意，是无法估值的。不是估值高低的问题，是分母还没稳定下来。

自由现金流都是深度负数，且在加速。 智谱推算年化经营现金流出约 9.5 亿美元（FY2025 的 3.1 倍），MiniMax 约 8.6 亿美元（同样是 3.1 倍）。两家的内生资本开支都极低，但这个数字是误导：算力全部租用，资本开支伪装成了经营开支。

盈亏平衡的路径不在视野内。 智谱毛利率 26.4%、研发占收入 223.4%；MiniMax 毛利率 17.9%、研发占收入 254.7%。要走到打平，收入需要在毛利率不下滑的前提下再涨一个数量级。过去半年的数据说的正好相反：收入涨得越快，毛利率掉得越快。

这不是"贵不贵"的问题，是"能不能算"的问题。 两家现在都该在观察名单上，不在买入名单上。

二、同一套假设下的三年推演

既然要选，就用完全一致的增长假设和退出倍数，把价格的差异单独隔离出来。

假设（对两家完全相同，且已经相当乐观）：2H2026 环比 +60%，2027 全年 +120%，2028 +80%，2029 +50%。这条曲线意味着三年后收入约为今天的 6 倍。

在完全相同的经营假设下，三年后无论给什么退出倍数，MiniMax 的回报都高出一个量级。因为你为同样的东西少付了 3.44 倍的钱。

注意最后一行：智谱需要在 2029 年、收入做到 147 亿元时 仍然维持 30 倍市销率 ，才勉强做到不亏钱。这等于要求市场三年后对一家收入体量已经不小的公司，继续给出今天的成长股定价。

反过来算：智谱要在三年里跑赢 MiniMax，收入增速需要比它快 3.45 倍。 目前的数据是反的，总收入半年环比智谱 78.8%、MiniMax 139.8%。即便只比两家正面相撞的 B 端 API 业务（智谱 411.6% 对 341.1%），这 1.21 倍的增速优势，离 3.45 倍的价格差距还差得远。

三、选 MiniMax 的四条理由

第一，价格差距远大于生意质量差距。 智谱在毛利率上领先 8.5 个百分点、增量毛利率领先 1.85 倍、B 端 API 规模领先 1.66 倍。这些差距都是真实的，但加总起来不到 2 倍。价格差 3.44 倍。

第二，最近半年的增长斜率在 MiniMax 一侧。 智谱 399.7% 的同比来自 2,910 万元的低基数，环比才是真实斜率：78.8% 对 139.8%。

第三，收入质量在几个具体项上 MiniMax 更硬。 应收周转 61 天对 149 天；减值损失占收入 0.95% 对 2.9%；开放平台收入里来自关连方阿里巴巴的只有 0.7%，其余全是真实第三方需求。而智谱有一处矛盾至今没有解释： 长账龄桶半年增长 248.6%，坏账拨备率却从 10.6% 降到 7.3% 。

第四，人均效率是组织能力的代理变量。 MiniMax 568 人做出 1.166 亿美元收入，智谱 981 人做出 1.420 亿美元；人均年化创收 41.0 万对 28.9 万美元。在技术迭代速度决定生死的行业里，小而贵的团队通常比大而便宜的团队跑得快。

四、我拒绝的那条多头逻辑，以及为什么

智谱最强的一条：它是这两家里唯一有可能形成结构性护城河的。

国产基座模型 + 10 万级国产芯片规模化推理跑通 + 政企私有化交付的行业积累 + A 股科创板通道，这四件事叠加，意味着在技术脱钩的路径下，智谱在"国产可控 AI 基础设施"这个生态位上几乎无人可替。MiniMax 没有对应的东西。它在全球市场用 1/50 的资本对抗 OpenAI 和 Google，在国内对抗字节、阿里和 DeepSeek，找不到一条结构性的防守线。另外两条：资金安全垫 4.6 年对 2.9 年；A 股历史上给 AI 龙头的估值体系确实显著高于港股，回 A 可能延长高倍数的持续时间。

为什么这些不足以让我选智谱：

护城河的价值最终要体现为超额的资本回报率。 今天没有任何证据表明这条护城河能带来更高的毛利率。 智谱云端毛利率 24.6%，是在 API 提价 101% 之后，只比半年前多了 2.2 个百分点。 一条不能转化为定价权的护城河，在报表上和没有护城河是一样的。 它可能会兑现，但那是未来的事，而 324 倍市销率已经按既成事实付了钱。

资金跑道的优势有一个循环论证问题： 智谱七月能以每股 1,588 港元融到 272 亿元，本身就是极高估值的产物。 它的跑道是估值的函数，不是独立于估值的安全垫。倍数一旦正常化，这个优势会同步收缩。

A 股估值体系的论证是流动性和情绪论证，不是生意论证。用它支撑一个 324 倍市销率的买入决策，等于把判断权交给下一个买家。

五、可证伪的改判条件

判断要能被推翻才有价值。以下条件出现，我会改变上面的排序。

会让我改选智谱的：

  1. 云端毛利率连续两个半年上行且突破 35%（现 24.6%），说明规模效应真实存在、护城河开始转化为定价权
  2. 智谱市值回落到 MiniMax 的 2 倍以内（约 2,438 亿港元），价格差距缩小到与生意质量差距匹配
  3. 经营现金流出／经调整净亏损降到 1.2 倍以下（现推算约 1.63 倍），说明预付算力不是无底洞
  4. MiniMax 的知识产权诉讼出现实质性不利进展，或阿里云采购上限被实际用满导致亏损失控

会让我放弃 MiniMax 的：

  1. 毛利率跌破 15%（现 17.9%），单位推理经济持续恶化，"规模换效率"证伪
  2. 2.66 亿美元预付款项在中期报告披露后，被证明含大额关联方往来或性质不明项目
  3. 2027 年可转债无法转股也无法再融资（现价 349 港元高于转换价 335 港元，暂时不构成压力，但这依赖股价）
  4. AI 原生产品全年收入低于 9,000 万美元，高毛利 C 端业务进入停滞

会让我两家都长期回避的： 2026 年报里两家毛利率继续同向下滑。那意味着这门生意的终局形态就是低毛利算力转售，此时任何一家的市销率都不该超过 10 倍。

六、更诚实的一句话

选 MiniMax，是"两个都不想要时选便宜的那个"，不是"找到了好生意"。

真正符合买入标准的做法是两家都不碰，放进观察名单，等两件事同时发生：毛利率结构稳定下来（连续两个半年不再出现两位数百分点的变动），以及价格回到能用现金流折现算得出来的区间。在此之前，这两只股票的定价靠的是叙事和资金，不是报表。

报表能说的，前十三节已经说完了： 两家公司在同一个半年里花掉了几乎一样多的钱，一家换回了更多的收入和毛利，另一家换回了更好的回款和更高的人效。它们共同证明的是，这门生意目前的毛利结构更接近算力转售，而不是软件。
