1. 核心结论

我的基准判断：美团2036年的正常化税后年利润约670亿元，较合理的基准附近讨论区间是500—850亿元。 这不是统计置信区间，更不是公司指引。竞争恶化的悲观模型只有约39亿元；入口、履约与海外同时成功的乐观模型约1,399亿元。极端情况下仍可能亏损。

未来三年，美团首先是一家需要修复单位经济的本地生活平台。AI能提高效率，却同时带来算力成本、广告入口变化和对手能力提升。基准模型中，2027—2029年利润约64、152、252亿元，AI相对2026年能力基线的净增量仅为−8、+4、+20亿元。 大部分利润改善来自竞争缓和、收入增长和新业务减亏，不能算作AI功劳。

截至参考价72.25港元，模型的三年基准回报约7.6%年化，未达到本文采用的10%要求回报；研究判断为观察，等待更好的价格或连续经营验证，不把“AI受益”直接当作买入理由。价格分析位于第9节，属于高敏感度估值示例。

三个必须纠正的口径问题：

  • 2025年约170亿元“经营亏损”的简化表述接近两分部合计；加未分配费用后，集团IFRS经营亏损为250.41亿元。数据商标准化经营亏损310.36亿元又是另一口径，不能拿来直接交叉判错。
  • 2026Q2的IFRS经营利润26.91亿元包含其他收益34.94亿元和金融投资公允价值收益0.55亿元。机械扣除这两项约为−8.58亿元。这只是盈利质量压力指标，不是经审计的“真实经营利润”：其他收益并不全部一次性。它足以提醒我们，单季扭亏不能直接乘四。
  • 公司已在历史期间使用AI。研发效率、广告推荐和调度的既有效果已在历史利润中；预测只加2026基线之上的新增影响。[S2、S7]

3.2 现金不等于可分配现金

截至2026年6月末，现金等价物1047.17亿元、短期理财635.97亿元，合计1683.14亿元；借款、票据及租赁负债约958.17亿元，对应净现金约724.97亿元。受限现金未纳入上述可用资金。该净现金不能直接全部派给股东，仍需保留日常经营和竞争储备。[S2、S3]

本文没有把长期战略投资计入现金，也没有把全部负债机械从现金扣除：应付商户等经营负债与经营资产和结算资金需配套分析。估值示例对未来盈余现金和战略投资单独设假设，不将投资公允价值收益永久资本化。

4. 竞争格局：谁拿走AI创造的价值？

美团的核心生意是把本地需求、商户供给、交易、配送和售后组合成可兑现的服务。密度优势存在于城市及商圈；通用模型可以买到，足够密集的履约网络不能只靠调用API复制。但商户、骑手和消费者可以使用多个平台，网络强不代表定价权强。

对手/赛道 已验证的竞争状态 AI可能改变什么 对利润的主要威胁
阿里：淘宝闪购/饿了么、盒马、千问 2026年6月季公告称维持份额并改善单位经济，高价值订单结构升级 [S10] 购物入口、会员、供应链与AI助手连接；减少从淘宝切到即时消费的操作成本 最强直接对手；同时压制订单利润和获客效率，无法靠“AI领先”跳过竞争
京东外卖 官方Q2披露投入及亏损收窄，未宣布退出 [S11] 物流、品质、零售会员交叉使用AI 即使第三名也能约束价格，投入收缩不等于旧格局恢复
抖音到店酒旅 内容推荐争夺商家获客预算；公开GMV存在支付/核销口径差异 [S12] AIGC降低内容制作成本，推荐与达人供给增强 重点争夺广告与高毛利到店业务；不必复制全部骑手网络即可损伤美团利润
携程、同程等酒旅 专业库存、售后及出行关系构成独立壁垒 [S13] AI攻略容易复制，库存和复杂服务较难复制 美团高频入口不能自动转化为高端酒旅优势，监管也约束收费
Keeta海外 美团称香港稳定盈利、中东效率改善，巴西仍聚焦圣保罗 [S2] 国内调度、商户工具和客服可复用 每个城市需要重新建立供需网络；当地对手、补贴、劳动及合规风险仍在
外部通用AI Agent 跨平台搜集、比较和执行是潜在路径，商业抽成尚未定型 用户入口可能从App迁移到助手 美团可能保住履约量，却损失广告曝光、直接用户关系和渠道议价权

份额不伪精确。有媒体转述2026Q2订单份额约49/41/10，也有所谓“综合份额”43/42/15，两者方法与餐饮/非餐边界不同，原始底稿未取得。不能把它们平均，更不能称双源验证。本报告只采用美团与阿里双强、京东第三方制约的定性判断，不以未经审计的份额驱动收入模型。[S14]

同理，阿里即时零售收入含盒马等不同形态，不能与美团配送收入直接比出市场份额；抖音支付GMV不能和美团核销交易额直接比较。市场扩容需要线上渗透、消费频次和非餐品类增长，不意味着无限提高抽成。

非共识风险：美团2036年可以更高效、更大，却不一定更赚钱。如果外部AI掌握需求和比价，美团偏向履约基础设施，行业降本可能主要转移给消费者、商户或入口平台。最终决定盈利的是效率收益留存与入口控制权。

5. AI利润桥：相对2026年已经部署的能力计算

5.1 已有证据与未披露项目

美团已发布LongCat 2.0及CatPaw。2026年7月官方技术文章称CatPaw累计覆盖9万员工、搭建3万个Agent；覆盖与创建数量不是活跃率或利润。公司早在2025年就称超过九成工程师使用AI、约一半新代码由AI生成，不能再把该比例当作未来研发成本削减比例。[S6、S7、S8]

小团和商户Agent有转化、客服及经营分析价值，但公司未披露独立AI收入、净新增订单、全成本ROI和实际费用节约。模型对外收费及无人配送大规模替代，在基准中均不作为独立高利润业务。

5.2 基准情景的AI增量

以下每一个前瞻数字都是研究假设。反事实是冻结2026年已具备的AI能力、正常维护与既有算法继续运行，而不是“完全没有AI的美团”。普通业务规模增长和补贴正常化在基础利润率中；额外AI收益与额外投入只在此桥计一次。

基准AI三个正向收益在2029年合计78亿元，扣掉投入和收益流失53亿元，只留下25亿元税前、20亿元税后。不能把78亿元当成净利润。2036年正向收益400亿元，成本和流失300亿元，仅留下四分之一。

量级依据及其脆弱性：

  • 2029转化42亿元：可由1000亿元相关变现收入底盘×6%额外提升×70%边际贡献率构成。三个因子均为假设，非独立披露的广告分部；不把整笔GMV当作收入。不再在基础核心收入增长率内增加同一AI转化。
  • 2029内部节约18亿元：180亿元适用成本×10%额外兑现率；只计算减少的现金成本或避免招聘，生产更多代码不自动算节约。新增AI人才和算力费用另扣。
  • 2029履约18亿元：400亿适用订单×每单0.045元新增节约；这一订单数是量级假设。节约已扣接管、维修和接驳等运营成本，新增AI折旧在成本行，不假设普遍替换骑手。
  • 2036正向收益：转化180可由1500亿元相关收入×15%×80%构成；内部80可由400亿元适用成本×20%构成；履约140可由700亿单×0.20元构成。均是技术渗透与规模联动的情景，不能由目前产品曝光量证明。
  • 2036成本180亿元必须容纳持续模型训练、人才、推理和折旧；入口与让利120亿元表示竞争会分走收益。若成本/流失增加100亿元，税后利润减少80亿元。

资本开支在自由现金流中扣，折旧在利润中扣，不能在会计利润里两次扣同一设备。20%为正常化税率；负利润不给即时税收利益，AI负增量是否有税盾取决于合并情景是否仍盈利。这并非实际税务主体逐一预测。

6. 未来三年：竞争修复比AI更重要

统一利润口径为含股份薪酬的正常化归属股东税后经营收益代理值：排除不可预测投资估值波动及偶发大额项目，保留经常费用、净融资成本与税；假设少数股东影响不重大。它不是逐项IFRS归母预测，也不是经调整净利润。2036亦使用同一口径，不能承诺某年报表净利与之相等。

公式：

税前收益 = 核心收入×基础分部经营利润率 + 新业务经营利润 − 总部经常成本 − 净融资成本 + 税前AI增量

税后收益 = 正税前收益×80%；税前为负时保留全部亏损

核心收入2026年取2800亿元工作起点：这是全年估计，不是公告实际值。半年约1356亿元及二季度约715亿元支持其数量级。基础利润率含正常研发、营销、履约和劳动保障，不含上节新增AI净影响。总部成本是股份薪酬和公司经常费用的正常化估计，未再次扣各分部已有费用，未加一次性投资收益，也不重复放入新增AI研发。

总部成本高于2025年未分配净额，是因未来组织成本和SBC、以及移除部分正收益抵销的建模选择；财报无法证明该分拆，故必须做敏感性分析，不能伪装成官方预算。

7. 十年后：2036年年利润模型

长期从2026年核心收入工作基数推10年，短期三年模型是恢复路径，长期CAGR是全十年平均。二者不应当作同一年度精确预算：基准2029到2036核心收入隐含增速约5.6%，低于前三年的7%。

基准算式：

[2800×1.06^10×17% + 80 − 170 − 20 + 100]×80% = 673.9548亿元

最后的100是AI税前增量，其税后为80；不能再额外加80。新业务80亿元是国内食杂零售与海外合计，示意拆分为国内30、海外50，不是Keeta单独利润预测。乐观250需要海外多市场成功与国内零售成熟，是显著更强假设；没有再额外叠加独立大模型利润。

基准商业条件：美团保住主要本地消费直接入口；与阿里、抖音长期共存而非完全垄断；非餐品类与商家数字化贡献增长；部分AI节约留存；海外失败市场及时止损。基础17%是核心分部利润率，绝不是集团净利率；国内自营零售收入按总额列报，不能套软件公司高利润率。

为什么说500—850亿元是基准附近区间？固定其他假设，2036年核心基础利润率分别为13%、17%、21%，税后利润为513.49、673.95、834.41亿元。这个区间只反映利润率变化；若收入、海外、AI入口也恶化，应切换到悲观情景，不可宣称500亿元是底线。

压力与尾部：2036年若核心利润率仅6%、新业务亏100、总部250、净融资成本30、AI税前贡献−100，按悲观收入3762.97亿元计算，全年正常化亏损约254.22亿元。另一方向，千亿元以上需要更高变现能力和海外成功；其可能性不能等同于最可能结果。本文不人为给三情景概率，亦不把加权平均数称作目标利润。

对AI的十年判断：基准80亿元约占2036总利润12%；技术主要帮助维持服务质量和经济性，真正决定千亿与百亿差距的仍是入口、竞争和资本配置。AI也可能放大商业模式风险，不能只看正向生产率。

8. 管理层、监管和反面检验

王兴及团队有建设履约网络和跨业务组织的能力；同一长期主义也可能使低回报项目持续耗资。不同投票权提高战略连续性，却使普通股股东对投入节奏影响较弱。股份薪酬是真实经济成本，本报告没有因其非现金性质将其全部加回，也没有预设回购永久抵消稀释。[S1、S5]

截至截止日的新风险：9月19日美团确认在线酒店预订相关业务被立案调查。应写作调查中，不能写成已经认定违法或已经罚款。它可能影响商户规则、排序、收费与高毛利业务的议价能力，长期影响未必只是一次性支出。[S15]

《互联网平台价格行为规则》已于2026年4月10日起施行，对强制跨平台最低价、竞价展示、价格歧视等有约束；AI增收不能建立在违法差别定价上。6月外卖补贴规范所检索到的是征求意见稿，不能由此假设补贴战已被法律永久终结。全国新就业形态职业伤害保障扩围进一步提醒模型保留劳动保障成本。[S16—S18]

风险 如何损伤利润 可证伪/需跟踪指标
高价值外卖再度价格战 收入增长但单位贡献下降 连续两季剔除补贴后的单位经济、核心利润率及高价值用户留存
AI入口迁移 交易量增长而广告及直接关系流失 直接入口占比、渠道分成、广告收入/交易额，未披露时承认无法验证
AI投入没有兑现 工具采用率上升但费用继续膨胀 推理成本、适用流程单位成本、研发费用率和实际招聘变化
海外扩张失控 长期负现金流消耗国内收益 分市场成熟队列、补贴后留存、新业务亏损与现金消耗
骑手保障与食品安全 成本底线提高，罚款或整改 安全事故、职伤支出、保障覆盖与单均履约全成本
治理与股份稀释 总利润上升却每股收益落后 SBC、期权归属、总股本净变动和回购注销

看多论点：密度和履约可信度；高频导入多场景；真实交易数据；商户工具黏性；AI适用流程较多；海外选择性成功。

看空论点：多平台使用导致低转换成本；阿里可跨业务竞争；抖音吸走广告预算；AI流量重新分配；模型军备成本；海外与监管压低资本回报。两侧都成立，投资判断取决于购买价格与后续证据。

9. 估值与安全边际：附属检验，不用负EPS机械算PE

9月24日参考收盘价72.25港元，StockAnalysis及Investing历史行情一致。8月末月报A类579,152,986股、B类5,596,331,814股，合计6,175,484,800股。这是最新已核实月末发行股本，不宣称为9月24日逐日精确在外股数。月报还列有292.48万股已回购未注销，不能重复当作已经注销。[S3、S5、S19]

72.25×6,175,484,800＝4461.79亿港元；数据商当前市值4459.20亿港元，相差约0.058%，不影响量级判断，但说明发行股本、回购待注销及报价口径须注明。TTM亏损，当前PE与对负EPS做复合增长均无经济意义。未调用工具的默认正EPS三情景模板，改用分部模型。

以下均为估值假设，汇率0.86人民币/港元是建模固定值，不冒充最新即期汇率：2029基准正常化利润252.17亿元，给16倍；期末盈余现金500亿元、独立投资资产折价250亿元；股本固定为上述月报总额。

2029每股价值 = (252.1734848×16 + 500 + 250) ÷61.754848÷0.86 ≈90.09港元

三年10%折现约67.69港元。期间未假定派息，500亿元现金是留存经营盈余、资本开支、租赁与流动性储备之后的终值工作假设，不是已核实未来现金流；投资资产不再贡献基准正常化利润，避免双计。净融资成本只代表经营及债务融资负担，不计盈余投资回报。

这个估值对三年现金积累缺少逐年现金流模型支持，可信度低于利润情景。盈余现金从500变到0，折现现值约减少7.1港元；总部经常成本变化和估值倍数变化影响更大。它适合检查安全边际，不适合作精确买卖点。

风格 本模型下的研究动作 条件价格参考（港元）
激进 小额试探需接受悲观亏损路径；不能只据AI叙事 约65—68以内且经营改善得到验证
稳健 等待更大安全边际，或提高对利润路径的把握 约55—60，基准折现价值再留约一至两成余量
保守 等待跨季经营及自由现金流验证，不以低价替代基本面 暂无单凭价格即可满足的区间

加大研究/上调模型信号：核心利润率持续改善且补贴不反弹；AI净ROI有披露；新业务亏损继续收窄；经营现金流覆盖资本开支和租赁。下调信号：高价值订单流失；研发及渠道费用增幅超过收益；海外投入增加而留存不足；监管使商户变现能力结构性下降。

11. 数据验证、模型复现与局限

交叉来源的优先顺序是港交所原件、公司披露、独立数据商/可信媒体。原始财报与公司新闻不算两个独立来源；新闻二次复述只是抄录核对。AAStocks页面未取得可用数据，改用HKEX与StockAnalysis。华盛通明确标注AI生成，仅用于数字抄录比较，不作为独立权威确认，且其季度归母标签不沿用。无法取得第二独立口径的分部、AI采用及治理细节标为单一原始披露，不假称全部双源通过。

抽样使用tools/report_audit.py extract固定seed=42、比例15%，外部事实与假设/算式分开核验。预测核验通过只表示算术可复现，不证明预测准确；未检到完整独立来源的项目在审计说明中列为单源，不用模型输出伪装第二财经数据源。

AI研究局限：没有付费原始行业份额底稿；没有公司AI独立损益、逐场景A/B结果与真实费用归因；现金模型简化；不能预测监管结论、未来重大收购和股本变化。因此应持续更新假设，而不是给674亿元增加无意义的小数精度。
