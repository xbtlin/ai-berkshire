明确标的

Global Mixed-mode Technology（8081.TW）— PMIC供应链A级瓶颈，五年首次涨价

为什么现在值得关注： 6月11-12日，Global Mixed-mode Technology（台湾PMIC供应商，股票代码8081.TW）宣布将上调电源管理IC价格，为5年来首次涨价。股价6月12日单日+5.49%。董事长吴金铨表示"AI驱动多产业需求、晶圆产能吃紧，PMIC供需缺口持续扩大。"同期，同行Anpec（安茂）5月宣布年中+15%涨价，uPI已预警2026年全面短缺（铅期35-40周）。PMIC瓶颈从单点信号演变为行业级确认。

瓶颈定位：Layer 2，电源管理IC（PMIC），瓶颈评级 A级

瓶颈维度 评估
供给集中度 🟡 台湾3-5家主要供应商（GMT / uPI / Anpec / Monolithic Power）
扩产周期 🔴 晶圆代工产能有限，新增需12-18个月
替代难度 🔴 AI服务器PMIC需高电流密度规格，无法快速用标准模拟IC替代
产能利用率 🔴 铅期35-40周（正常8-12周），>90%利用率特征明显
需求增速 🔴 AI服务器PMIC需求>50%/年
客户验证周期 🔴 新供应商验证>1年（安全认证+热管理设计协同）

判定：6项标准满足5个🔴 → S级瓶颈边界（当前按A级记录，等财报确认升S）

估值红灯检查（4条，无一触发）： 1. 市值 > TAM 20%？PMIC市场$50B+，20% = $10B；GMT市值$650M << $10B → 通过 ✅ 2. PS > 30x 且增速 < 100%？PS 2.6x → 通过 ✅ 3. 市值 > 5年乐观收入预测×10？收入$268M × 1.3^5 = ~$990M × 10 = $9.9B；GMT $650M << $9.9B → 通过 ✅ 4. 增发后60天内翻倍？不适用 → 通过 ✅

估值安全边际检验（10年25x PE退出法）： - 当前净利润：$45M USD - 乐观情景（15%/yr增长）：$45M × 4.05 = $182M → 25x PE退出 = $4.55B；当前$650M → 年化21.6% ✅ - 保守情景（5%/yr，维持历史增速）：$45M × 1.63 = $73.3M → 25x PE = $1.83B；年化10.9% ✅ - 结论：即使历史低速增长也具备安全边际；涨价催化下若收入增速加速到15%+，回报空间显著

看多逻辑： 1. 五年首次定价权解锁：5年未涨价意味着定价权被长期压制；短缺环境下涨价是利润率扩张的直接触发器，相当于压弹簧。Anpec已领先涨15%，GMT跟进是行业确认而非孤立行为。 2. 纯正PMIC标的 + 极低PE：PE 12x在台湾半导体行业（均值31.7x）明显折价；股价尚未充分反映PMIC短缺逻辑，涨价宣布日仅+5.49%，市场尚未完全定价后续利润弹性。 3. AI驱动需求具有可预测性：AI服务器每GPU配套高性能PMIC数量是PC的10-20倍；下游需求增长路径清晰（NVIDIA GB200 / GB300 / Rubin全产能拉动）。

看空逻辑： 1. 历史增速低（5%）：过去增长慢，没有证据证明这次涨价能持续转化为高速营收增长；可能存在客户谈判博弈（客户强制二供认证等）。 2. 竞争者密集：MPS（Monolithic Power）、TI、ADI等大厂在AI PMIC有更强技术壁垒和更大产能；GMT中高端产品能否真正切入GB300生态尚未验证。 3. 台湾地缘风险：台海局势影响所有台湾半导体公司，GMT小市值流动性可能在避险行情中压力放大。

催化剂时间线： - 近期（1-3月）：Q2 2026财报（预计7-8月）——验证价格上调是否转化为毛利率/营收增长 - 中期（3-12月）：若铅期数据维持35-40周，市场将开始重新定价PMIC短缺；同行Anpec/uPI财报如超预期，将带动整体板块重估

关键数据：市值 $650M USD / 年收入 $268M USD / PS 2.6x / PE 12-14x / 收入增速 +5% / PMIC占比 ~100%

交叉验证状态： - ✅ 客户验证：uPI预警铅期35-40周（上游同行确认） - ✅ 行业验证：Anpec 5月宣布+15%涨价，GMT 6月跟进，行业级信号 - ⚠️ 收入验证：价格上调尚未体现在财报数据（Q2财报7-8月公布） - ✅ 估值合理：PE 12x / PS 2.6x / 安全边际确认 - ❌ 客户名单：未公开高端AI客户导入信息

建议：加入观察名单 ★★★，等Q2财报（7-8月）验证涨价落地→利润率改善；如毛利率提升>3pct且收入增速加速至15%+，考虑执行/investment-team深入研究。
