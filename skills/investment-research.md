# 投资研究：单公司系统化研究

对 $ARGUMENTS 做系统化投资研究，按第零步到第八步顺序执行。

## 总原则

- **证据**：一手原件优先，包括年报、10-K/10-Q/8-K、交易所公告、电话会原文和监管原文。媒体报道只作线索，用到时标注"媒体线索"。仓库里的旧报告只是观点，不引用其中的数字。
- **口径**：事实和观点分开写。估计值标"估计"，查不到的写"数据不足"。每个核心判断都要附上反面证据。
- **计算**：一律用工具计算，禁止心算。
- **不写**：股价涨跌和分析师目标价。
- **命名**：小标题按分析维度命名，不挂投资人名字。如果引用某位投资人的原话，必须给出可核验的出处，禁止编造。

## 第零步：信息丰富度评级（写在报告开头）

| 等级 | 特征 | 陷阱与对策 |
|---|---|---|
| A 充裕 | 上市多年，覆盖密集 | 结论容易趋同于共识。篇幅重点放在反面检验：聪明人为什么不买？ |
| B 适中 | 上市 1–3 年，覆盖有限 | 容易用推测填补空白。推算数据要标置信度，区分"有据推算"和"填空" |
| C 稀缺 | 新股、冷门股 | 容易把"看不清"误判为"不好"。不要硬拼完整报告，只回答四个问题：客户为什么付钱、复购靠什么、对手拿 100 亿能否复制、管理层做过哪些关键决策 |

报告开头写三项：
1. 评级。可以按维度分别评级，比如财务 A、治理 C。
2. 局限性声明：哪些信息查不到。
3. 偏见自查：确定性来自生意本质还是资料数量？资料减半，结论会不会变？结论和共识雷同时，增量在哪里？

## 第一步：数据收集与交叉验证

并行启动后台 Agent 收集以下数据：
- 分部收入、增速、毛利率；
- 近 5 年损益表与现金流；
- 竞争格局与份额；
- 护城河来源；
- 研发；
- 管理层履历、持股与关键决策；
- TAM；
- 风险；
- 估值倍数；
- 多空论点。

数据源按 `skills/financial-data.md` 执行：
- 美股：macrotrends 加 stockanalysis。
- 港股：aastocks 加 macrotrends ADR。
- A股：东方财富加巨潮资讯。

**必须做两源验证的数据**：总股本、股价与市值、最近财年收入和净利润、现金与净现金、管理层持股（区分经济权益和投票权）。
- 偏差超过 1% 必须查明原因，以公司原件为准。
- 口径差异要写明，常见的有：债务是否含租赁、自由现金流里资本开支的定义、币种和单位。

```bash
python3 tools/financial_rigor.py verify-market-cap --price {股价} --shares {总股本} --reported {报告市值} --currency {币种}
python3 tools/financial_rigor.py cross-validate --field {字段} --values '{"来源1": 数值, "来源2": 数值}' --unit {单位}
python3 tools/financial_rigor.py verify-valuation --price {股价} --eps {EPS} --bvps {每股净资产} --fcf-per-share {每股FCF} --dividend {每股股息}
```

工具输出放进附录"关键数据交叉验证记录"。工具报 ❌ 时，排查清楚才能继续。

## 第二步：生意本质

- 用一句话定义这门生意。
- 收入结构；5 年盈利趋势。
- 商业模式：一次性销售还是复购？硬件、软件还是平台？
- 客户锁定程度。
- 毛利率与同行对比，并解释原因。
- 经营杠杆。

追问：这门生意好在哪里，弱在哪里？

## 第三步：护城河

逐项给出证据、趋势和★评分：
- 定价权：提价是否掉量。
- 转换成本。
- 网络效应。
- 规模效应。
- 技术壁垒：领先几年，能否被复制。

再判断过去 5 年护城河是变宽还是变窄。

追问：10 年后护城河还在吗？什么能摧毁它？

## 第四步：风险与反面检验

- 失败路径表：路径 / 证据 / 概率 / 影响。
- 历史类比：处境相似的公司，最后结局如何。写清类比的边界。
- 空方最强论点，按证据强度排序。
- 偏误自查：叙事偏差、锚定效应、幸存者偏差。

追问：最可能在哪里犯错？聪明人为什么不买？

## 第五步：管理层

- 关键决策复盘表：时间 / 决策 / 结果 / 评分。
- 资本配置：并购、回购时机、分红。
- 利益一致性：持股、薪酬、减持（看 Form 4 或减持公告）。
- 继任安排与关键人才。

追问：CEO 离开后，公司还能保持竞争力吗？

## 第六步：行业趋势

- 是否属于范式转移？正反证据都要列。
- 天花板：TAM，管理层口径和独立机构口径分开写。
- 价值链位置：上下游议价权。
- 技术路线风险。
- 客户和供应商集中度。

追问：20 年后回看，这家公司是这个时代的标准石油，还是 3Com？

## 第七步：估值与安全边际

用 `verify-valuation` 算出当前倍数，再做以下几项：

**反向折现**：现价隐含了怎样的增长？零增长时值多少？

**三情景（3 年）**：
```bash
python3 tools/financial_rigor.py three-scenario --price {股价} --eps {EPS} --shares {总股本亿} \
  --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE} --years 3 --currency {币种}
```

**对比**：与自身历史分位、与同行对比。

**结论**：给出具体的价格区间。

追问：如果股市关闭 5 年，愿意以这个价格持有吗？

### 十年折现（凡是给出十年 IRR 或终值倍数，都必须走这一节）

**分工**：
- 三年三情景回答"贵不贵"。
- 十年折现只是仓位压力测试，用来定仓位上限。它不是买入、持有、回避的否决票。十年基准 IRR 低于 r，只能收紧仓位，不能单独把结论改成回避或观望。
- 敏感性检查的目的，是暴露结论到底买的是公司还是折现率。禁止为了想买，把 r 调出币种的合理区间。

**终值倍数**只用永续模型 `PE = (1 − g/ROIC) / (r − g)`。禁止用同业倍数类比，那是用别人今天的价格证明自己的假设。

**输入**（每一项都要写出理由）：
- **r**：必须和现金流同币种。人民币 6%–9%，主用 8%；美元或港元 9%–11.5%，主用 10%。不要跟着国债利率跑。
- **ROIC**：稳态的增量回报。取值夹在存量 ROIC（偏高）和由派息反解出的隐含增量 ROIC（偏低）之间。不要直接用存量 ROIC。
- **g**：终值年之后的永续增速，上限是长期名义 GDP。人民币基准档不超过 2%，美元不超过 4%。g 不随 r 变，做敏感性时只动 r。

**准出检查**：
```bash
python3 tools/terminal_value.py audit --currency {CNY|USD|HKD} --r {r} --roic {ROIC} \
  --g {悲观},{基准},{乐观} --rf {无风险利率} --beta 1.0 \
  --discrete-risks "{风险名}:{情景|尾部档|概率|未建模},..."
```

三条检查，任一条不过就打回：
- **C1**：r 和 g 必须同币种。
- **C2**：每一档的 r − g 至少 5 个百分点。分母小于等于 0 时模型失效。确实要做上行或下行情景，就加 `--upside-only`，并在报告里写明"这是情景，不是估值"。
- **C3**：退市、VIE、断供、监管这类离散风险，只能归入情景或尾部档，不得放进 r 或 β。原因是抬高 r 惩罚的是远期现金流，会把风险的时间分布搞反。β 偏离 1.0 时，必须给出 `--beta-justification`。

完整论证见 `reports/7公司10年投资价值横评-确定性调整后回报-20260814.md` 第 3.4–3.6 节。

**出数**：
```bash
python3 tools/terminal_value.py pe --roic {ROIC} --g {g} --r {r}
python3 tools/terminal_value.py irr --profit {终值年利润} --mcap {市值} --pe {退出PE} --years 10 --payout {股息率-稀释率}
python3 tools/terminal_value.py flip --name {公司} --r {r} --delta 0.02 --currency {币种} --g-shift {平移} --rf {无风险利率} \
  [--roic .. --g 悲,基,乐 --p 悲,基,乐 --irr10=悲,基,乐 --k ..]   # 新公司用内联参数或 --config，字段见 --help
```
多公司横评时，用 `--config` 配合 `table`、`sweep`、`check`。排序比绝对数字更稳健。

**报告必须写明以下五项**：
1. r 的取值、币种，以及配对的 g 上限。
2. r 加减 2 个百分点时，三档的期望 IRR，以及结论会不会翻转。
   - 区间外的档位只作参考，不能用来论证买入。
   - 如果两侧都落在区间外，再用 `--delta 0.01` 复核一次。
   - 结论会翻转的，要标明"对折现率敏感，仓位降级"。
3. 每一档 r − g 的宽度。低于 5 个百分点的，标"仅作情景参考"。
4. audit 里标为"未建模"的风险，写进"限制"一节。
5. 十年结论和三年结论、或和前六步的倾向方向相反时，单开一节「估值分歧对账」。写清三件事：哪一方是定价判断，哪一方是仓位压力测试；最终结论怎样由六个维度综合得出；仓位上限怎样被收紧。

## 第八步：决策备忘录

| 维度 | 结论 | 信心度 |
|---|---|---|
| 生意质量 / 护城河 / 管理层 / 最大风险 / 行业趋势 / 估值 | | ★1–5 |

- 六个维度并列，没有哪个维度能单独否决结论。
- 估值一格同时写三年结论和十年压力测试的结果（如果做了十年折现）。

| 策略 | 建议 |
|---|---|
| 空仓者 / 持仓者 / 卖出信号 / 加仓信号 | 要具体：价格、仓位上限、可检验的触发条件 |

结论必须明确：买入、观望或回避。

最后按维度写多视角点评，用引用格式，每段一个判断。

## 输出

报告写入 `reports/{公司名}/{公司名}-research-{YYYYMMDD}.md`，首行是 `# 标题`。

**结尾依次包括**：
1. AI 分析置信度与投资确定性对照表：前者取决于资料量，后者取决于生意本质。分别说明哪些结论有充分数据，哪些靠有限信息推理。
2. 需要一手验证的问题清单。
3. 交叉验证附录：写明两源不一致的地方，以及撤回的流传说法。
4. 免责声明。
5. 最后单独一行 `<sub>研究模型：{当次实际使用的模型}</sub>`。

## 准出抽检

```bash
python3 tools/report_audit.py extract --report {报告路径} --seed {任意整数} > /tmp/audit_items.json
```

抽样是随机的。要么固定 seed，要么只用存下来的这一份清单，不要重复 extract。

对清单里的每一项，按数据源规范取两个源，填写 `fetched_value`、`fetched_source`、`fetched_value2`、`fetched_source2`，然后执行：

```bash
python3 tools/report_audit.py verdict --results "$(cat /tmp/audit_items.json)" --report {报告文件名}
```

- 所有抽检点偏差都不超过 1%，判【准出】。
- 有任何一点超过 1%，判【打回】：修正后重新抽检。

如果报告含十年折现，定稿前用最终参数再跑一次 `terminal_value.py audit`，退出码为 0 才能发布。写作过程中经常会回头改 r 或 g，最后一次 audit 才算数。
