## 一、日常追踪

### portfolio-review
分析当前持仓，给出调仓建议。每次必跑。
```
portfolio-review
或：portfolio-review @当前持仓文件路径
```

### news-pulse
股价异动时快速归因。不是深度投研，10-15分钟快速判断。
```
news-pulse 股票名称
例：news-pulse 华友钴业
```

### thesis-tracker
检查已买入股票的"投资论文"是否还成立。每季度跑一次。
```
thesis-tracker 股票名称
例：thesis-tracker 比亚迪
```

## 三、Skill 调用方式

**重要：不需要加斜杠 `/`，直接说中文即可。**
```

✅ 对： news-pulse 融发核电
✅ 对： portfolio-review

```

## 四、每次分析的要求

1. **取当前时间** → 用实时股价，不缓存
2. **先看 PE/ROE/毛利率** → 基础判断30秒
3. **看公司治理** → 实控人/关联交易/诚信记录
4. **给明确结论** → 可买/等待/回避，不说"可能"
